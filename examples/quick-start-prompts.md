# Quick-start prompts

These prompts demonstrate that each Skill can be invoked on its own. Replace the bracketed material with your project information.

## Script and directing

```text
Use $director-agent to diagnose this scene's protagonist goal, opposition, action logic, subtext, and weakest dramatic beat. Do not rewrite until the diagnosis is complete: [scene]
```

## Storyboard and generation prompts

```text
Use $ai-storyboard-director to turn this approved scene into readable shots with blocking, shot size, camera position, motivated movement, continuity, and generation-ready prompts: [scene]
```

## One reusable asset

```text
Use $character-asset to create a reference-asset contract for this character, including identity anchors, views, expressions, actions, continuity rules, and failure conditions: [character]
```

## One visual genre

```text
Use $noir-design to translate this scene into observable noir framing, light, color, space, action, material, and continuity parameters without changing the story: [scene]
```

## Production

```text
Use $produce-ai-video to plan production of this approved passage as a watchable AI video, including asset readiness, cost gates, generation stages, quality checks, and final acceptance: [passage]
```
