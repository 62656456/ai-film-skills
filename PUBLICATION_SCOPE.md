# Publication scope

## Included

- 18 packaged, personally authored Skills in `skills/`;
- 1 isolated experimental Skill in `experimental/`;
- shared references required by those Skills;
- original repository documentation, diagrams, metadata, and validation tooling.

## Intentionally excluded

- `sci-fi-design`: retired by its owner and not restored from history;
- `xianxia-visual-director`: installed from an external source without a verified redistribution license;
- `frontend-design`: third-party Apache-2.0 Skill used only as a design-quality reference, not republished as original work;
- system Skills, Lark Skills, plugin Skills, company work, client work, project assets, credentials, local runtime state, and caches.

`hard-sci-fi-visual-director` is present only under `experimental/`. It is not part of the normal installation command and must not be described as approved or deployed.

## Status rule

Structural validation proves that a Skill can be loaded and inspected. It does not prove stable real-world quality. A Skill should be called practice-validated only after accepted results across three different real tasks with evidence.
