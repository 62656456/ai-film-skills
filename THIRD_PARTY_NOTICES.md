# Third-party notices and provenance

## Pinned rendering fonts

The two DejaVu Sans 2.37 font files in `docs/assets/fonts/` are unchanged inputs from the [official DejaVu release](https://github.com/dejavu-fonts/dejavu-fonts/releases/tag/version_2_37). Their upstream copyright and redistribution notices are included in `docs/assets/fonts/LICENSE`, and exact hashes and provenance are recorded in its manifest. These fonts support future launch-asset rendering; the existing published PNGs remain historical outputs and are not regenerated by this maintenance release.

## OmniRoute

The repository presentation was informed by the public information architecture of [OmniRoute](https://github.com/diegosouzapw/OmniRoute): visual thesis, fast navigation, diagrams, multilingual entry points, copyable installation, visible project status, contribution routes, security policy, and third-party notices. No OmniRoute branding, artwork, README prose, code, or private data is copied into this repository.

## Excluded packages

- `xianxia-visual-director` was installed from a third-party repository whose redistribution license was not verified. It is not included.
- `frontend-design` is a third-party Apache-2.0 package. It is not included or represented as original work.
- Codex system Skills and Lark connector Skills are not included.

The personally authored `web-design-director` Skill includes a concise quality checklist whose own provenance note points to Vercel Labs' MIT-licensed Web Interface Guidelines. Preserve that notice when redistributing the Skill.
