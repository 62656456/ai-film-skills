01 / HOW THE PARTS CONNECT

Start from the material you already have.

The full route connects writing, directing, visual language, assets, shots, prompts, optional previs, generation, editing, sound, playback, and user review. Existing material enters at its relevant stage.

  1. 01Writestory · cause · dialogue
  2. 02Directperformance · reveal
  3. 03Visualsstyle · people · space · props
  4. 04Shotsblocking · camera · cuts
  5. 05Promptscompile the chosen design
  6. 06Make & reviewgenerate · edit · watch · repair

Creative-shot ideas remain optional suggestions until selected. Text requests can finish with the text. Images, previs, and videos run when the current request explicitly calls for those media.

03 / VERSION UPDATES

Current use, optional review, and history.

The maintainer's current A 5.7.2 maintenance update is selected by the user's explicit instruction. This activation does not approve every comparison image or establish three-task practice stability.

A 5.7.2 — current maintainer default. Keeps storyboard design, prompt compilation, and actual generation in their requested stages. Creative-shot ideas stay separate until selected; shared facts and chosen shots survive local revisions. A uses the main model's text review without Jev.

B 5.7.1-jev — optional text review. Uses the same creative core and adds explicitly enabled Jev checks of submitted text and locked facts. Jev does not inspect images, decide aesthetics, automatically rewrite shots, or approve a version.

5.6.5 — comparison and rollback baseline. Preserved as the prior local workflow and common-story comparison baseline. The fusion direction retains selected strengths and the user's exact choices; a preferred sample does not validate every output.

v1.4.0 / 5.7.2 — current maintenance Release. Includes all 21 independent packages and the 18 regular-package complete archive, with explicit manifests and checksums.

v1.3.0 / 5.4.4 — historical Release. Published v1.3.0 assets contain the older 5.4.4 snapshot. Its examples, the separate 5.6 Preview, and newer source are distinct artifacts. The older Director example remains SELF-AUDIT ONLY.
