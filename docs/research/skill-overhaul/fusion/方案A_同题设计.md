# locked_prompt

【纸袋交接后的目光】

一、生成任务

生成一条18秒视频，按0—6秒、6—12秒、12—18秒的既定三镜顺序呈现，时间连续。

二、主要主体

林与周站在同侧人行道，纸袋开始由周拿着。对面药店门口有一名保安。一位老人从第一镜开始沿林与周所在的人行道走向公交站。

三、场景状态

午后的干燥住宅街，稳定天光。林与周所在的人行道、车行道、对面药店依次分开，人物站位与药店、公交站的位置保持一致。稀疏车流沿道路正常通行；老人持续向公交站前进，出画后仍按经过时间继续，后镜只呈现取景范围内相符的行走进度。

四、情绪目标

先让观众看清纸袋确实交到林手里，再随林的目光将注意力转向对面药店，最后停在保安脸上。

五、视觉风格

稳定自然天光，人物面部、纸袋和干燥路面保持自然质感，三镜光色一致。

六、分段脚本

[0—6秒｜双人中景，同侧人行道｜固定机位→交付完成后停留]

画面：林与周同时在框内，递接纸袋的双手清楚可见。周递出纸袋，林用左手接住；交付在4秒完成，周的手离开纸袋，4—6秒纸袋由林左手持有。老人从本镜开始沿同侧人行道走向公交站，稀疏车辆沿车道通行。林的内心音不驱动画内口型。

台词：林／内心音｜4—9秒｜“他还是把东西带来了。”

表达情绪：从4秒自然起句，轻轻落重音在“还是”，带着确认后的复杂感受，持续跨过6秒的切镜，于9秒完整收句，全句只说一次。

声音：稀疏车流的远近声与纸袋交付时的轻微摩擦声。

[6—12秒｜林的脸部近景，与上一镜处于同一关系轴侧｜固定机位→视线落向药店]

画面：6秒切入林的脸部，纸袋已经在他的左手，位于近景画幅外；交付动作不再起演。林看向对面药店，机位和取景保持固定。老人继续前进，只有进入当前取景范围的部分才显现，其位置承接经过时间；车流在道路上继续通行，近景无需将其全部纳入画面。

台词：林／内心音｜6—9秒｜承接上一镜已开始的同一句，9秒说完；9—12秒无台词。

表达情绪：承接起句时的语气和速度，切镜处声音不断开，不重新起句；林的嘴不随内心音做说话口型。

声音：住宅街车声连续，随实际车辆的远近自然起落。

[12—18秒｜同轴侧过肩中远景，望向对面药店门口｜焦点从林的肩侧接力→15秒落在保安脸上并停住]

画面：林的肩侧留在近前景，对面药店门口及保安进入中远景。机位保持，12秒从近处林的肩侧开始转移焦点，12—15秒对面保安逐渐清晰；15秒焦点准确落在保安脸上，15—18秒保持。林左手仍持纸袋。稀疏车辆沿道路通行；老人只在当前可见范围内继续走向公交站，位置与此前累计行走时间一致。稳定天光延续到结束。

台词：无。

声音：保留同一条住宅街持续的车流环境声。

# quiet_local_revision
