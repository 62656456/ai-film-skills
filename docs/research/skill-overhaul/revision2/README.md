## 用户纠正与本轮结果

用户明确：创意镜头环节是给用户提供思路，不是自动生成；整体技能还需要实际修理。此前“创意试拍必须生成视频、等待平台入口”的路线已撤销，不再是当前待办，用户无需补视频账号或密钥。

本轮逐包读完21个入口并展开相关引用，修复8个包的26个运行文件；连同合同源、双语指南、工作流与构建工具，较本轮修改前备份共80个仓库文件新增或改变。其他13包经过入口审计与全仓检查，本轮未发现需要新增修复的确定问题；不宣称每个引用都完成全文语义审计或21包均已实战通过。

- 创意镜头：在导演/分镜主方案旁交独立的画面思路、作用、前后衔接与取舍；不限于转场，用户例子不变成固定动作；未采用不并入主稿，采用也不自动授权生成。
- 阶段交接：思路、可读分镜、生成提示词、实际媒体分开。“测试”“看成果”“继续”沿用上下文，不能单独升级到生成。已有导演决定直接继承，局部问题只补缺口。
- 资产与短剧：取消无条件附加交互图和生成关键帧，文字任务仍交文字；保留三视图加中景、静态资产、状态与接触等原合同。
- 时间与摄影：不强制镜数，不把“不能机械等分”变成“必须不等长”；固定镜头不强填运动字段，用户锁定的合理等长保持。
- 制作与白模：仅在明确需要实际视频或预演时进入；实际单镜测试不被扩为全片；创意思路不等待平台、额度或凭证。
- 文档与打包：修复导演自包含分镜能力被说明错误否认的问题；修复版本和部署状态投影；工作流明确生成条件。新构建器固定A/B共享核心、许可证与独立引用，拒绝覆盖已有包，默认关闭Jev网络调用。
