# 创意镜头设计与试拍方案 v0.1

状态：隔离研究与测试候选。用户要求形成方案、研究、据此测试并观看最后成果。正式Skill、当前默认5.6.5、A/B冻结包及已选融合分镜保持原样。创意产物不进入正式时间线，只有用户另行明确采用具体片段才处理局部替换。

## 目标与最低完成证据

把导演的创意判断接到真实制作：有观看目的、有可执行拍法、有可播放素材、有前后镜头对照，有明确的保留或返工决定。最终成果应是两条可播放试片与一次对照观看，而不是提示词、分镜图或把静图推拉拼成MP4。

当前以《修表铺外》融合候选为测试基线，用户已选定的“直接看灰衣男子本人走进巷口”不在试验修改范围。测试片段取全片8.5—18.5秒，只改变其中10—15秒的发现镜头。

## 研究形成的设计判断

1. 创意转场可以依赖构图、动作或声音的关系，不等同于添加炫目的过渡效果。前后镜头需要预先设计承接点。
   - Adobe：[Match cuts](https://www.adobe.com/in/creativecloud/video/discover/match-cut.html)。
   - Chen等：[Match Cutting: Finding Cuts with Smooth Visual Transitions](https://arxiv.org/abs/2210.05766)，研究将相似构图和动作的候选查找，与剪辑者最终选择分开。
2. 同一个镜头内也能产生创意：景深和焦点可以改变观众先看谁、何时得到信息。本次选择这种机制，避免为了模仿关车门转场而给当前剧情强塞关门、路人挡镜或时间跳跃。
   - Adobe：[Cinematography](https://www.adobe.com/creativecloud/video/production/cinematography.html)，将rack focus列为引导注意和揭示信息的方法。
   - Adobe：[Focus pull](https://helpx.adobe.com/in_hi/premiere-pro/how-to/focus-pull-effect.html)。本次借其注意力机制，不用对静态图加模糊冒充人物动态试拍。
3. AI研究中的连续结构与运动匹配可以提供设计启发，但论文效果不等于本机服务支持或本项目已验证。
   - Pardo等：[MatchDiffusion](https://arxiv.org/abs/2411.18677)。本轮不安装研究模型，不把该算法作为已接入能力。
4. 《飞驰人生3》关门转场仅作用户提供的创意机制例子。本轮检索定位到发行方片段条目，未在当前可控播放环境逐帧观看，不能声称完成其原镜头复刻研究。

## 接入位置与职责

- 导演层：指出具体创意机会和观看作用；没有作用就不增加试拍任务。
- 分镜层：在原方案旁写独立候选，固定所替换的镜头范围、入出状态、动作、焦点或剪辑承接。
- 制作层：复用已有资产和可用前后镜头，真实生成候选；普通咨询不因这个模块自动发起生成。
- 对照与观看：原方案和创意方案使用相同前后接段、台词、声音、时长和画幅；各自正常速度播放。
- 用户决定：明确采用才替换点名片段；待修改继续留在候选，暂不采用不自动等于淘汰。

这是一条按需试拍流程，不是每镜额外生成多版。先验证当前最有价值的一处；后续数量按故事和已授权投入决定。主方案交付不以创意探索完成为前提。

## 本轮试拍01

创意：同框焦点接力。真实的林在近处，灰衣男子的倒影在玻璃中；两者位置始终不变。先看清林的发现和停顿，再将焦点交给灰衣倒影，让观众意识到失焦背景里一直有人盯着他们。

基线：融合稿的手停后向上仰摇，同时移焦揭示倒影。

比较问题：同框关系是否比逐步仰摇寻找，更清楚地把“发现者”和“威胁”联系起来？同时记录损失：林真实侧脸是否挤压倒影尺度，是否让“从玻璃发现”反而不清楚。

不使用A/B命名，避免和技能版本混淆。文件标为“主方案对照”和“创意试拍01”。

## 制作与返工边界

1. 先通过静态机位检查：实人和倒影不重叠，窗框与巷口可辨，灰衣人不能看起来站在店内。
2. 先生成共享前接和共享后接，再分别生成两段5秒发现镜头；若平台最小时长较长，保留剪辑余量再裁切。
3. 完成两条各10秒剪辑，对两条复用完全相同的前后动态素材及音轨；不让表演差异替代拍法比较。
4. 首轮各生成一个候选，发现明确劝退点时只重做该镜头；新增收费任务遵守实际平台的费用确认要求，不默认无限重抽。
5. 正常速度完整观看后，再检查焦点变化、脸/手/袋子、倒影、背景进度、声音与切点；抽帧只能辅助定位。
6. Jev可复核文字要求与已标注观察；不把主模型写出的计划当成已经发生的画面，也不给“电影感”作自动终审。
7. 失败保留基线；合格内部结果仍等用户确认，不升级技能或改默认。

## 本轮准备测试结果
