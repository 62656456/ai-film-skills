## 什么时候能升正式

只有你实际测试后，明确认可对应版本通过，助手才记录用户通过结论、真实来源、候选对象和冻结包SHA。以下均不算通过：内部测试通过、模型自评、Jev高分、选择A/B、要求开始、先试用、暂时没继续反馈。

正式切换入口读取项目唯一 `PROJECT_STATE.json` 中该候选的用户测试结论，并核对冻结包哈希。没有明确通过、版本不符或包被改动，就拒绝切换。一次明确通过可以按你认可的范围升正式；不额外要求凑三次测试。“长期实战稳定”与正式准入分开。

通过后再统一相应正式源、安装入口与批准范围内的分发文件，并回读检查。已有备份继续保留，正式版后续出现问题仍可退回。公开上传和发布遵循已有单独授权边界，不因测试通过自动外发。
