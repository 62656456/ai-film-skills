原白模 15 秒、24fps、360 帧、6 镜。实际生成时误选了约 30 秒，创作者要求保留完整结果；原生成片与 v2 都保留 721 个视频帧，视频轨为 30.041667 秒，容器约 30.048 秒，后者包含音频尾部。

目标第 300 至 656 帧（从 0 开始，左闭右开区间 `[300,657)`）没有对应白模，约为 **12.5—27.375 秒**。对照下半画面保持上一参考帧并显示未覆盖说明。这段不是白模成功控制生成的证据。其余镜头按实际切点匹配，局部差异在 [mapping.json](mapping.json)中逐段列明。

创作者这次反馈镜头控制有效、更稳，但 LibTV 中 15 秒参考生成约 900 积分、480P，成本较高。这是未经现行官方价格核对的个人体验；本条生成结果又来自误选约 30 秒，不能直接拿积分除以时长推算统一每秒成本。当前没有相同时长的控制实验或多次重复，也不能称严格 A/B。

v2 加入中文公共库音色解说、目录配乐及字幕；实际连续试听和用户最终听感／审美接受未获确认。只分发合成视频作案例复核，不单独分发音色、配乐或声音目录，见 [媒体许可范围](../MEDIA_LICENSE.md)。

重建对照时应保持生成片完整帧序，显式标明未覆盖区间，不能用循环或整体慢放制造对应关系。可复用实现参见上游 [build_comparison.py](https://github.com/62656456/ai-visual-previs-lab/blob/main/scripts/build_comparison.py)；它重建基础映射，不复刻 v2 的第三方配音配乐。
