# 类型视觉执行合同

本文件保留摄影、动作、材质、连续性、声音和结构化交接的完整方法。按本次媒介使用相应部分；静态图没有视频时间线，参数查询和局部修订不运行整套生产流程。类型专属色表、场景和风险见本包 `genre-presets.md`。

## 输入与交付

从现有材料确定对象、观看目的、成像方式、锁定事实和本轮变化。只澄清会改变结果且无法合理判断的缺口；没有资产编号、平台或视频时长不阻断普通静态方案。已有资产合同只取适用锁定项，不要求先新建台账。

用户要视觉方案就交方案，要提示词就交可复制正文，要求诊断就给问题位置和可见依据。分镜沿用已定设计与格式；类型参数不改剧本、台词、镜数、动作结果或摄影路径。视频提示词只在点名提示词或已授权生成阶段编译，不把下游用途提前变成本轮交付。

## 十类信息覆盖

下表是内部适用性检查，不是十个外显标题，也不要求每次填满。只写当前媒介中能影响画面或执行的内容，用户已有合法格式优先。

| 信息 | 有关时需要明确 | 不必补的情况 |
|---|---|---|
| 画幅与时间 | 画幅；视频总时长、切点和已核实的帧率要求 | 静态图不写时长、帧率或切镜 |
| 主体与空间 | 自然名称、身份、位置、尺度、关系与必要地标 | 不为填表增加角色、物件或三层布景 |
| 行动 | 当前进度、触发、路径、接触/落空、反应与结果 | 有意静止不强塞微动作 |
| 摄影 | 景别、视点、机位、光学和焦点；视频的中心路径、朝向、速度与落点 | 静态图只写此刻取景；固定机位不添运动 |
| 光影色彩 | 光源、方向、遮挡/反射、明暗和色彩分工 | 无依据时不补精确色温、光比或百分比 |
| 材质物理 | 可见表面、尺度、受光、接触、重量和惯性 | 不要求所有物体都有磨损、纹理和变形 |
| 情绪关系 | 注意力、人物目的、表演与关系变化 | 不把情绪词自动映射到某焦段或颜色 |
| 终点衔接 | 当前尾态及下一段实际需要继承的事实 | 独立静帧不补下一镜入口 |
| 声音台词 | 声源、进入退出、原句、说话人及可说完的时间窗 | 静态图不补声音；无声设计保留 |
| 必要限制 | 已锁定项及本段真实风险 | 不生成无关否定清单或重复全套负向 |

## 摄影与空间

先固定世界地标、人物朝向、通道、道具与光源，再从当前摄影机推导画面左右、纵深、遮挡和受光。换机位不会移动房间；不可把某一画面的左/右固定成世界坐标。关键细节需要足够画面尺度、清晰平面和辨认时间。

关系戏可比较同框、过肩、近景或其他有目的的视点；空间建立按地理与信息需要选择远近；信息变化把注意力落在实际载体。景别、焦段、距离、纵深、遮挡和焦点共同判断，预设焦段只作起点。

视频按行动和观看目的选择固定、单项或复合运镜。复合运动写清起始构图、画内触发、分阶段中心路径与朝向、焦点/遮挡接力、速度和终点；摄影机位移与摇摄分清。切镜有明确切点；连续长镜没有隐藏硬切。类型不限制运动数量，也不规定最低镜数或默认慢速。

## 时间、动作与道具

时间来自说话、察觉、接触、施力、位移、结果和反应的需要；`建立焦点 → 发生变化 → 完成 → 反应或尾态`只是可选因果顺序，不固定8秒或四段。无法在已锁时长中容纳时指出具体冲突，不靠吞词、加速、擅拆镜或改结果过关。

- 对话人物：从目的和刺激判断视线、呼吸、倾听、停顿、手部或重心变化。吞咽、摩擦衣角不是每场必做；不抢台词，不无故改站位。
- 移动和战斗：支撑、重心、接触与发力方向相连，衣料和武器按惯性回应；快速动作仍有清楚起点、路径、结果。失重中以接触、推力和约束解释运动。
- 道具：追踪初始持有人、可见面、朝向，经过有因果的变化到最终状态。允许剧情需要的多次变化，每次都可追溯；不能无故换手、增殖或穿模。
- 后段承接当前进度，已完成动作不重新发生；持续动作从现有状态继续。人物换位或越轴需要可读交接，不能为守检查而强改已锁拍法。

## 材质、受力与光

选关键表面写清可见特性及交互：金属的粗糙度/拉丝与反射，布料的织纹和受力褶皱，地面的湿度与接触阴影，纸张的厚薄和有限弯曲，灯管/招牌的局部染色。高光由光源、视点与表面共同决定；变化必须符合当前材质。

磨损、积尘、冷凝、雾与湿面由环境和使用经历决定；新物、真实塑料、二维或三维风格按用户选择保留。光可在画外，有位置、遮挡和反射依据；魔法/超自然光遵守作品规则。接触压力、阴影、形变或位移按对象需要表现，不要求刚体也明显变形。

## 连续性与声音

需要跨镜时保存最少的必要尾态：人物位置/朝向、道具持有与状态、地标、光源方向及延续声音。提示词用自然名称，不用内部编号、版本或路径代替可见信息。

台词原句与画面说明分开，点名说话人、起止和必要情绪说法；只估计时可用“字数÷语速＋停顿”，再留动作与呼吸余量。慢/克制2.5–3.2字/秒、自然3.5–4.2字/秒、急促4.5–5.5字/秒仅作起草参照，不能当实测。同期或后期配音依本次方案；字幕/画内文字由用户需求决定。

环境音来自实际声源：室内可用布料、餐具、钟表或房间底噪；城市可用交通、雨、排水或脚步；设备空间可用通风、机械、继电器或回声；荒野可用风、植被、生物和装备。只选当前存在且有叙事作用的声音；真空不直接传环境声。

## 按实际问题检查

一次检查覆盖本次涉及的光源与受光、主体分离、景别/焦点、空间与轴线、色彩功能、人物/道具状态、材质受力、时间/台词和范围守恒。只有真实失败项才修，不为不适用项补“无”或增加报告。具体问题可查本包 `NEGATIVE-CASE-BOOK.md`。

负向按需要从通用结构错误、类型专属风险、当前成像方式的失误中选；已经用正向说清且没有新增作用的否定句省略。修正后只重查受影响项；未解决的冲突明确说明。文本自洽、实际像素/运动检查、用户接受分别报告；`ready_for_prompt`只表示适用文本条件满足。

## 平台与结构化接口

未知平台用清楚的通用描述。平台限制确实影响本次决定时，核对当前工具或官方资料，再适配语法、参考素材或生成单元；不沿用“某平台必须十段式”“一段只能一个动作”等未经核实的定律。保留已给seed/reference等复现信息，但不虚构支持参数或生成成功。

需要机器交接时保留以下接口；普通文字交付不另附四份数据块：

| 接口 | 内容 |
|---|---|
| `style_module` | 当前类型包名字符串，保持已有调用方类型 |
| `style_route` | 保留 `camera/color/scene/action/material/continuity` 键；按实际采用的规则填值 |
| `style_source` / `style_status` | 预设来源说明；默认状态 `bundled_design_preset_not_externally_validated` |
| `qc_contract` | 保留 `checklist` / `negative_layers` 的适用检查与限制引用 |
| `asset_contract` | 仅已有或确需建立的身份、版本、批准状态与锁定项 |
| `qc_checklist` / `negative_layers` | 当前适用检查、实际失败和必要限制 |

结构化记录保留来源状态；未选预设不写成锁定。不读取兄弟Skill或私人知识库，本包文件独立够用。
