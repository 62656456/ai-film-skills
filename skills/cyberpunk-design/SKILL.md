# 赛博朋克类型视觉设计预设

从当前人物、行动、关系或空间信息决定类型如何帮助表达。保留既有的镜头、色彩、空间、动作、材质与声音能力；色表和场景例按需要采用，不覆盖用户的故事、资产、成像方式或已锁摄影。

| 新画面、整体视觉改写或整体图像诊断 | 读 [画面关系判断](references/cinematic-image-direction.md)；需要类型备选时读 [视觉预设库](references/genre-presets.md) |

## 先确定画面，再选择类型手法

从现有输入确定本轮媒介、观看目的、主体/环境关系、成像方式、允许变化和用户锁定项。缺口只有实质改变结果且无法合理推导时才问；已给剧本按实际覆盖的正文理解人物目的与当前状态，不能仅凭类型词补剧情。

- 摄影、构图、光色、材质共同服务观看顺序。固定或复合运镜按行动选择，不把“宏大”“压迫”“浪漫”等词机械换成固定焦段、配色、慢推或航拍。
- 静态画面只容纳同一时刻可共存的信息。视频再处理时间、触发、路径、声音与尾态；分镜请求交镜头设计，提示词请求才编译生成正文。
- 局部修订保留未涉及的人物、外观、数量、动作结果、台词、镜序与摄影；参考图只承担用户指定职责，不自动改变故事或成像方式。
- 光源可在画外，位置与受光可解释；世界规则允许的超自然光有其依据。新物、真实塑料、动画或插画均按目标处理，不强制磨损、雾、湿面或摄影写实。
- 数值用于已给约束、明确设计选择或真实执行需要；没有依据时描述可见关系，不编造色温、暗部占比或成功率。

## 直接交付与接口

只交本次需要的视觉方案、可复制提示词、参数或有依据的诊断。正文使用人物、场景、道具自然名称；单图不扩成系列，静帧不附视频时间线，普通结果不附资产台账、十段填表和全套自检。明确要分镜与提示词时分别交付同一设计，已有格式优先。

需要结构化交接时保留 `style_module` 与 `style_route`：前者保留当前包名字符串，后者保留 `camera/color/scene/action/material/continuity` 键，填本次选定的规则与参数。`asset_contract`、`qc_checklist`、`negative_layers` 仅在交接需要时提供；具体字段见执行合同。现有下游键名和用户已用接口不擅改，来源状态保留为设计预设、未外部验证。

交付前只检查当前适用的范围守恒、观看关系、空间/光源、动作与素材衔接；发现问题修具体内容后重查影响项。需要生成时沿用宿主实际可调用的工具与当前授权；提示词完成、真实生成、图像/视频检查和用户接受分别报告，不以内部检查冒充成片通过。
