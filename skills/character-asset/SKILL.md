# 人物资产参考图生成预设

> 当前包已经包含全部运行规则、参数依据和质量门；不使用未经用户确认的人脸或生物特征。

## 0. 加载规则与映射表

确认资产设计任务 → 通读已提供剧本并建立设计依据 → 选择交付与成像模式 → 读本包画面关系判断 → 提取第1节字段 → 按第2节一致性锁定 → 第3–5节补足材质/光影/几何 → 选择平台和第7节适用模板 → 按当前交付阶段执行第8节检查与第9节负向 → 输出资产合同。资产编号：C01–C99，已确认编号不得复用。

| 节 | 独立输出 | 用途 |
|---|---|---|
| 1–5 | 资产描述、锁定规则 | 确定外观与状态 |
| 6–7 | 平台任务与提示词字段 | 直接生成参考图 |
| 8–9 | 验收和防崩 | 独立质量检查 |
| 10 | JSON 合同 | 供后续制作直接读取 |
| 11 | 类型适配字段 | 注入成片提示词的对应段落 |

### 剧本先行与设计依据

用户提供剧本时，第一步先通读所提供的完整正文，理解故事气质、时代与世界规则、人物身份和关系、剧情因果及时间线，再回到资产出现的场次设计外观、空间或状态。长剧本可分段读完并保留简短连续性记录，不能只搜资产名或读摘要就声称通读；只有片段时说明实际阅读范围，未给剧本时依据当前描述设计，不虚构已读全本。

内部保留简短设计依据：正文来源与阅读范围、相关场次、故事风格与成像方式、已确认事实、设计推定、关键未知。设计要能解释“为什么这个资产在此时此地是这个样子”；后文信息可帮助理解时代、身份与伏笔，但不能把后续损坏、受伤、天气或揭示结果提前带入当前场次。

用户与当前项目已经明确的画风优先；未指定成像方式时默认摄影写实，以可信结构、材质和光影呈现。悬疑、喜剧、奇幻等故事类型不自动等于某种画风。未提供细节或参考图时，从剧本与用途主动提出合理设计；影响剧情、身份、既有锁定事实的关键未知才需确认。一般颜色、材料、陈设、维护与使用细节可作有依据的设计推定，不一律退回待确认；推定不能冒充原文或用户已确认事实。

### 交付与成像模式

按用户点名的媒介选择；建立或重设计人物资产时，三视图加中景是最低完整交付：

- **提示词/设计说明**：交付当前请求的完整提示词、必要锁定信息与资产合同；尚未生成的参考图用空列表并标为计划，不填写虚构图片路径或声称图片通过。
- **实际参考图**：用户要求出图且有可用能力时生成所需图片；人物资产须包含第2节的三视图加中景。只要一张图时交一张四视图角色表，不能因此删成单个角度。实际看图后记录检查结果，用户批准前保持 pending_review。
- **诊断/局部修改**：围绕给定图或提示词指出可见问题、原因假设和对应修正；保留未点名的身份、风格与状态，不默认重做整套资产。

依第0节确定成像方式（无指定时默认摄影写实），再按本包 [电影画面关系判断](references/cinematic-image-direction.md) 设计画面关系与负向。此参考在设计、改写、诊断时读取；编号/文件查询不必加载。人物资产的四项视图按第2节固定，布光与材质表达服务于所选画风和清晰可读；普通肖像、表情特写或已给图片的局部修正按点名范围处理，不冒称已交完整人物资产。

## 1. 描述维度表

必填维度：年龄、性别、国籍/种族、体型、脸型/眉眼鼻唇/伤疤、发型、服装层次、配饰、气质标签、特殊标记；同时说明身份职业、生活经历与当前处境怎样影响体态、衣着、面部及使用痕迹。未明确的国籍、族群或伤疤不得仅为填表而杜撰，也不默认所有人物都是年轻、俊美的精修模特。

规则：按第0节区分剧本事实、设计推定与关键未知；只把用户或剧本已确认的维度写入 locked_features，待审设计不冒充已锁定。描述按从整体到局部、从外观到材质、从静态到状态组织，并对应当前剧情节点。

## 2. 一致性/状态规则

人物资产必须三视图加中景：正面全身、精确90度侧面全身、背面全身，以及头部至腰部附近的中景。三面全身完整保留头顶、足部与轮廓，使用可比较的尺度与自然站姿；中景清楚展示面部、神态和上身服装。四项须在任务说明、实际生成输入和验收中同时成立；一张四格或分别四张都可承载，不将文件数量混同视图数量。

四个视图保持同一人物、年龄、脸型、发际线、体型、服装、配饰、特殊标记与剧情状态；身体左右标记不随换面镜像。脸部近景、表情、俯视和交互图只作必要补充，不能替代中景或任一全身视图。非人类角色仍交正面、侧面、背面全貌与相应中景，保留其物种结构，不强改为人形。

变体规则：服装、受伤、昼夜、损坏等变化使用原编号后缀（如 C01b）并记录变化原因；不得悄然覆盖已审核版本。参考图一经通过资产审门，后续视频只可引用，不能重新发明外观。

## 3. 材质细化库

皮肤毛孔与微油光、独立发丝走向、布料经纬纹/缝线/压褶、金属氧化/拉丝、皮革毛孔与磨损。

粗词禁止：高级材质、精致金属、真实皮肤、电影级纹理。每项必须改写为表面结构、磨损、反射、接触或微动态。材质与光源、接触点、重力方向一致。

## 4. 光影规则

正面柔主光、弱轮廓光、背景分离；避免无来源美颜泛光。

标准资产图优先可读性而非情绪滤镜：主体与背景分离、关键细节不被死黑吞没、反射不遮挡结构；风格色彩作为可切换层，不能改变资产真实颜色记录。

## 5. 比例、透视与物理规则

全身比例、头身关系、双肩/双眼对称、手指数量与关节、无透视拉伸。

禁止：结构断裂、无承重关系、穿模、悬浮、镜像/重复零件、透视与光影方向相互冲突。涉及手持、穿戴、打开或碰撞时，另交付一张交互校验图。

## 6. 平台适配

| 平台 | 输出重点 | 保留字段 |
|---|---|---|
| Midjourney | 英文主体、视角、镜头、材质、背景隔离 | aspect ratio / reference / version |
| 即梦 | 中文分段：主体—细节—状态—背景—光影—约束 | 资产编号与禁止项 |
| 可灵 | 图生视频前的多角度、材质、动作锚 | reference image / 状态起点 |
| Stable Diffusion | 英文正向/负向与可复现参数 | seed / model / reference / negative |

任何平台都不得改变 locked_features；平台版本能力未知时标记 unverified，不作为硬约束。

## 7. 资产提示词模板

适用模板：成年男性、成年女性、儿童、老年、非人类。

~~~
[人物自然名称]，[剧情身份、当前状态与用途]，[全维度描述]，
[正面全身+90度侧面全身+背面全身+头部至腰部中景]，[真实材质和磨损]，
[标准布光和背景分离]，[比例/透视/物理规则]，
[目标平台参数]，[三层负向]。
~~~

建立人物资产时，下列各模板均须落实三视图加中景；用户只要提示词就交完整四视图提示词，不自动出图。普通肖像或局部改图保留范围。用户可复制的正文用人物自然名称，资产编号只留后台绑定与合同；不把视频动作或台词写入静态资产提示词。

## 8. 质量检查清单

- [ ] 编号、版本、名称和用途唯一
- [ ] 已通读提供的正文，阅读范围、相关场次与设计依据可核对；没有只凭名称套模板
- [ ] 第1节维度已区分事实、合理设计推定与关键待确认；当前状态符合剧情时间线
- [ ] 涉及女性魅力设计时，气质已落到可见神态、体态或造型关系；案例中的肤色、脸型、服饰与单镜表情未被写成所有女性的默认或永久身份
- [ ] 成像方式符合用户要求，无指定时采用摄影写实
- [ ] 人物资产三面均为全身且侧面为90度，中景为头部至腰部；无胸像、俯视或细节替代
- [ ] 四视图人物、年龄、比例、服装及左右标记一致；非人类视图保持原物种结构
- [ ] 锁定特征跨视角一致
- [ ] 主体比例/透视/结构正确
- [ ] 材质可见且符合光源
- [ ] 接触、重量和阴影可信
- [ ] 关键面、朝向、开口/接口可辨
- [ ] 无多余肢体、物件、文字或水印
- [ ] 背景不抢主体且能辅助尺度
- [ ] JSON 合同可被下游解析

按交付阶段检查：提示词只验证设计与合同，未生成/未见图片的像素项目标 not_evaluated；实际图片的适用项目失败时为 rework。只有实际参考图通过用户审阅才进入 assets_approved，文本通过不替代看图。

## 9. 负向提示词

第一层（通用）：畸形、扭曲、多余肢体、错误手指、穿模、粘连、漂浮、重复元素、乱码、水印、低清、闪烁。  
第二层（character）：与选定成像方式不符的皮肤/头发/服装材质、非设计的面部镜像、抢夺主体的背景、超出人数要求的人物；玩具、黏土或动画角色按用户锁定保留其材质与造型。\
第三层（画质）：先按用户成像方式选择。摄影写实排除不符合目标的卡通化、蜡皮、合成渲染感；三维动画、二维动画/插画保留选定风格，排除结构错误、风格漂移或意外写实化。各模式按需要限制低清、遮蔽结构的过曝/欠曝、过度锐化；不一律禁止动画、卡通或真实塑料材质。

十条通用反面案例与三层负向写法详见 `references/NEGATIVE-CASE-BOOK.md`；本节的专属负向与之叠加，不可互相替代。

  "required_views": ["front_full_body", "side_90_full_body", "back_full_body", "medium_head_to_waist"],
  "view_coverage": [],
  "locked_features": {},
  "design_basis": {"script_sources": [], "reading_scope": "", "scene_context": "", "story_style": "", "imaging_style": "", "facts": [], "design_assumptions": [], "critical_unknowns": []},
  "material_keywords": [],

required_views 是完整人物资产的最低视图合同；view_coverage 仅在实际看图后记录每项对应的文件及格位，未生成时保持空列表。普通肖像或局部修订注明局部范围，不假报四项已完成。

本 Skill 自己完成资产审核字段、编号登记、参考输入说明和对照复核要求；后续制作只读取本 Skill 已交付的资产合同，不得重写锁定特征。

## 11. 类型适配字段

将人物压缩描述和参考图直接写入视频第②/⑥段或等价的主体与材质字段。

流程：资产生成 → 人审 assets_approved → 本地类型适配 → 10段式拼装 → 每镜引用资产编号 → 当前 Skill 的QC字段对照资产原图、实际尾帧和状态合同。若未获人审，不得进入正式镜头制作。
