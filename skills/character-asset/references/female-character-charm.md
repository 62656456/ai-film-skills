# 女性角色魅力与肖像表达

用于女性角色的美感、气质、吸引力设计与肖像诊断；随人物资产包独立使用。只有文字参考时做文字推导，未看原图或未生成图片就不声称视觉效果已验证。本参考不是所有女性的统一审美模板。

## 从人物到可见吸引力

先区分本次要的是完整角色资产、单张肖像，还是对既有设计的局部修改。已有身份、年龄、体型、肤色、服装及画风优先；魅力设计不能擅自年轻化、美白、瘦身或换脸。有剧本先按入口通读正文；无剧本依据用户给出的气质设计，不编造人物经历来证明美感。

在内部确定一句具体意图：这个人物希望给人什么感受，什么可见关系让这种感受成立。把主要气质落到少量有效选择，允许相容的反差，不强求每个人都柔和、安静、清冷或取悦镜头。

| 设计维度 | 可操作的选择 | 检查依据 |
|---|---|---|
| 视线与神态 | 视线目标、眼睑张力、眉部状态、嘴角与下颌是否放松 | “温柔、疏离、坚定”等词是否有可见支撑；不把冷淡表情等同于人物有深度 |
| 体态与重心 | 躯干朝向、头部转向、肩颈关系、承重腿、手势与持物 | 动作自然且符合身份；回眸须说明身体、头和眼睛各朝哪里 |
| 外形识别 | 脸部关系、发际线、轮廓、年龄痕迹和已给体型 | 保留此人的辨识点；不靠统一杏仁眼、白皮肤或精修脸获得魅力 |
| 造型与身份 | 衣料、剪裁、发型轮廓、饰物主次、整洁或使用痕迹 | 有助于身份与气质；装饰丰富也能成立，不将“减少装饰”变成通用答案 |
| 人物与摄影 | 观看高度、距离、明暗分离、背景信息、清晰度分配 | 眼神和表情能被读到；光线和镜头服务人物，不用器材名代替设计 |
| 生命感 | 当前姿态中的细小不对称、发丝或衣料受风状态、手与道具的接触 | 静帧是一个可信瞬间；不把连续动作、时间线或表演状态塞进永久身份锁 |

下列仅是可选方向，按人物重新推导，不是完整分类或固定配方：

- **克制温柔**：自然的视线交流、放松肩颈与轻微表情变化，可与朴素或华丽造型搭配。
- **清醒英气**：稳定重心、明确视线目标、利落轮廓和合乎用途的衣着；不靠加武器或冷脸代替身份。
- **明快灵动**：开放表情、轻松手势及有节奏的局部色彩；不把所有人变成年轻少女或夸张卖萌。
- **成熟从容**：保留年龄与生活痕迹，以沉着目光、舒展体态和有分寸的细节表达；不靠磨皮和贵重首饰代替。

“低调”应分别判断表情强度、装饰密度、色彩强度和背景复杂度。人物神态安静与服饰鲜明可以共存；用户只希望神态克制时，不自动删除已锁定花饰与鲜艳服装。

完整资产中，把可跨角度保持的外形、服装与轮廓写入设计说明，经用户确认后才进入 locked_features；中景可展示基础神态。特定回眸、逆光、风吹或凝视镜头属于肖像呈现，不成为此人物所有图像必须重复的姿态与环境。

## 案例：古风回眸、团扇与蓝天逆光

**来源边界**：2026-09-10 用户提供并要求沉淀的《东方古风人像提示词》，对话 `6aa27c2f-436c-83ee-9821-df772ff03885`。已读取完整文字；未取得原图。原文附 X 链接 `https://x.com/GrayNoteLab/status/2097626551613579756`，原帖身份、发布日期、浏览量及成图效果未经独立核验，不用作有效性证据。以下为对用户提供文本的机制提炼与设计修订建议，不是假称原作者的方法或真实摄影参数。

原案特征：成年东方女性、蓝色汉服、丰富红蓝白花饰与彩带、花瓣轮廓团扇、身体转侧后回望镜头、纯蓝天、后上方日光、掠过脸侧的发丝、9:16 半身肖像。原案是具体审美选择，不限制本参考的适用人群、时代或画幅。

可迁移的是三个画面关系：回眸与视线建立人物和观看者的交流；相对克制的神态与发丝、衣带的轻动形成静动层次；团扇与人物分居画面两侧，蓝天留白使轮廓和神态容易辨认。蓝衣、红结、团扇本身只属于本例。

| 原案待解关系 | 写入当前设计的方法 |
|---|---|
| “朴素低调”与大型蝴蝶结、多色花果、彩带和刺绣并列 | 区分“神态克制、节庆造型丰富”与“整体朴素”。前者可保留原造型；后者在允许修改时减少竞争装饰或缩小强调色面积。不能暗中改掉用户锁定的装饰 |
| “近距离轻微广角透视”与“85mm lens look”并列 | 选择一致的观看距离、画幅与透视意图。可取35–50mm等效视角表达邻近空间感，也可取85mm等效视角并退后保持半身构图；这些是设计选择。低机位与85mm本身不冲突 |
| 躯干、肩膀和回头方向含糊 | 例如写为“躯干朝画面右侧转开，肩线随躯干，头部自然回转看向镜头”；不让颈部为实现回眸发生过度扭转 |
| 强逆光又要求脸部清晰自然 | 明确太阳位于人物后上方，面部由天空散射光或反射补光照亮；保住皮肤层次，避免用过曝白边、光晕或HDR词补救 |
| f/2.0浅景深与前伸扇面、脸部同样清晰 | 先定眼神是否为第一焦点。扇子靠近面部所在深度可提高同时清晰的可行性；否则允许扇面略虚，或选择更充足景深，不承诺固定光圈必然满足全部细节 |
| 发丝掠脸、丝带向右下方飘 | 给出共同主风向，允许软硬材质、惯性及重力造成差异；发丝不遮住关键眼神，衣带不穿过身体或扇柄 |

可复用的紧凑表达骨架：

> [人物身份与已定外形]；[主要气质及眼神、嘴角、肩颈的具体表现]；[躯干、头部、视线与手的关系]；[服装轮廓、材质及饰物主次]；[符合范围的背景、机位与光线]；[一个可信的瞬间细节]；[本图真正需要保持的特征与排除的问题]。

不要把本例的天气、颜色、扇子、回眸、白皙皮肤或冷淡气质预填到新人物。肖像不强制四视图；完整人物资产则仍须保留入口的三面全身加中景。

## 判断与验收

提示词阶段，检查气质是否转成可见关系、身份是否保持、光线与视点是否一致，以及实际交付是否符合肖像或资产范围。用两个反事实帮助定位问题：暂时拿掉装饰后人物的神态与轮廓是否仍有识别度；保持外形只换视线和重心后气质是否发生预期变化。反事实用于理解装饰和表演各自的贡献，不等于要求删掉原设计。

成图后先看整体注意力、人物辨识和气质，再看表情、肩颈、手与道具、皮肤纹理、风和光的关系；具体哪里不成立就调整哪里。原案例文字已读、内部文本判断、实际生图、图像检查与用户审美接受分别记录。本例尚无真实图像验证，不能据此宣称成功率提高或此方法已实战验证。
