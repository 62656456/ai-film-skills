# 电影画面的关系判断

设计、改写或诊断画面时使用；只问编号、引用或文件位置时不加载。用户锁定的内容、成像方式与交付范围优先；本包旧色表、焦段和场景模板只是可选起点。

## 从画面命题到整体裁决

1. **先看什么，为什么看。** 从当前行动、关系或空间信息确定第一视觉落点和随后发现的信息。只采用服务这个命题的主体、背景与细节；参考图中的人物、巨构、黄金时刻或配色不自动变成新任务要求。
2. **主体怎样从背景中分开。** 联合比较主体与相邻背景的明度、色相、饱和度、轮廓和清晰程度。选择足够的分离手段即可，不必同时加轮廓光、高饱和与浅景深；暗主体衬亮背景或亮主体落在暗区域，都由注意力决定。
3. **光怎样改变物体和空间。** 确定光源方向、相对大小、遮挡与反射路径，用阴影边缘、明暗交界和高光验证。大面积光源通常产生较软阴影，反射宽窄和清晰程度还取决于粗糙度；不要让金属、皮肤、塑料和湿面共用一种亮面。光源可在画外，但位置与效果须可解释。
4. **空间怎样被读懂。** 按用途选择前中后景、遮挡、尺度参照、透视与留白。留白承担视线、运动方向或情绪关系，不设固定比例；局部资产、平面插画和近景不强塞全套纵深、小人物或宏大尺度。
5. **细节放在哪里。** 先看大形与明暗块，再组织中尺度结构，最后在焦点与可见距离允许的位置增加微细纹理。高分辨率不等于满屏同样锐利、复杂和高对比；次要区域可通过光、空气、焦点或简化降低信息强度。真实塑料、新物、发光设计与风格化笔触均按目标保留。
6. **回到整张图裁决。** 缩小看注意力和明暗关系，放大看结构、材质与接触。每种新增效果都应帮助表达；修正时指出可见问题、位置及需要改变的关系，不靠堆“电影感、8K、青橙、黄金时刻”替代判断。

## 成像与时间边界

- 先按用户意图选择摄影写实、三维动画、二维动画/插画或其他成像方式。负向排除该方式中的错误，不把动画、卡通、真实塑料、无磨损或有依据的发光本身视为劣质。
- 静态图描述最终可见的机位、构图、光影和状态；视频再按注意力变化选择固定、单项或复合运镜，说明起止、路径、速度、触发与衔接。类型不限定运动数量，也不以复杂运动证明电影感。
- 用户给图时，只将可从像素观察到的明暗、色彩、空间和材质关系作为图像证据。精确焦段、灯位尺寸、相机品牌等未经其他来源确认时，是设计推定而非原图事实。
- 提示词检查只证明设计自洽；实际图片需要看像素，实际视频需要观看运动与连续性，用户接受单独记录。

### 把参考拆成可保持和可变化的部分

在内部用简短记录明确：本张用途、借鉴机制、用户已锁定事实、允许变化、参考图各自用途。记录直接服务提示词与对图，不强制增加用户可见表格或新JSON。

- **资产事实保持**：已确认身份、服装/装备结构、固有色、空间布局、物件数量和状态不因借鉴案例而改变；未知资产事实不从案例补全。
- **视觉选择按需变化**：在用户未锁定的范围内，选择机位、占比、遮挡、负空间、明暗组织、材质表现或文字层级。每项变化都对应观看目的，不为凑数量而变化，也不凭空新增故事事件。
- **多图先辨关系**：同一场景的视觉方案、同一身份跨场景、同故事不同事件、独立故事、互不关联的主题图分别处理。固定项由该关系决定；同IP不等于同一人物，同故事不等于每张同一地点，换配色/机位不能冒充独立故事。
- **参考图分配职责**：分别说明哪张提供身份、服装、空间、构图或材质。身份参考不自动继承曝光与姿势，材质参考不自动改变几何；用户明确锁定的参考构图必须保留。
- **交付数量和媒介守恒**：人物资产建立的一张图须承载三视图加中景，不能以单图为由省略视图；普通肖像、局部修订不自动扩表或系列。纯人物/道具/空场景不强加剧情；电影画面不因参考海报而增加排字或双重曝光。二维、三维、摄影等成像方式服从当前任务。

### 让方法进入真正的生成输入

把选中的关系写成当前主体的可见描述：谁在什么位置、占据多少画面、被什么遮挡、哪种光照到哪个表面、何处留出阅读或行动空间。只保留对本张有用的项目，不把整张资料表塞进提示词。

必须保持的特征和所需参考要进入实际发送的正文或确实附带的图像；不能只写“按上文合同”“保持上一套”。提示词使用自然名称，来源编号、路径、版本与审核记录留在正文外。文字只在当前任务需要时列出准确内容、位置及层级；没有文字需求则不添加。结构化记录有助于维护，不保证比清楚的自然语言产生更好的图像；“8K”和相机名也不是实际尺寸或物理精度的证据。

### 看结果后决定是否保留

提示词阶段核对范围、保持项和关系是否真的进入最终输入；未生成的画面项目仍为未验证。实际出图后，先看整体注意力与系列共同特征，再看身份、结构、文字、接触和非目标区域是否漂移。局部修订定位问题与修改范围，保留有效部分；系列中分开核对身份/结构稳定、风格共同点和每张的必要差异。

比较方案时保持其余关键条件一致，并记录具体改变及观察结果；不把单张好图或一次内部文本测试写成成功率提升。原案例文字已读、原图已看、本次已生成、内部图像检查、用户接受分别记录。仓库展示图不自动成为本项目资产，第三方原图和人物不因收录就获得再分发或商用许可；本节仅保存方法提炼，不复制图像或安装外部Skill。
