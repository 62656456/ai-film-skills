## 周期更新规则

- 即时榜单与都市情感拥挤度：每周检查，先形成候选，不自动覆盖。
- 题材与剧情趋势：每月检查。
- 行业规模、平台财报与商业趋势：每季度检查。
- 政策和审核规则：发现变化后立即复查。
