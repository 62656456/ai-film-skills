# 版本、过期与冲突

## 更新频率

- 热榜/即时热点：每周。
- 题材/剧情趋势：每月。
- 行业规模/商业数据：每季度。
- 年度市场：每年。
- 政策/平台规则：发现变化后立即复查。

## 写入策略

1. 使用稳定 `record_id` 识别同一语义结论。
2. 新证据改变结论时创建新版本，把旧版本状态改为“已被新数据替代”并移入 D-11。
3. 到达 `review_on` 但尚未复核时标为“待复查”；超过有效期标为“已过期”。
4. 不删除旧来源、旧值、修改原因或失效原因。
5. 不同来源口径冲突时保留并列版本，状态为“存在争议”，写明冲突字段。
6. 每次写入生成回执：新增、更新、历史化、拒绝、争议、下一次复查。
