# D 语义层合同

## 分区

| 分区 | 内容 |
|---|---|
| D-00 总入口 | 职责、来源规则、更新时间、范围、调用方式 |
| D-01 当前市场总览 | 当前题材、平台变化、市场状态 |
| D-02 热门剧本类型 | 已被数据验证的题材趋势 |
| D-03 热门剧情模式 | 结构、冲突、关系、情绪价值 |
| D-04 平台差异 | 平台偏好、用户和商业模式 |
| D-05 用户与情绪需求 | 画像、需求和消费动机 |
| D-06 商业化与制作成本 | 收入、成本、投入产出、AI适配 |
| D-07 趋势与风险预警 | 增长、饱和、衰退、政策风险 |
| D-08 官方来源库 | 政府、平台、协会、财报、专业来源 |
| D-09 待验证观察 | 数据不足但值得追踪的信号 |
| D-10 项目评估记录 | 具体项目的市场评估 |
| D-11 历史版本 | 旧结论、修改和失效原因 |

## 每条记录必填

`record_id`、`target_section`、`conclusion`、`fact_type`、`source_urls`、`source_publishers`、`data_cutoff`、`data_period`、`platforms`、`regions`、`evidence_level`、`valid_until`、`review_on`、`status`、`version`、`limitations`、`follow_up_metrics`。

`status` 只允许：有效、待复查、已过期、已被新数据替代、证据不足、存在争议。

`fact_type` 只允许：官方公开事实、平台官方解释、权威第三方数据、行业案例、数据推断、尚未验证的市场观察。

证据 D 必须写入 D-09。具体项目评估写入 D-10。来源条目写入 D-08，其他内容按主题分区。
