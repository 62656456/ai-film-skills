# 从剧情到观众经历

用于新设计或重设计尚未锁定的拍法。普通场景以本文件完成决定；特殊摄影查 `cinematography-design-engine.md`，复杂投影与轴线查 `framing-and-axis.md`。不以参考库数量代替设计，不重复已有导演方案。

## 1. 先找到这场戏的变化

完整读当前片段及必要前后文，确定谁为达成什么而行动、遇到什么阻力、怎样回应、最后什么变了。区分原文事实、用户锁定项和可设计部分。心理需转为有依据的可见表演；不凭空新增剧情来证明情绪。

观众体验必须能改变拍法：观众比人物先知道、同步发现、还是暂时落后？观众从哪里进入这段经历，接近谁，何时等待或转移，结束时多了什么理解、压力或释放？这些决定留在画面与声音中，不额外生成问卷。

若只是从逐句台词配一个近景，先回到人物行动和关系。若已有方案只欠表达，沿用它，不重新开展探索。

## 2. 排演人物与正在运行的场所

建立足够用的空间：门窗、通道、固定地标、人物与目标、持物、实际光源。简单空间用清楚的相对关系即可；坐标、图纸和白模只在需要解开真实几何问题时使用。

已有场景交付数据直接接收布局、视觉设计、环境基线和拍摄条件；可用 `spatial_contract`、`visual_design`、`environment_baseline`、`filming_conditions` 与 `reference_roles`，缺少这些字段时从现行文字和实际图片提取，不要求用户补表。继承已定场景大形、光色与材质响应，分镜负责选择观看位置和随时间的变化，不为运镜另造装修。

人物通过接近、回避、控制出口、让位、遮挡、交付、停住或拒绝改变关系。先确定这些行为如何发生，再安排摄影机观察；不能只写情绪词和运镜名。

当前行动含近身交锋或争夺中的攻防时，主动读 `fight-design.md`，先形成相互应答与后果，再选镜头。排演起点、关键接触和退出时，把人物身体、展开动作、落地道具、障碍与摄影机放进同一空间；核对谁占路、谁先让开、机位能否抵达及退出。对可拍性有影响的狭窄通道、高差和门槛，按 `framing-and-axis.md` 检查，不以“无遮挡”“空间连续”代替依据。

**环境也有当前状态。** 根据地点用途、时段与已知天气，判断主体表演期间场所怎样继续运行。开放项可作合理设计并在必要时简短标为假设，不每次向用户询问风、人、车是否存在。已定空街不能加人，晴日不改雨夜。

- 重要背景对象明确目的、路径和持续过程；切镜后从当前进度继续，出框不等于消失。远处匿名人群只需流向、密度和节奏，不逐人建账。
- 风、雨、机器等只有在适用时才加入，并作用于实际物体；受遮挡和材质差异影响，不让所有物体同步摆动。
- 光变化来自车灯、遮蔽、开门等真实关系；车辆经过不一定照到脸。反打不会移动世界光源。
- 环境声有来源、远近与遮挡；进入室内后声场改变。不为制造悬念临时补剧情性敲门或脚步。
- 安静、无风、稳定光照和有意停住都成立。环境检查用来发现无意冻结，不要求每镜至少一个动点，也不要求空气里有颗粒。
- 关键脸部、手部或证据需要辨认时，背景活动不抢走注意；已设计的遮挡或干扰则保留其显露时机。

按 `reference-design-and-handoff.md` 区分参考职责：普通美术/空间图指导外观、布局和光色，只按现行决定锁定已定项，不自动锁全段机位或冻结视频人车；明确首帧、末帧分别约束指定的起终画框；风格参考只提供已采用的视觉属性。

拟定路径时核对参考是否为目标机位，已知空间是否存在可走通路，以及改变高度、朝向或位置后遮挡怎样解除、关键对象何时真正可见；移焦不能让实板后的证据露出。单张图未见区域不当作已知连续空间。锁定空间只调整获准的摄影，不为圆运镜搬桌、搬墙或新增出口。未批准资产与未见区域可形成边界明确的候选文字，不阻塞可独立完成的设计，也不默认生成额外视角或首尾帧。

## 3. 组织整段观看

从信息、表演和空间关系决定连续长镜、切分或混合结构。每次切镜带来观看距离、视点、反应、省略或节奏变化；不切可以保留同时发生的关系、等待压力和完整行动。没有最低镜数、固定秒数或远中近阶梯。

对会显著影响表达且尚未锁定的选择，比较不同观看方式。可以改变信息先后、主体关系、空间投影、镜内接力或剪辑结构；不是把缓推替换成环绕。普通中景、固定构图能否完成任务？如果换掉所选拍法，会失去哪项可见证据、身体感或关系？比较聚焦关键选择，不逐镜强做两套完整方案。

叙事成立后继续判断摄影完成度：起点、关键变化和终点各自怎样组织人物尺度、空间层次、空区与明暗重量，合在一起留下怎样的画面印象？“动作看得清、移动有理由”只完成叙事判断。明确要求院线/好莱坞质感时，按本场题材选择具体摄影方向，并读 `cinematography-design-engine.md` 联合排演画框、运动与光色。已获认可的情绪和动作保持，不能用加戏换取摄影差异。

大胆摄影是实际选项：距离突变、低位穿行、升起揭示、远距观察、特殊焦点、静动反差和速度变化都可能有效。不能因避免炫技而只剩固定中景；也不能用复杂程度证明价值。

用户要创意镜头思路，或主方案旁存在值得单独提出的开放选择时，按 `creative-shot-ideas.md` 把少量备选及取舍交给用户。主方案仍完整交付；备选未被采用前不混入镜序，也不触发实际生成。

导演意图简短落到一个可观察结果，例如同时看见邀请的手和未被占用的空椅。摄影机可以跟随、领先、等待、拒绝跟随或离开主体去揭示另一信息。空间中的独立行动不能为了同框挤到错误房间或门口。

重要开放摄影先完成画框与观察距离比较，再选择运动。保持相同剧情动作、对白、空间、时间及媒介，具体排出起点、关键变化和终点：需读清哪个部位、动作或空间关系，它在框内多大，什么占主画面，哪些暂不显露。人物始终腰上中景、物件始终小在手里，不能仅凭“从细节展开全貌”宣布尺度变化；宽景足以表达时可全段保留，不强制局部开场、渐次拉远或移焦。

比较须改变实际先后/同时信息，或同一关系的观察尺度与透视。两个方案全程同尺中景，只换前领、后随或左右侧，且可读信息与显露时机不变，仍是同一种观看组织。依据可见损益选方案，不能用“更紧张、更电影”作答案；无收益则简化，有效旧稿可保留。选定后反推中心路径、朝向和光学：行进中从局部到整体须真实拉开相对距离并扩大画框，主体与摄影机同速同行不自动造成这种变化；固定机位可借已有主体移动改变尺度。普通进入、确认或交付不自动成为悬疑发现，不为制造“后知”增加隐藏事件。

## 4. 把所选摄影写清楚

按被选用的维度形成每镜最小底稿：实际取景边界、机位与视点、光学和清晰对象、人物调度、摄影路径与朝向、信息显露、声音、切点及最终状态。不要给未用维度制造参数。

新设计在需要细节、特殊观察位置、远近同时清晰、焦平面组织、镜内尺度变化或鲜明镜头性格时，主动按 `optical-shot-selection.md` 选具体光学方案。焦距、镜头类型、工作距离、焦点与路径一起服务观看；普通定焦合适时保留，专业名称与实际取景效果一起进入成品。已定镜头不因新增选项重开设计。

先用已选观看位置和画框缩小机制范围，需要扩展时按 `fcml-motion-index.md` 检索相关条目。选中后将来源 ID、实际操作与路径阶段保存到 `motion.fcml_ids`、`motion.operations`、`motion.stages`；没有选用库时无需这些字段。需要保真的观察距离、画内主对象尺度及远近顺序沿用 `framing`、`camera` 和可选 `critical_retention`，短画框候选与取舍可放在 `camera.decision_record`；编译阶段不重查库、不重选拍法。

主动决定摄影机由什么支撑、具有怎样的运动质感：手持或肩扛的身体感、稳定器的连续漂移、轨道的精确位移、固定机位的等待压力，均按本场观看任务选择，不等用户提醒，也不按类型机械分配。选中手持时，把晃动写成过程：由步伐、呼吸、急转、追赶或冲击中的哪项产生，沿什么方向、强弱怎样变化，何时触发、何时收稳或停止；身体微动与明确的一次震动分清。关键触点、脸部反应或证据的辨认窗口不能被晃动和模糊吞掉；不要求所有手持镜头命中时绝对静止，更不把所有镜头都改为手持。

**整体摄影与成像在设计层主动选择。** 未锁定时按题材、情绪和既定场景选具体媒介、风格参照、摄影机或拍摄制式、胶片/数字成像与镜头路线，读取 `color-and-image-formation.md` 第0节；已定方案直接继承。保留专业名称及其借鉴的可见特征，并落到全景、人物与细节共享的颜色、亮暗、反射、清晰度和运动观感。美术、照明、曝光/白平衡与最终成像分别承担这些结果，明亮或幽暗、鲜艳或克制均按本场选择。提示词第一模块定调、第二模块再次强化并展开，逐镜写实际光学与受光变化，不机械套同一器材或统一滤镜。

环境摄影确定光源世界位置、方向、软硬与覆盖区，将所选Look落实为本镜亮暗落区、色块与材质响应；移动时重新推导光源的遮挡、受光与反射变化。稳定灯光无需人为闪烁，未定参数不以精确数值伪装事实。纯光色对照保持同一画框、对象与锁定条件，在授权开放项内比较不同的光形、色块或高光形状；同时授权重做摄影时按 `color-and-image-formation.md` 第3节联合设计。仅多写参数和形容词不算改善，已定动作及未获重设计授权的运镜保持。

关键细节先核对观众能否看清：对象的哪个部分、在框内多大、何时清晰、停留多久。特写、深焦同框、前景放大或移焦是解法；写“85毫米”不能证明细节可读。

细节还须核对真实遮挡和取景边界。脸、手和动作结果按本场职责分配观看，不默认全段必须兼得；移焦只能改变清晰平面，不能使背面脸露出、让被挡的手出现或把画外证据纳入画框。需要时修机位、取景或已有行动的观察时机，不为圆拍法擅加转头、让位或停顿；用户留出的表演开放项仍按人物目的与观看作用设计。

复合运镜按时间排演：**起始构图 → 画内触发 → 中心路径与转向 → 人物/焦点/遮挡接力 → 速度与停顿 → 终点**。每阶段改变观看内容；不靠“流畅复合运动”代替。横移与摇摄、推进与变焦、摄影机滚转与世界倾倒分别描述。通路须可解释，遮挡不能证明穿墙合法。

升降与俯仰、绕主体环绕与绕光轴滚转、移焦与镜头呼吸、镜内揭示与隐藏剪辑、全局慢动作与局部冻结也须分别说清。触发来自已有动作、声音或信息变化，不为运镜补事件；没有新观看任务的行进衔接可合并，必要路径转弯仍保留，不把每个地标机械升格成新段落。逐段写从哪里看、何物以何种尺度占画面，已有行动怎样改变距离、遮挡、焦点与显露；用户复制的六模块成品不带占位骨架、运镜百科或来源编号。

在用户已授权的特效方向与作品规则内，设计时就决定触发事件、作用对象与范围、从出现到扩展再消退的形状和过程、与动作或播放的节奏关系、怎样照亮或遮住实际区域、结束后留下什么。冲击闪光、抽帧、短停、残影、能量或环境变换各有不同作用，可单选、组合或不用；不靠“特效燃炸”替代设计，不为加效果新增能力或结果，也不让特效抢先替代接触与反作用。没有本场效果需求时不制造特效段。

静止也有设计：框内的人怎样改变距离、遮挡或空位，停留保住什么，哪个节点让切镜成立。不要强塞哈欠、舔毛或摆手。

## 5. 时间和连续性

设计时分别安排四种速度：人物事件怎样在世界中发生，摄影机怎样跟进或等待，画面怎样实时/慢放/加速/短停播放，剪辑怎样换视点及保留辨认时间。快切不等于动作变快，慢放不等于人物慢慢表演，镜头后撤也不等于播放加速。按本段需要明确变化触发、作用区间和回到何种状态；匀速、实时、长停和少切同样成立，不默认快—慢—停或每镜变速。抽帧需要时写明作用时段与断续观感，不能把动作因果所需过程抽掉。

时间按动作、对白、辨认和反应分配，不均切。可以并行的摄影与行动共用时间；接触、施力、移动、结果等先后依赖必须看见过程。精细动作被摄影接力遮掉时，先调整竞争的摄影任务。

在同一时间轴排演人物与摄影机路程、停留、转向及清晰对象，不能仅给相机首尾位置就声称及时抵达。落点须留真实观看时间，不能到最后一帧才宣布结果完整。

固定世界、实际行动与画面投影分开：门从画左变画右可能是合理反打；重要的是同一世界能否解释，并且剪辑方向可理解。光源、道具、人车不会因切镜重置。下一镜只承接紧邻前镜的真实尾态；明确的省略、回忆或重复设计按原意保留。

用户锁定的时长、动作和对白若不可兼容，指出具体冲突，不以异常速度、吞词或暗改镜头解决。未知模型能力不当作硬限制；真实限制出现时保留原设计，说明变更及代价。

## 6. 成品反查

按本次媒介交付同一方案：分镜用可读设计，提示词才读 `production-contract.md`。只看最终文本还原起、中、终的画内对象、主次尺度与清晰关系，再核对所选距离/取景变化、支撑与晃动过程、四种速度的变化和停顿、已选特效的触发/作用/受光/后果、选中颜色浓度与落区、亮暗过渡、材质反射和成像处理、原信息优势、人物行动、环境持续和尾态。若选中细节观察却仍写成中景全程跟随，或已定手持、特效与Look只剩名称，先修编译；若底稿也没有对应过程，回到设计。问题修在最早失效处，不输出分析账本代替成品。

有明确作品目录时，按 `design-memory-protocol.md` 把导演意图、选中依据、锁定事实与镜头状态保存在既有 `.director_design` 中；不能另建平行状态系统。文本判断不证明真实视频已经执行。
