# 从剧情到观众经历

用于新设计或重设计尚未锁定的拍法。普通场景以本文件完成决定；特殊摄影查 `cinematography-design-engine.md`，复杂投影与轴线查 `framing-and-axis.md`。不以参考库数量代替设计，不重复已有导演方案。

## 1. 先找到这场戏的变化

完整读当前片段及必要前后文，确定谁为达成什么而行动、遇到什么阻力、怎样回应、最后什么变了。区分原文事实、用户锁定项和可设计部分。心理需转为有依据的可见表演；不凭空新增剧情来证明情绪。

观众体验必须能改变拍法：观众比人物先知道、同步发现、还是暂时落后？观众从哪里进入这段经历，接近谁，何时等待或转移，结束时多了什么理解、压力或释放？这些决定留在画面与声音中，不额外生成问卷。

若只是从逐句台词配一个近景，先回到人物行动和关系。若已有方案只欠表达，沿用它，不重新开展探索。

## 2. 排演人物与正在运行的场所

建立足够用的空间：门窗、通道、固定地标、人物与目标、持物、实际光源。简单空间用清楚的相对关系即可；坐标、图纸和白模只在需要解开真实几何问题时使用。

人物通过接近、回避、控制出口、让位、遮挡、交付、停住或拒绝改变关系。先确定这些行为如何发生，再安排摄影机观察；不能只写情绪词和运镜名。

**环境也有当前状态。** 根据地点用途、时段与已知天气，判断主体表演期间场所怎样继续运行。开放项可作合理设计并在必要时简短标为假设，不每次向用户询问风、人、车是否存在。已定空街不能加人，晴日不改雨夜。

- 重要背景对象明确目的、路径和持续过程；切镜后从当前进度继续，出框不等于消失。远处匿名人群只需流向、密度和节奏，不逐人建账。
- 风、雨、机器等只有在适用时才加入，并作用于实际物体；受遮挡和材质差异影响，不让所有物体同步摆动。
- 光变化来自车灯、遮蔽、开门等真实关系；车辆经过不一定照到脸。反打不会移动世界光源。
- 环境声有来源、远近与遮挡；进入室内后声场改变。不为制造悬念临时补剧情性敲门或脚步。
- 安静、无风、稳定光照和有意停住都成立。环境检查用来发现无意冻结，不要求每镜至少一个动点，也不要求空气里有颗粒。
- 关键脸部、手部或证据需要辨认时，背景活动不抢走注意；已设计的遮挡或干扰则保留其显露时机。

静态场景参考锁空间与外观，不自动冻结视频中的人车；只有明确指定某镜构图的参考才锁该机位与边界。

## 3. 组织整段观看

从信息、表演和空间关系决定连续长镜、切分或混合结构。每次切镜带来观看距离、视点、反应、省略或节奏变化；不切可以保留同时发生的关系、等待压力和完整行动。没有最低镜数、固定秒数或远中近阶梯。

对会显著影响表达且尚未锁定的选择，比较不同观看方式。可以改变信息先后、主体关系、空间投影、镜内接力或剪辑结构；不是把缓推替换成环绕。普通中景、固定构图能否完成任务？如果换掉所选拍法，会失去哪项可见证据、身体感或关系？比较聚焦关键选择，不逐镜强做两套完整方案。

大胆摄影是实际选项：距离突变、低位穿行、升起揭示、远距观察、特殊焦点、静动反差和速度变化都可能有效。不能因避免炫技而只剩固定中景；也不能用复杂程度证明价值。

用户要创意镜头思路，或主方案旁存在值得单独提出的开放选择时，按 `creative-shot-ideas.md` 把少量备选及取舍交给用户。主方案仍完整交付；备选未被采用前不混入镜序，也不触发实际生成。

导演意图简短落到一个可观察结果，例如同时看见邀请的手和未被占用的空椅。摄影机可以跟随、领先、等待、拒绝跟随或离开主体去揭示另一信息。空间中的独立行动不能为了同框挤到错误房间或门口。

## 4. 把所选摄影写清楚

按被选用的维度形成每镜最小底稿：实际取景边界、机位与视点、光学和清晰对象、人物调度、摄影路径与朝向、信息显露、声音、切点及最终状态。不要给未用维度制造参数。

关键细节先核对观众能否看清：对象的哪个部分、在框内多大、何时清晰、停留多久。特写、深焦同框、前景放大或移焦是解法；写“85毫米”不能证明细节可读。

复合运镜按时间排演：**起始构图 → 画内触发 → 中心路径与转向 → 人物/焦点/遮挡接力 → 速度与停顿 → 终点**。每阶段改变观看内容；不靠“流畅复合运动”代替。横移与摇摄、推进与变焦、摄影机滚转与世界倾倒分别描述。通路须可解释，遮挡不能证明穿墙合法。

静止也有设计：框内的人怎样改变距离、遮挡或空位，停留保住什么，哪个节点让切镜成立。不要强塞哈欠、舔毛或摆手。

## 5. 时间和连续性

时间按动作、对白、辨认和反应分配，不均切。可以并行的摄影与行动共用时间；接触、施力、移动、结果等先后依赖必须看见过程。精细动作被摄影接力遮掉时，先调整竞争的摄影任务。

固定世界、实际行动与画面投影分开：门从画左变画右可能是合理反打；重要的是同一世界能否解释，并且剪辑方向可理解。光源、道具、人车不会因切镜重置。下一镜只承接紧邻前镜的真实尾态；明确的省略、回忆或重复设计按原意保留。

用户锁定的时长、动作和对白若不可兼容，指出具体冲突，不以异常速度、吞词或暗改镜头解决。未知模型能力不当作硬限制；真实限制出现时保留原设计，说明变更及代价。

## 6. 成品反查

按本次媒介交付同一方案：分镜用可读设计，提示词才读 `production-contract.md`。从最终文本核对观众何时看见什么、人物能否完成行动、世界是否延续、环境是否适用且持续、摄影是否可还原。问题回到最早失效层局部修复，不输出分析账本代替成品。

有明确作品目录时，按 `design-memory-protocol.md` 把导演意图、选中依据、锁定事实与镜头状态保存在既有 `.director_design` 中；不能另建平行状态系统。文本判断不证明真实视频已经执行。
