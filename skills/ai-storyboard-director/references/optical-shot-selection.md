# 按观看任务选择专业光学

适用于所有题材的分镜设计与视频提示词。新设计主动选择；接收已定镜头时保留选择，只有当前请求开放的部分才重新设计。沿用项目已定媒介、风格、人物和空间，不以增加器材为由加戏或改造场景。

## 从画面需要选择

先明确要看清的对象、画内尺度、观察位置、工作距离、近远清晰关系与移动通路，再选焦距、镜头类型或附件。球面/变形是成像类别，焦距是另一维度；镜组性格、近摄能力和附件还可继续选择。普通定焦能完成任务时直接采用，不规定每场必须用特殊镜头。

| 当前观看需要 | 可选光学方案 | 必须落到画面里的内容 |
|---|---|---|
| 清楚观察眼睛、纤维、水滴、工具接触等局部细节 | 普通微距镜头 | 实际放大尺度、对焦部位、可用工作距离与景深；焦距长不自动等于微距能力 |
| 极贴近小物体，同时保留环境和低位纵深；观察细窄但可达的空间 | 广角探针微距镜头 | 前端位置、可通过的间隙、前后景关系及移动方向；不把长管造型当成穿墙能力 |
| 摄影机主体无法正对，镜头前端需从狭窄位置向侧方看 | 潜望式探针微距镜头，如90°观察端的PeriProbe | 区分镜头前端的观察方向与管身路径，写清由什么遮挡进入、最终看见哪里；微距并不默认选潜望探针 |
| 近处线索与远处人物需要在同一画面同时清晰 | 分焦屈光镜／Split Diopter附件 | 两个清晰区域分别对应什么距离、分界放在哪里；它不使中间所有距离连续清楚。需要整个纵深连续清晰时考虑深焦方案 |
| 需要倾斜的清晰平面，或保持相机姿态时调整建筑取景 | 倾斜移轴镜头／Tilt-Shift | 倾斜改变清晰平面，移轴调整取景；明确对主体的作用，不自动做微缩玩具效果，也不把世界随镜头倾斜 |
| 一个镜头内连续改变画角或尺度 | 专业电影变焦镜头 | 焦段起终、变焦速度、对焦及主体占比。采用推拉变焦时同时交代摄影机移动与反向变焦，单纯变焦不改变观看位置的透视 |
| 主观视点需要强烈的广角包围或弯曲几何 | 超广角或鱼眼 | 区分保持直线的广角与鱼眼畸变，明确人物距离和边缘位置；按作品风格选择，不泛化到所有写实镜头 |
| 需要不同的反差、焦外、炫光或边缘性格 | 具体电影镜组、复古镜组或适配的光学附件 | 选中哪种可见性格、在哪个亮源/焦点/距离下出现，如何与其他镜头保持同一基调；价格与品牌不作为质量等级 |

## 具体名称与摄影过程一起写

用户未点名器材时，也主动判断当前画面是否需要上述选择。名称写准确；型号及其能力已知时可具体到型号，未知时用准确类别和可见目标，涉及最短对焦、倍率、覆盖画幅等硬规格再查官方资料。摄影机画幅、镜头覆盖、焦距、输出比例与景深分别判断，不把35mm胶片规格当成35mm焦距。

潜望结构尤其要核对机械边界：可更换的直视端与固定90°侧视端，不等于一个观察端能在连续拍摄中从0°变成90°。管身滚转只改变固定侧视端朝向哪一侧，不能把它转成直视；没有已验证依据时不编造可变视向棱镜。可选择从开场就保持侧视、沿真实通路移动使目标进入画框，或在用户允许的切镜处更换观察方案；明确锁定的连续镜头不得暗藏换镜头。若必要条件仍不可兼容，指出具体冲突并保留其余可完成设计。

第二模块保留全段共用的光学性格与成像路线；特殊镜头按段采用，不要求整部片所有镜头使用相同光学结构。第六模块写“具体光学/焦距＋观察位置与距离＋焦点/清晰区域＋移动或停留＋最终画面关系”。复杂路径只写实际需要的阶段，解释理由和未采用候选留在内部。

例如，只有水珠细节时可用普通微距；要贴着机芯观察零件与环境可用探针；还需向管身侧面观察时再选潜望结构。这些例子说明选择机制，不固定成任何题材的默认镜头。

## 成文反查

确认专业名称确实对应本镜画框、观察方向、可达路径及清晰关系；共用摄影基调仍贯穿全景、人物和细节。压缩时保留选定的光学过程，删去重复器材罗列。负面提示词不得禁止本片主动采用的鱼眼畸变、焦外、炫光或其他光学特性。生成模型是否执行这些效果，要依据实际画面判断，名称出现不等于效果通过。
