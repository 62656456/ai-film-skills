# AI Storyboard Director 生产合同

## 1. 交付与内容准入

默认正式交付只有一条融合母稿：它用六大模块组成六个可见段落，第六段直接承载完整、可读的镜头时间轴，因此同时满足分镜阅读与视频生成，不再并列输出五列表和提示词，也不另输出十段式。用户明确只要镜头表时才改用五列表。用户点名总时长时，一条母稿覆盖完整时长，六个模块只出现一次；只有明确要求逐镜生成或已核实平台硬限制，才在母稿之后追加独立、自足的拆分生产单元。

### 1.1 什么内容进入正文

每句话必须能对应当前片段所需的画面、行动、声音、摄影、光色、风格、时间或必要连续性。素材可能包含全故事背景，但只在后续片段出现且对本条没有实际作用的角色、地点、道具、动作、镜头和结果不写入本条。整条后段使用的主体可以在主体模块定义，逐镜仍只写该镜所需内容。

内部需要检查“谁尚未出场、谁已出框、哪些风险不存在”；检查结果不自动变成给模型的句子。与当前镜头无关的概念，连同“没有、不出现、不得、仅有、暂不”等排除改写一并省略。不要为了保险写背景角色名单、未发生事件或“本段不展示后续剧情”。

必要的画外声音、影子、倒影、延迟显露、遮挡边界和用户明确的画面限制仍可写：判断其是否决定当前可见、可听的结果，而非按“否定词”一刀切删除。负面约束只针对当前描述或实际参考引发的具体混淆风险、已出现的生成错误、用户明确限制或已核实平台要求；没有依据时不生成通用负面清单。

编译已确定镜头时，不能用新增反应镜、建立镜、过场、对白、道具或剧情结果补齐字段。原设计缺少必要摄影细节时，在不改变其含义的范围内补足；时间、动作或空间不可兼容时报告冲突，不暗自重导演。

### 1.2 按需要分配信息

- 整段共享的身份、场景、光色和风格集中定义；每镜写自己的动作、拍法、变化及必要连续性锚点。同一母提示词内不逐镜重述全套设定。
- 标题提供摄影索引，正文承载动作和摄影的时间关系，尾部只保留尚未说明且确有必要的共同限制。同一事实只在最有效的位置写清，跨镜变化、独立生产单元和用户要求的必要重述不算重复。
- 主体数量、动作阶段、摄影变化和跨镜关系决定详略；不设统一字数、固定理解秒数或压缩比例。简单固定镜头可以短，复杂运镜须完整。
- 焦段、距离、角度、速度或占比来自用户锁定、实际参考、设计需要或明确推导。无必要时用可执行的相对关系，不给无依据的小数、百分比或每阶段秒点。用户已确定的数值与关键光学不得省略。
- 有生命主体具有符合当前目的的身体状态与必要反应；有意静止、屏息和停顿不是缺项。不能以“不能站桩”为由新增小动作或生活事件。
- 用户可见正文使用角色、场景、道具自然名称，内部编号、路径、版本、哈希与治理信息留后台。

## 2. 明确点名时的五列分镜

五列表是用户明确要求“只要镜头表／先看分镜表”时的替代交付，不与融合母稿并列。其内部镜头方案必须和可编译的融合母稿一致，但当次只输出用户点名的表格。

```text
总时长：<N秒>　画幅：<比例>

| 时间 | 景别 / 机位 | 摄影机 | 画面与动作 | 台词 / 声音 |
|---|---|---|---|---|
| <起止> | <主体尺度与拍摄方位，必要光学> | <摄影机如何移动、转向或固定，关键接力和落点> | <先写本镜主动作，再写必要布局和变化> | <原台词与必要声音时段> |
```

五列各负其责，不在每格重复全套技术参数。摄影机栏用具体动词写可想象的路径，不能退化成“电影感、复合运镜、流畅跟拍”。画面栏让人先读到正在发生的事；不追加第三份逐镜摘要、解释表或内部检查报告。无台词的表格单元可以用“—”，无需解释没有哪些人物或声音。

按事件、动作、辨认、对白和停顿做非等分时间轴，不机械均分；即使当次只交表格，也不能丢失后续编译融合母稿所需的摄影、动作、声音和终点。

## 3. 单一融合六段：六大模块与数字10

“六段式”和“六大模块”在正式输出中是同一套可见骨架，不生成两份提示词。严格使用一次以下外层，六个模块均有针对本条的具体正文；数字10的十项信息直接写进最合适的六段，不另起十个章节、第二份提示词或映射说明：

```text
【片段标题】

一、生成任务
<总时长、画幅、帧率与本条任务>

二、主要主体
<本条所需主体、已有外观特征与初始状态；实际参考的身份职责>

三、场景状态
<支撑本条摄影与行动的空间关系、道具、实体光源及实际环境状态>

四、情绪目标
<由具体表演或关系变化体现的情绪过程，简洁且不新增动作>

五、视觉风格
<本条共用的摄影质感、色彩与材质；不重复逐镜拍法>

六、分段脚本
<按时间展开镜头；适用时保留必要共同限制>
```

数字10是内部审查维度，并按下列关系融入六段；这张关系表只供编写与核对，不进入用户成品：

| 数字10内部信息 | 融入位置 |
|---|---|
| ①时长、画幅、帧率与任务 | 一、生成任务 |
| ②主体与场景 | 二、主要主体；三、场景状态 |
| ③动作与事件 | 六、分段脚本 |
| ④摄影 | 五、视觉风格只写整段共用质感；六、分段脚本写每镜机位、光学、路径、速度、接力与切点 |
| ⑤光色 | 三、场景状态写实体光源；五、视觉风格写共用色彩；六、分段脚本写随行动和机位发生的变化 |
| ⑥材质与物理 | 二、三写初始材质和状态；六写接触、施力、惯性与环境反馈 |
| ⑦情绪与风格 | 四、情绪目标；五、视觉风格 |
| ⑧终点 | 六、分段脚本写每镜落点与全段最终状态 |
| ⑨声音与对白 | 六、分段脚本按时间写原台词、声音来源及跨镜延续 |
| ⑩必要负面约束 | 写入实际引发混淆的对应段；确属全段共同限制时才放在六末尾 |

每项均判断适用性，适用信息须完整，不适用不等于失败，也不输出“不涉及”。禁止为凑10/10增加无关人物、环境、负面句或新剧情；禁止增加第七至第十模块，禁止把同一信息再复制成十段式版本。

参考素材只在相应模块声明本次真实用途：外观、地标、世界站位、明确指定的镜头构图、运动、声音或指定时刻状态。不得把资产图自动当锁定机位，也不得让站位图限制后续重新构图；用户明确锁定某镜参考时遵守其实际锁定范围。

## 4. 世界状态与换机位

在场景状态中建立一次足以支撑本条的空间关系：方向基准、必要地标与可通行入口、人物位置朝向及视线、道具持有人与状态、行动或关系轴、实体光源和实际存在的环境运动。不为填表添加罗盘坐标、家具、尘烟或人物。

世界状态只随真实行动变化。每次换机位或镜内跨越空间，内部依次推导：
固定世界 → 摄影机位置、朝向、高度、俯仰与光学 → 当前左右纵深 → 遮挡与露出 → 局部受光 → 行动反馈。

世界位置与画面位置不同，上一镜的画左不能直接复制到新机位。轴线与构图按 `references/framing-and-axis.md` 核对，左右投影正确不等于切镜方向正确。

正文只保留当前取景需要的关系，例如“右肩占画左前景，焦点落在对面人伸来的手”。被裁掉的无关人物、肩膀、衣角和影子不列为排除名单。局部露出承担叙事任务时，写明可见部位、位置及必要尺度；明确取景边界即可表达时不再追加相同否定句。

用户锁定参考图时继承其机位、透视、地平线与构图。不同空间的独立行动分镜表达，不硬塞进门口大全景。入出画依据真实通道、遮挡或已建立的画外空间；切镜不改变房间拓扑、人物朝向、光源位置或道具状态。

## 5. 分段脚本：可见摄影与连续行动

不再在第六模块开头重复整份世界地图。每镜标题显示具体拍法；推荐紧凑形式为：

```text
[起止时间｜具体景别与机位｜主要摄影过程→落点]
```

这是阅读组织，不是固定字段数量。关键焦段／光学、速度变化、焦点或遮挡接力具有辨识作用时直接进入标题；其余必要参数放在本镜正文出现一次。固定镜头写“固定”；特殊光学、用户锁定参数和分阶段复合路径不能因标题缩短而丢失。剧情短标题只能辅助识别，不代替摄影方案。

正文从起始取景与主动作开始，按触发写人物、摄影、焦点和声音如何共同变化，结束于观众实际看见的状态。示意：

```text
[0—6秒｜手部近景，椅边侧俯｜沿椅边缓移，车票→松开的手]

车票在椅面落稳。摄影机沿椅边缓移，立柱掠过前景后，焦点由车票交给刚松开的手；压在包上的手指卸力，布面随之回弹，镜头减速停在手部。
```

此例只说明组织方式，人物、场景、动作、秒数和拍法均不自动进入其他任务。

每镜内部检查，但只将适用信息写入正文：
- 起始机位、景别／必要光学、实际取景范围与可见主体；
- 人物行动及有因果依赖的接触、施力、位移、反应与结果；
- 摄影机中心路径与朝向；复合运动的触发、阶段、速度、停顿、焦点／遮挡接力和终点；
- 原台词及声音发生或跨镜延续的时段；
- 与当前观察或动作有关的受光、环境及物理反馈；
- 切点及结束时的实际状态。

不存在的风、火、雨、雪、烟、尘不要求描述，没有移焦不强制再写“无移焦”，无关出框对象不要求声明。关键的固定状态或清晰平面会影响执行时，用明确对象写出；不得把条件项省略成含糊拍法。

仅当确有未在前文表达的共同限制时，在第六模块末尾写“[全段硬约束]”，只列实际必要项。没有新增必要限制时整个尾块省略。不要重复身份、空间、动作顺序或追加“没有下一场人物／不增加其他剧情”等保险话。

## 6. 摄影设计到提示词的守恒

先在内部确定摄影底稿与镜头时间轴，再编译为唯一融合母稿。底稿的具体观看对象、构图边界、机位与轴线侧、焦段光学、中心路径与朝向、阶段触发、人物／焦点／遮挡／声音接力、速度停留、切点与落点都须保留；内部底稿不作为第二份用户输出。

标题与正文共同承载完整拍法，不要求同一信息在两处重复。复杂路径不能缩成“平滑跟拍”；特写须真正拍到关键部位并留够观看时间。清理文字不能变更镜头顺序、动作结果或用户已定设计。

完成后只看最终提示词，反向还原每镜起点、中途和终点，与底稿对照；再对照原文，检查新增内容与遗漏。未展开、路径改变、焦点错接、停留被吞、切点不明或无依据的新内容，均修正对应句。不能只靠术语与标题计数判通过。

明确作品目录中，使用 `references/design-memory-protocol.md` 保存的当前场景版本，状态程序回执不代替上述语义检查。类型模板的固定秒数、单运动或最低镜数不能覆盖已定设计；真实平台限制需另说明变更及代价。

## 7. 台词、光线与环境

原台词逐字保留，除非用户授权改写。按人物状态确定语速、音量、重音和停顿；装不下时调整未锁定的时段或跨镜延续，仍冲突则报告，不吞词、不擅自加速。切镜不让连续台词重新起句。画外声确有作用时保留来源和必要方向，不为了保留声音把说话者塞进画面。

光源先有实体位置、方向、颜色和强度；换机位后重算亮暗、反射和轮廓，不为面部好看凭空补光。实际存在的风雨、火焰等按动作与物理连续，人物移动造成的衣物、发丝及环境反馈来自当前场景。无依据的环境现象不添加。

## 8. 内部验收

交付前一次核对内容，不向用户打印审计表：
1. 是否只交付一个符合当次要求的成品；默认融合母稿的六模块是否完整且只出现一次，是否残留第二份分镜表、十段式或映射说明；
2. 数字10是否逐项判断适用性，必要信息是否完整，不适用项是否未被写成正文；
3. 是否擅加原文和已确定设计以外的人物、道具、环境、动作、对白、镜头或剧情结果；
4. 无关概念及其否定／“仅有”改写是否残留，必要画外声、遮挡或明确限制是否被误删；
5. 最终提示词能否还原既定摄影，是否因去重而丢失光学、阶段、接力、速度、停留或切点；
6. 台词、时长、投影、轴线、入出画、道具、光源与接触受力是否连续；
7. 融合母稿第六段能否直接想象主动作与拍法，是否与前五段一致；明确点名五列表时，表格是否完整且未附重复母稿；
8. 正文是否只用自然名称、实际素材职责及必要信息，无内部编号、路径、回执或空占位。

发现问题修具体内容；格式与程序通过只属内部验证，用户接受及真实生成效果另验。
