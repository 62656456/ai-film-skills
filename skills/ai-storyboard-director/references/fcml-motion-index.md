# FCML 摄影机制索引与来源边界

本页负责按需选取摄影机制及来源审计。叙事、空间、人物调度和观看信息顺序仍由本包已有摄影引擎决定；已有锁定拍法不因查库重开。规范库在 `assets/fcml-motion-library.json`，离线读取，不依赖网站、兄弟技能或私人目录。

## 先决定观看任务，再查小范围

从当前剧情变化推导“先知道什么、后知道什么”，确定观看位置与人物路线，再用下列索引筛选。查询返回候选，只有已选方案进入摄影底稿。复杂镜头可以分阶段组合，固定机位继续有效，不因库接入增加位移、变焦或移焦。

| 当前摄影问题 | 可读的规范范围/示例 | 操作区别 |
|---|---|---|
| 接近、后退、往返、速度阶段 | fcml-001–007 | 摄影机中心位移与焦距变化分别记录；004为退行加增焦，006只有往返位移 |
| 过肩、正反观看、受限窥视 | fcml-008–010 | 008是来源实际轻推组合；过肩构图自身不要求推进，锁定固定过肩时不采用其位移；009为剪辑视点交接 |
| 遮挡揭示、真实开口、覆盖后露出 | fcml-011–014 | 单镜内揭示与隐藏剪辑分开；封闭门窗不可因想穿越临时改变 |
| 对焦、失焦、焦点接力 | fcml-015–018 | 焦点变化不同于镜头呼吸引起的视角变化；不是变焦 |
| 原地转向与横移 | fcml-019–024、045 | pan/tilt改变朝向；横移改变观察中心并产生距离相关视差 |
| 环绕、宽弧、绕行变速 | fcml-025–028、065 | 位移与朝向配合；不能用主体自转或相机绕光轴滚转替代 |
| 升降、升俯接力、高位飞行 | fcml-029–033、038–043 | 升降改变中心高度，俯仰改变朝向；041已显式选有半径顶视绕行 |
| 固定位置的焦距变化 | fcml-005、034–037、088 | 不绕开原遮挡；088极大尺度需要素材/CG，不保证无限无损光学 |
| 手持、冲击、人物前后侧跟随 | fcml-044、047–052、056–057 | 微动幅度有观看作用；跟随记录真实路径、触发、清晰对象和终点 |
| 时间处理 | fcml-053–055、070–079 | 世界/拍摄/播放时间分开；普通慢动作、局部冻结、时间切片不等价 |
| 跨尺度、实体透视、空间变形、多视点 | fcml-059–069、080–088 | 是否摄影写实与是否合成/VFX分开；未知平台执行不删导演表现力 |
| 形状/动作/光区连接、画内跨入 | fcml-089–092 | 可见连续不代表单次无剪辑实拍；转场与目标内容需已有采用依据 |
| 表演节律、主观视线、多对象揭示 | fcml-093–098 | 原站列为AI类并不证明AI专属；不照搬人物数量、声音或示例情节 |
| 媒介、分层、循环、解构、长路径 | fcml-099–104、108 | 保留二维或指定画风；媒介渐变与跨媒介边界是两种机制 |
| 超常主观、记忆、既有特效及双人动作 | fcml-105–107、109–116 | 特效/回忆/动作必须已经存在；107外部偏置跟随与114特效第一视点不合并 |

从本包根运行（脚本只有 Python 标准库）：

```text
python -B scripts/fcml_motion.py search --query "进入" --operation translation --limit 6
python -B scripts/fcml_motion.py get --id fcml-049 --id fcml-012
python -B scripts/fcml_motion.py get --id yj058
python -B scripts/fcml_motion.py adapt --id fcml-049 --input 当前任务临时变量.json
python -B scripts/fcml_motion.py audit
python -B scripts/fcml_motion.py validate
```

`search` 是词项查找，用简短名称、别名、用途或源ID筛选，可以多次读取不同小范围；它不替代导演判断。`get` 读取已经选定的规范条目，包括源映射、操作分类、路径阶段、模板变量、空间条件及执行状态。第三个命令会从重复来源 yj058 找到规范 fcml-043。

`adapt` 输入由助手从当前来源整理，用户不填技术表格。JSON中的 `variables` 只放当前场景/摄影决定，必需键以所选条目的 `variables` 为准。采用的效果用 `adopted_effects` 记录，媒介转变还需 `approved_medium_transition: true`；这些是既有采用决定的记录，不是运行工具即获授权。未填变量会报错，脚本不补人物、门、椅、对白、声音或时间。输出仅为可融入逐段画面的摄影过程，不代替一条完整六模块母稿。

摄影底稿把已选 `id` 写入 `motion.fcml_ids`，实际操作与阶段写入 `motion.operations` / `motion.stages`；库中三阶段 `phases` 只是机制信息，选定后须按实际时长、路线、焦点和揭示对象细化。场景光色、环境持续及终帧写入既有场景/镜头合同，必要项进入 `critical_retention`。编译阶段直接读保存的决定，反向检查最终母稿有没有路径转向、遮挡/焦点接力、关键光区和终态；不要重新遍历运镜库或把占位模板交给用户。

参数化保留单条机制的方向、阶段次序和起终关系：整周闭合、半周换侧、光轴完整回合、冻结后的恢复/继续冻结、吸气退离/呼气接近、逐脉冲反应及渐增幅度、中心停时/外层渐快/镜头外扩绕行。在相关条目的 `mechanism_invariants`、实际模板及终段记录中均有落点。当前剧情不适合该覆盖或速度时，选择另一候选或提出保留叙事作用的实现调整；不能泛化成任意路径来假称保留机制。实际秒点、半径、幅度和速度仍从当前任务确定，原站数值不成为每镜默认。

## 实际来源覆盖与许可

[FCML公开网站](https://fcml.infission.com/) 于 2026-10-10 UTC 实际核查。首页加载 [公开应用脚本](https://fcml.infission.com/assets/index-xzS1XB-T.js)，其中唯一 `JSON.parse` 数据被界面按 `systems → categories → items` 全量展开，卡片展开与复制均绑定 `item.prompt`，没有分页或额外条目接口。实际为 **2个体系、22个分类、117个来源记录，117条完整提示词已读取**；只合并两组完全相同提示词，得到 **115个原创规范机制**。这是所观察公开目录的覆盖，不保证未来更新或未公开页面。

首页数字为58、59、合计117；体系说明文字仍写14类44条、9类60条，而实际分别14类58条、8类59条。库同时保存宣传数字、实际数字、完整内容读取数、覆盖分母依据、抓取时刻、逐项定位及全文SHA256，不拿宣传数字硬设验收答案。两组重复为 yj043/yj058 → fcml-043，yj073/yj117 → fcml-073，全部来源均保留映射，无未读条目或未映射缺口。其它看似相近条目保留差异，例如冻结后恢复/冻结结束、特效外部跟随/特效第一视点、同空间媒介渐变/穿媒介边界。

未确认整站转载许可，包内**不含原站完整提示词、图片、视频**。名称、来源定位和内容哈希用于追溯，模板为本项目原创参数化改写。原站“AI专属”“全平台适配”“零误差”“无限无损”“100%清晰”只作为被审计的原站声明，不是本包能力承诺。逐条矛盾和修正在 `source_records[].conflicts` / `motions[].source_corrections`。

运维更新使用 `scripts/fcml_source_audit.py` 读取维护者公开下载到任务临时目录的网页脚本，比较新增、删除、prompt哈希变化和映射缺口；该脚本不联网、不自动改库、不保存或重新发布全文。`--enumeration-verified` 只有重新检查目录UI及数据加载闭合后才使用；没有完整枚举证据时分母及覆盖率为未知。原始网页和全文读取完即按临时产物规定清理，库不依赖它们。

## 定义核对与验证等级

焦距/视角依据 [Nikon焦距说明](https://www.nikonusa.com/learn-and-explore/c/tips-and-techniques/understanding-focal-length)，镜头呼吸依据 [Nikon官方说明](https://onlinemanual.nikonimglib.com/zr/en/09-04-47.html)，位移同步变焦依据 [Adobe说明](https://www.adobe.com/creativecloud/video/production/cinematography/camera-shots-and-angles/dolly-zoom-shot.html)，跟随主体依据 [Adobe跟拍说明](https://www.adobe.com/creativecloud/video/production/cinematography/camera-shots-and-angles/tracking-shot.html)，均于2026-10-10核查。分类结合中心位置、朝向、焦距、焦点、时间和投影等操作推导；不是照抄原站体系判断。

结构/引用检查、参数绑定测试可在包内离线运行。它们核对证据、映射、枚举缺口、操作区别和明确采用状态，**不证明语义设计、模型生成、媒体审看或用户审美通过**。截至本次资料吸收，没有本库对应的新付费媒体生成、指定模型稳定性或用户接受记录。平台适配读取该型号/版本官方约束，在母稿之外保留执行层，不静默削掉已定复合镜或光色。
