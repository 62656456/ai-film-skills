# AI Storyboard Director

内部维护版本：**5.6.3**。用户始终调用 `ai-storyboard-director`，打戏也由这个入口处理，不需要选择版本或另一套镜头技能。本目录是完整独立运行包；运行时只引用本包文件，不读取父版本或历史目录。

交付为人能看懂的五列分镜，以及可直接使用的一条六模块视频提示词。内部底稿、检查、参数账本和恢复回执不代替成品。具体格式与内容准入以 `references/production-contract.md` 为唯一合同；交付模式以 `references/delivery-mode-guard.md` 为准，入口不再复制整套模板。

## 1. 按工作内容读取

初次使用本技能时，完整读取生产合同和交付模式门。随后按当前工作读取：

| 当前工作 | 必需资料 |
|---|---|
| 从剧本新设计镜头、重设计未锁定拍法、检查导演选择 | 顺序完整读取 `references/shot-design-engine.md` 与 `references/cinematography-design-engine.md`；先剧情、调度与整段镜头句，再选摄影 |
| 打戏新设计，或攻防、打击感、动作节奏与打戏素材诊断 | 另读 `references/fight-design.md`，按任务阶段使用专项判断；需要具体案例时才读 `references/fight-reference-case.md`。已锁定打戏仅编译时不重新编排动作 |
| 将已确定的完整镜头写成提示词，或仅清理措辞、重复、格式 | 读取完整当前镜头、剧情事实与锁定项，依生产合同编译；不重开摄影候选。出现缺失的摄影决定时再读取对应设计引擎，补足可合理推导的细节，保留用户已定拍法 |
| 涉及构图边界、关系轴、换机位、遮挡或入出画 | 另读 `references/framing-and-axis.md`；从同一世界状态核对投影与轴线 |
| 用户要求运镜对照练习，或诊断推进像缩放、横移像摇摄、环绕执行偏离 | 另读 `references/camera-motion-diagnostics.md`，按可见证据比较；仅在用户要求实验时编排对照练习，不改普通分镜的交付方式 |
| 在明确作品目录中保存、修改或恢复镜头 | 另读 `references/design-memory-protocol.md`，实际运行 `scripts/design_memory.py` 获取状态和知识清单，并实际读取清单正文 |

同一上下文内已完整读取且文件未变时复用；版本、引用或任务模式变化时补读必要文件。跨上下文不能仅凭摘要宣称已读。按需读取不是删去摄影能力，也不允许忽略当前片段的完整原文、最新用户决定和相关连续性。

恢复打戏场景后仍按当前内容补读打戏专项；程序返回的通用知识清单不等于专项已经读取。纯交锋设计与纯拉片不自动扩成分镜／提示词，按交付模式门执行。

所需文件缺失、引用越出本包或指向旧版本时，停止相应执行并报告具体缺口。没有明确作品目录的单次咨询照常交付，不把技能目录当作品，不虚构持久化或恢复成功。

## 2. 先锁事实和工作阶段

在内部区分剧本事实、用户锁定决定、导演解释、尚未确定的拍法。只问会实质改变方案且无法从现有材料确定的一个关键问题；其余依据文本完成合理判断，不要求用户填写导演表。

- 新设计：理解谁处在什么局面、为何行动、什么构成阻力、行动怎样改变关系或结果。不能复述清楚时，不先套景别或运镜。已有可用导演方案直接继承。
- 新编交锋：用户授权设计打戏时，可在已定人物、空间、能力与结尾内补足攻防衔接，并标明必要设计假设；这项权限不扩到已锁动作的编译或只改摄影任务。
- 摄影选择：人物调度与整段镜头句共同设计，使用两份设计引擎中的完整摄影语法与可见证据。具体手法只是选择，不按情绪词机械映射。
- 编译阶段：已确定的镜头顺序、时长、行动、对白、机位、路径、焦点和落点是输入。只把它们写清楚，不新增镜头、反应事件、过场、人物、道具、地点、对白或剧情结果。发现不可兼容的事实时指出冲突，不能靠补戏解决。
- 局部修正：先核对最新指令及受影响范围。保留无关镜头和用户修改，只重算受影响的动作、空间、声音与前后衔接，不为改一句文字重新导演全场。
- 续接：读取真实作品状态、原文、锁定项和相关前场尾态。源版本冲突时重新核对，不以最后修改时间或最高版本名作决定。

用户说“比如、举例”时，抽取它代表的上位问题；例子不是完整清单、时限、风格或范围上限，只有明确采用才升级为要求。

## 3. 摄影设计必须保留的能力

新设计时先读两份引擎，并完整执行其决策方法：

1. 从具体行动和变化确定观看任务、人物目的、表演、调度与信息顺序。心理转为可见行为，不只写抽象情绪。
2. 从整段关系决定连续长镜、切镜或混合结构。景别、机位、纵深、光学、视点、运动、焦点、声音和剪辑共同形成节奏，不能只轮换术语。
3. 对未锁定且影响表现的拍法比较真正不同的观看方式。关键细节先检查画面尺度、清晰平面和停留，再决定特写、同框、焦点或其他解法；不等用户提醒才补可见证据。
4. 复合运镜必须具备起始构图、画内触发、中心路径与朝向的分阶段变化、人物／焦点／遮挡接力、速度和停顿、终点构图。路径不等于摇摄；滚转不等于场景倾倒。每个阶段改变可观察信息。
5. 非等分时间轴来自动作、台词、辨认和反应的需要。先后依赖的接触、施力、位移、结果不能压成一瞬；不能靠快切、强行加速或吞词过关。
6. 固定镜头、停顿、屏息和拒绝反应可以成立。生命感来自当前身体和目的，不强塞哈欠、舔毛、摆手等无关微动作。
7. 先选摄影，再核实实现限制。未知平台能力不能被当作限制，也不能宣称支持；真实限制需要保留原设计、说明改法和代价，不静默降级。

## 4. 空间、参考与连续性

建立足以支撑本条的固定世界状态：必要地标、通道、人物朝向与关系、道具状态、轴线、实体光源及实际存在的环境运动。未发生剧情动作时，世界状态不随切镜改变。

每次换机位，从摄影机位置、朝向、高度、俯仰与光学推导当前左右、纵深、遮挡、露出与受光。重新计算在内部完成；正文写实际需要呈现的结果，不把所有出框对象列成名单。画外台词、影子、倒影或遮挡造成的必要信息按其真实叙事作用表达；与本镜无关的后续角色不因“排除”而进入正文。

用户明确指定某张图用于某镜时，继承它锁定的机位、透视、地平线、构图与可见边界。不同空间行动分镜处理；不为了同时交代把画外角色挤进门口或背景。入出画路径须来自实际通道、遮挡后空间或已建立的画外入口，不能从实墙或家具中凭空出现。

每份实际参考素材只在适用模块说明它约束的外观、地标、站位、指定构图、运动或声音。参考职责不自动升级：资产图不锁运镜，白模不锁最终美术，首尾帧不证明中间过程。与本条完全无关的参考不上传；整条后段需要的参考按其实际适用时段绑定，不逐镜写排除名单。

光源按世界位置延续，换机位后重算人物亮暗面；不得为照亮脸擅自补光。道具持有人、接触、施力、惯性和环境反馈连续；无依据的风雨、尘烟、特效不添加。

## 5. 写成可读且完整的成品

遵照生产合同：保留五列人读分镜、一次六模块母提示词和数字10内部信息核对。人读表首先让人想象发生什么、摄影机如何跟随变化、最终停在哪里；具体摄影仍清楚可见，不增加第三份长摘要。

提示词逐句先判断是否应写入，再去重和组织。没有作用的内容整句删除，不换成“仅有”“没有其他”等同义排除；有作用的复杂路径、表演、声音和连续性必须保留。标题显示具体景别、机位、主要摄影过程与落点，正文展开关键阶段；同一事实不在标题、正文和尾部反复复述。数值只在已有依据、锁定要求或真实执行需要时使用，不用虚构百分比制造精确感。

普通分镜或提示词请求同轮交付双层成品；明确“只要提示词”时只交完整六模块，明确“先看分镜”时只交分镜。所有可复制正文用自然名称，不含内部编号、路径、版本、回执或审计字段。总时长母提示词完整自足；只有用户要求或已核实平台限制才后置追加拆分版，拆分版各自具备必要上下文。

## 6. 保存、恢复与完成检查

有明确作品目录时，按恢复协议保存导演意图、选中镜头、简短依据、进入／退出状态、锁定事实与候选决定；运行程序并重新读取后才称已保存。程序只核查显式状态、时间和有限几何，不证明自然语言守恒、审美或视频执行。

交付前复用一次语义反查，同时核对：
- 依据原文与锁定项，是否擅加人物、物件、动作、台词、镜头或结果；无关内容及其否定形式是否残留；
- 只看最终提示词，能否还原既定摄影的起点、触发、路径、接力、速度、切点和落点；重要信息有没有因去重或压缩丢失；
- 时间、对白、世界位置、轴线、入出画、道具、光源和物理因果是否连续；
- 人读表与提示词是否描述同一方案，交付模式是否满足当次要求。

适用性在内部核对；不适用项无需生成“无／不涉及”正文。发现错误修具体内容，不附长篇自检，不把格式计数当内容验收。

需要测量效率时分别记录读取、设计、成文和检查的可观察时点、输入与输出字符数；不能把少读文件或短文本直接称为提速。记录复用必须基于最新版本，不能为效率跳过关键核验。结构、语义、用户接受与真实视频验证分别报告。
