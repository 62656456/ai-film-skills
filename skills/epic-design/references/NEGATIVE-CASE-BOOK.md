# 反面案例与改写

需要诊断具体失败时选相关行；例子说明判断方法，人物、数值、动作和场景不能自动加入当前作品。

| 错误写法 | 缺少什么 | 修正方向 |
|---|---|---|
| 电影感、氛围感、高级感 | 可见关系 | 明确第一注意力、取景、光源、主体分离和必要材质；只写当前有效项 |
| 很像某导演 | 可执行画面 | 写实际选用的留白、遮挡、对称、声音或色彩关系；实名方法需要来源 |
| 镜头慢慢移动 | 触发、方向、起止 | 说明何时开始、从哪里向哪里、怎样转向、何时停；速度由观看需要决定 |
| 画面很暗很神秘 | 光源与信息可读性 | 明确哪处光照到什么，关键线索怎样从邻近暗部被辨认；不虚构暗部百分比 |
| 冷暖对比很强 | 色彩角色 | 说明冷暖来自哪些光源/材质，分别服务哪些主体或信息 |
| 宏大史诗场面 | 尺度证据 | 用地标、透视、遮挡和适用尺度参照建立体量，不固定人物比例或强加人物 |
| 他把道具交给对方 | 持有与变化过程 | 用自然名称写谁持哪面、怎样递交、谁接住、最终在哪里；不擅补手别 |
| 角色紧张 | 当前目的与表演 | 从刺激和人物策略选择可见反应；屏息或有意静止也可成立，不机械添加吞咽 |
| 华丽魔法/霓虹光 | 来源与影响 | 选实际光源或有依据的世界规则，写局部照明与必要反射；不强加湿面或雾 |
| 保持上一镜一致 | 需要继承的事实 | 写当前位置、朝向、道具、光源和必要地标，承接进度而不重演前镜动作 |

负向只保护实际风险，可按通用结构、类型失误和成像方式选择；不强制三段或每段重复。无关对象及其排除句不进入正文。诊断只交证据与必要修正，不以检查清单替代用户请求的提示词、图像或镜头设计。
