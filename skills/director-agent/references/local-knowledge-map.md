## Routing

- If the companion repository is unavailable, continue with this Skill's bundled screenplay and director references. Report only that the optional deep-knowledge layer was not loaded.
- For script creation, revision, or diagnosis, read `screenplay-writing-core.md`; then use the relevant A3 cards only when the public knowledge repository is available.
- For a director treatment, use the relevant A1/A2 cards when available.
- For pre-storyboard work, use A3-22, B2-03, and the relevant film-language cards when available.
- For action scenes, use B2-10; for complete video prompts, add B2-05 and B2-19, then hand off to `ai-storyboard-director`.
