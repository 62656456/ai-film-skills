# Director Thinking Spine

This file distills the user's draft files:

- The original private source drafts were distilled into this public reference; local source paths are intentionally omitted.


## Twelve Dimensions

1. Script interpretation: type/form, protagonist goal, arc, premise, plot opposition, supporting roles, survival/psychological/social/political dimensions.
2. Director path: character arc, dramatic arc, subtext idea, voice/attitude, deep value.
3. Visualization: previsualization, shot choice, continuous visual flow, storyboard thinking.
4. Mise-en-scene: setting, light, costume/makeup, performance, blocking inside shots and across shots.
5. Shot language: shot size, angle, movement, composition, focal length.
6. Editing/montage: narrative montage, expressive montage, intellectual montage, rhythm, meaning through juxtaposition.
7. Time control: real time, expansion, compression, reverse, acceleration, pause, flashback, flashforward, parallel timelines, subjective expansion/compression.
8. Emotional rhythm: entry emotion, escalation, peak, release, aftertaste; rhythm as rate of information-density change.
9. Sound design: sync, parallel, counterpoint, separation; sound can reveal, mislead, bridge, or withhold.
10. Color: emotion, worldview, conflict, character arc, value contrast.
11. Performance direction: objective, action verb, trust, restraint, listening, do not direct only emotion.
12. Theme/subtext: what is said vs meant, silence, restraint, contemporary pressure, value collision.

## Operating Flow

```text
Read material
-> choose director path
-> interpret survival/psychological/social/political dimension
-> define audience endpoint
-> build visual concept
-> design mise-en-scene, shot language, color, sound, and time
-> define performance actions
-> plan editing/montage
-> calibrate emotional rhythm
-> test theme/subtext
-> hand off to script output or storyboard engine
```

## Core Philosophy

- Audience experience first.
- Form is content.
- Restraint beats accumulation.

## Practical Additions

Use these as hard checks:

- **No default coverage**: reject plans that merely open wide, cut to over-shoulder dialogue, add reaction close-ups, and end on a pretty shot without a concept.
- **Action before emotion**: convert every emotional instruction into a playable action.
- **Object carries meaning**: whenever possible, let theme travel through an object, gesture, spatial relation, or withheld information.
- **Sound has a job**: every major scene needs a sound relation, including the possibility of silence.
- **Edit has a motive**: no cut without information, emotion, action, sound, eyeline, or rhythm motive.
- **Assumptions are labeled**: missing world, character, time, and production facts must be marked.
