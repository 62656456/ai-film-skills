# Director Agent｜完整生产分镜编译器

## 进入条件

只有用户明确要求完整分镜、shot list或生成就绪片段，并且本 Skill 已完成 `DIRECTOR_PLAN` 后使用。导演分析或纯剧本请求不得被强行扩展成分镜。

## 输入锁

- 完整剧本事实、逐字台词和用户锁定项；
- `DIRECTOR_PLAN` 中的观众终点、人物压力、视觉概念、表演、声音、剪辑和时间决定；
- 人物、场景、道具和光源状态；
- 总时长、画幅、帧率、平台已知限制；
- 入场和离场世界状态。

## 五列分镜

逐镜输出五列：`时间｜景别/机位/摄影机｜画面与人物动作｜台词｜声音`。

每个镜头必须有职责、首态、尾态、景别、方位、高度、焦段、焦点、运动起点/触发/路径/速度/终点、人物动作阶段、道具状态、声音、切点和连续性交接。时间轴无重叠、无缺口，总和精确等于点名时长。

## 世界投影

固定世界坐标、人物站位、朝向、视线、场景锚点、道具位置和光源方向；每次换机位重新计算屏幕左右、纵深、遮挡和出入画。不得为了画面标签移动世界实体。

## 六模块提示词

1. 生成任务；
2. 主要主体；
3. 场景状态；
4. 情绪目标；
5. 视觉风格；
6. 分段脚本。

六模块内部必须完整包含：时长画幅、主体场景、动作事件、摄影机、光影色彩、材质物理、情绪关系、尾帧、声音台词、负向约束十类信息。不得新增七至十章，也不得把数字10缩成标签。

## 表演、台词和声音

- 动作用可见起点、过程、受力、结果和反应表达；
- 台词逐字保留，按语速、停顿、动作和呼吸校验；
- 环境音和动作音有物理来源；
- 音乐、对白或环境声可以跨切接力，但必须写进入和退出；
- 默认不让生成模型制作字幕或乱码文字。

## 十二项质量门

1. 剧本事实、台词和顺序守恒；
2. 镜头职责和切点成立；
3. 调度、表演和摄影共同表达戏剧变化；
4. 景别、机位、焦段、焦点和运动具体；
5. 总时长与逐镜时间完全闭合；
6. 台词时间可执行；
7. 空间、轴线、视线、遮挡和出入画一致；
8. 人物身份、位置、姿态和关系连续；
9. 道具持有人、朝向和状态可追溯；
10. 光源、阴影、色温和曝光有依据；
11. 声音来源和跨切关系成立；
12. 五列、六模块、十类信息和场景专项负向全部完成。

失败时回到最早责任层修复。表格完整不能代替镜头成立，文字通过不能冒充生成成片或用户审美接受。

## 交付

- 完整 `DIRECTOR_PLAN`；
- 五列人读分镜；
- 每个生成片段的六模块提示词；
- 世界状态、相邻镜头/片段交接；
- 时间闭合、六模块6/6、十类信息10/10和十二项门回执。
