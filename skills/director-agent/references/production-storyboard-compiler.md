# Director Agent｜完整生产分镜编译器

## 进入条件

只有用户明确要求完整分镜、shot list或生成就绪片段，导演决定尚未解决，并且本 Skill 已在当前任务中完成 `DIRECTOR_PLAN` 后使用。导演分析或纯剧本请求不得被强行扩展成分镜。若用户已有获批的 `DIRECTOR_PLAN` 且只要求镜头扩写，本 Skill 必须保留该方案并停止在交接边界，不得重新解释、重建或覆盖；应交给匹配的分镜生产入口（若当前环境可用）。

## 输入锁

- 完整剧本事实、逐字台词和用户锁定项；
- `DIRECTOR_PLAN` 中的观众终点、人物压力、视觉概念、表演、声音、剪辑和时间决定；
- 人物、场景、道具和光源状态；
- 总时长、画幅、帧率、平台已知限制；
- 入场和离场世界状态。

## 五列分镜

默认逐镜输出五列：`时间｜景别/机位｜摄影机｜画面与动作｜台词/声音`。用户已锁定的合法表格格式优先，不为统一列名重排其镜头或遗漏内容。

每个镜头必须有职责、首态、尾态、景别、方位、高度、焦段、焦点、运动起点/触发/路径/速度/终点、人物动作阶段、道具状态、声音、切点和连续性交接。时间轴无重叠、无缺口，总和精确等于点名时长。

## 世界投影

固定世界坐标、人物站位、朝向、视线、场景锚点、道具位置和光源方向；每次换机位重新计算屏幕左右、纵深、遮挡和出入画。不得为了画面标签移动世界实体。

## 六模块提示词

1. 生成任务；
2. 主要主体；
3. 场景状态；
4. 情绪目标；
5. 视觉风格；
6. 分段脚本。

六模块内部必须完整包含：时长画幅、主体场景、动作事件、摄影机、光影色彩、材质物理、情绪关系、尾帧、声音台词、负向约束十类信息。不得新增七至十章，也不得把数字10缩成标签。

用户点名一个总时长时，先交一条覆盖该时长的完整母提示词，六模块只出现一次。内部切镜不自动变成多条提示词；只有用户要求逐镜交付或已核实平台限制时，才在母提示词后补充必要生产单元。用户可见正文使用人物、地点和道具的自然名称，内部资产编号、合同ID、路径与审核记录不进入提示词。

分段脚本每个时间段的标题直接显示景别/焦段、机位方位/高度/俯仰、摄影机路径与朝向、速度、焦点/遮挡接力及动作落点。具体摄影方案来自已完成的导演和镜头设计，不在编译时把复合路径压成“缓推”“跟随”，也不替固定镜头新增运动。只读最终提示词反向还原动作、摄影机与尾态，对照已选方案，发现丢失先修正文。

## 表演、台词和声音

- 动作用可见起点、过程、受力、结果和反应表达；
- 台词逐字保留，按语速、停顿、动作和呼吸校验；
- 环境音和动作音有物理来源；
- 音乐、对白或环境声可以跨切接力，但必须写进入和退出；
- 默认不让生成模型制作字幕或乱码文字。

## 十二项质量门

1. 剧本事实、台词和顺序守恒；
2. 镜头职责和切点成立；
3. 调度、表演和摄影共同表达戏剧变化；
4. 景别、机位、焦段、焦点和运动具体；
5. 总时长与逐镜时间完全闭合；
6. 台词时间可执行；
7. 空间、轴线、视线、遮挡和出入画一致；
8. 人物身份、位置、姿态和关系连续；
9. 道具持有人、朝向和状态可追溯；
10. 光源、阴影、色温和曝光有依据；
11. 声音来源和跨切关系成立；
12. 五列、六模块、十类信息和场景专项负向全部完成。

失败时回到最早责任层修复。表格完整不能代替镜头成立，文字通过不能冒充生成成片或用户审美接受。

## 交付

下面是完整生产任务所需的内部材料集合，用户可见交付按其点名范围选择。用户明确只要提示词时，只交完整可复制提示词；导演底稿、五列表、世界状态和审核回执保留为内部依据，不自动追加到正文。只要表格或局部修订时同样仅交对应层，不能用本清单扩大原请求。

- 完整 `DIRECTOR_PLAN`；
- 五列人读分镜；
- 覆盖点名总时长的一条六模块母提示词；明确需要时后附分条生产单元；
- 世界状态、相邻镜头/片段交接；
- 时间闭合、六模块6/6、十类信息10/10和十二项门回执。
