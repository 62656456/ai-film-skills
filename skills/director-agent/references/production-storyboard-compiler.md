# Director Agent｜完整生产分镜编译器

## 进入条件

这是明确分镜或提示词请求的自包含兜底，不是每次导演任务的必经步骤。用户要求分镜设计、完整分镜或 shot list 时，先复用已有可用 `DIRECTOR_PLAN`，只解决影响交付的缺失决定；有匹配分镜入口时交接给它，用户明确要求本 Skill 独立交付或没有可用分镜入口时按本文件完成。已有获批的 `DIRECTOR_PLAN` 不得重新解释、重建或覆盖。

分镜阶段交付人读镜头设计；提示词阶段仅在用户明确要求视频提示词或已授权流程进入视频生成时启用。导演分析、创意思路或纯剧本请求不得被扩展成分镜、提示词或媒体执行；平台和密钥不构成这些文本交付的前置条件。创意候选保持独立，只有用户明确采用的部分才进入主分镜或主提示词，采纳本身不授权生图或视频生成。

## 输入锁

- 完整剧本事实、逐字台词和用户锁定项；
- `DIRECTOR_PLAN` 中的观众终点、人物压力、视觉概念、表演、声音、剪辑和时间决定；
- 人物、场景、道具和光源状态；
- 总时长、画幅、帧率、平台已知限制；
- 入场和离场世界状态。

## 五列分镜

默认逐镜输出五列：`时间｜景别/机位｜摄影机｜画面与动作｜台词/声音`。用户已锁定的合法表格格式优先，不为统一列名重排其镜头或遗漏内容。

每个镜头写清观看职责、起止状态、具体摄影、人物动作及必要的道具、声音和前后衔接。运动起点、触发、路径、速度和终点只在有摄影机运动时展开，固定镜头不强填运动字段。时间轴无重叠、无缺口，总和精确等于点名时长；用户锁定的合理等长安排保持。

## 世界投影

固定世界坐标、人物站位、朝向、视线、场景锚点、道具位置和光源方向；每次换机位重新计算屏幕左右、纵深、遮挡和出入画。不得为了画面标签移动世界实体。

## 六模块提示词（仅提示词/视频生成阶段）

分镜设计或分镜列表请求不显示此模板。转成提示词时保持已确定的镜头顺序、时长、摄影与动作；只编译表达，不重新导演。

1. 生成任务；
2. 主要主体；
3. 场景状态；
4. 情绪目标；
5. 视觉风格；
6. 分段脚本。

六模块按适用性在内部核对：时长画幅、主体场景、动作事件、摄影机、光影色彩、材质物理、情绪关系、尾帧、声音台词、负向约束十类信息。不适用的信息不输出空项，不为凑数增加负向清单或新戏；不得新增七至十章或打印数字10映射。

用户点名一个总时长时，先交一条覆盖该时长的完整母提示词，六模块只出现一次。内部切镜不自动变成多条提示词；只有用户要求逐镜交付或已核实平台限制时，才在母提示词后补充必要生产单元。用户可见正文使用人物、地点和道具的自然名称，内部资产编号、合同ID、路径与审核记录不进入提示词。

分段脚本每个时间段的标题直接显示景别/焦段、机位方位/高度/俯仰、摄影机路径与朝向、速度、焦点/遮挡接力及动作落点。具体摄影方案来自已完成的导演和镜头设计，不在编译时把复合路径压成“缓推”“跟随”，也不替固定镜头新增运动。只读最终提示词反向还原动作、摄影机与尾态，对照已选方案，发现丢失先修正文。

## 表演、台词和声音

- 动作用可见起点、过程、受力、结果和反应表达；
- 台词逐字保留，按语速、停顿、动作和呼吸校验；在分段提示词中每段单列“台词：说话人／现场对白、内心音或旁白等发声方式｜起点秒数—落点秒数｜原句｜表达情绪与语气”，写清情绪如何落在音量、语速、停顿、气息或重音上；画面动作描述不夹入可被误读为台词的引语，无台词写“台词：无”；
- 每个时间段只写该段当前画面、必要状态与新发生动作。连续性承接前段的结果、站位、道具与情绪，不复述已完成事件；一条母提示词中的跨镜对白在起句段完整写一次，标总起止，后段只注明承接至何时，不再复制原句；独立生成单元才按进度分配实际发出的字句，不能从头重说；
- 内心音／旁白不驱动画内人物开口；直接修正与发声方式冲突的画面句，不用末尾“不对口型”抵消前面的张嘴动作。已定两条声音重叠时分别标时间与主辅，只有现场对白驱动口型；只参考音色时不照搬参考情绪。介绍性叙述自然表达，不擅自拔高为高潮；
- 环境音和动作音有物理来源；
- 音乐、对白或环境声可以跨切接力，但必须写进入和退出；
- 默认不让生成模型制作字幕或乱码文字。

## 十二项质量门

1. 剧本事实、台词和顺序守恒；
2. 镜头职责和切点成立；
3. 调度、表演和摄影共同表达戏剧变化；
4. 景别、机位、焦段、焦点和运动具体；
5. 总时长与逐镜时间完全闭合；
6. 台词时间可执行；
7. 空间、轴线、视线、遮挡和出入画一致；
8. 人物身份、位置、姿态和关系连续；
9. 道具持有人、朝向和状态可追溯；
10. 光源、阴影、色温和曝光有依据；
11. 声音来源和跨切关系成立；
12. 交付媒介符合请求：分镜阶段完成镜头设计；提示词阶段才检查六模块、必要十类信息、台词独立时间与表达情绪、分段事件不重演及场景专项负向。

失败时回到最早责任层修复。表格完整不能代替镜头成立，文字通过不能冒充生成成片或用户审美接受。

## 交付

- 分镜阶段：交付五列人读分镜，包含必要的表演、情绪、声音、时间与连续性交接；用户已有格式时沿用其格式。
- 提示词/视频生成阶段：交一条覆盖点名总时长的六模块母提示词，分段内画面与台词分开；只有用户要求或已核实限制才追加自足生产单元。
- 明确两者都要：先给分镜、再给提示词，保持同一镜头方案。
- `DIRECTOR_PLAN`、世界状态账本与质量门检查默认内部完成；用户要求导演方案、审计或确有未决问题时才显示对应内容。
- 不向用户附送6/6、10/10等格式回执，不把格式计数当镜头设计完成。
