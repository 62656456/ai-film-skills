# 参考到真人影像

借鉴二次元、插画、概念图或游戏视觉，或把幻想设计转为真人摄影质感时读取。

## 识别参考的作用

实际看图，分开提取轮廓、姿态动势、服装道具、场景尺度、构图、配色明暗、工艺与情境。用户锁定和可变化项分别继承；只有文字时说明依据文字，不假称看过图。

保留设计辨识度和幅度。高耸头冠、巨大披风、夸张肩甲、机械义肢与超常空间均可设计；不以实拍为名一律删成普通人物。参考的一项配色不自动授权继承原角色、脸、世界观和全部构图。原创改造使用用户采用的视觉机制。

## 给设计一个可拍的解释

| 图像语言 | 真人转译 |
|---|---|
| 夸张五官、头身、身体扭转 | 保留神态与姿态意图，转换为用户想要的人体比例与演员动作；有意的风格化真人夸张仍可保留 |
| 巨大披风、长袖和特殊衣形 | 设计裁片、层次、闭合、支撑、重量与垂坠；薄纱、缎、皮革和金属各有形状与反光 |
| 头冠、装甲、机械构件与武器 | 保留体量线条，明确固定点、关节、吊带、承重和使用姿态，不自动缩掉奇观 |
| 赛璐璐高光、阴影与发光色块 | 按空间重建光源、遮挡、反射、曝光和材料；科技或超自然光依用户世界规则，避免所有表面同样发亮 |
| 巨构、空岛、战场与神性空间 | 用尺度参照、遮挡、接触、镜头位置和空气透视建立可信布景或电影视效观感 |
| 图形纹样与复杂装饰 | 选择刺绣、镶嵌、编织、蚀刻等工艺，沿服装与物体结构展开；细节服从观看距离与主次 |
| 高饱和幻想配色 | 保持色彩冲击，区分固有色、光源和反射，以面积明度纯度组织，不靠全图降饱和证明真实 |

现实化不要求所有物件在真实历史存在。架空、科幻与神话按世界逻辑和拍摄观感判断；历史复原的事实主张另需依据。可以采用真人演员、实物服装与电影视效共同完成的成像目标，准确描述其属性。

## 在同一个摄影空间中组织

人物、服装、盔甲、道具、背景共享视点、尺度、光照与曝光，相互受光和接触；不能只把脸变真、其他部分仍是游戏材质。远近清晰度和细节随观察距离变化，避免所有表面同时镜亮、锐利、发光。

镜头或设备参照应对应透视、空间压缩、焦点或亮部响应，名称不是已完成真人化的证据。保留图形构图、奇幻轮廓与大胆色彩，不强制改成纪实抓拍。

选定的设计和参考职责应进入真正发送给模型的输入，不能只留在记录里。工具能力和参考权重未知时不编参数。

## 判断转译

先看原设计的视觉力度是否保住，再看人物、造型和环境是否遵守同一摄影逻辑，并判断整幅是否有美感。更真实、更漂亮和更接近参考可能是不同结果，按用户目标评价。

批准且合格的基准可用于继续编辑，失败结果只诊断；下一轮回原基准或完整文本。说明参考实际使用了哪些部分，没有图片输入就不声称借用了某张插画。
