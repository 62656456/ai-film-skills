# 风格、形象与服装的统一决策

## 何时加载

切换题材、形象或服装，创作风格变体、主题图组、明确混合风格，或将插画设计转成真人影像时加载；诊断“只是换背景”“技能互相打架”也适用。方案已清楚时不必额外加载。统筹风格是一套决策方法，不要求每图混入全部风格。本专项仅创作成年女性，年龄、肤色、体型与气质可以多样。

## 先辨清图片之间的关系

- **独立主题**：各图可有不同人物、服装与世界，分别确立审美，不强留上一张的脸、配色和道具。
- **同身份风格变体**：保持用户锁定的身份特征，按授权改变妆发、服装与环境；不能以换风格为由替换面孔，也不把服装变化误判为身份变化。
- **同故事不同图**：明确时间、地点与行动关系，继承已锁定的衣着、道具和光线连续性；景别与构图可按叙事需要变化。
- **明确混合风格**：先定主要世界与审美，再说明另一风格具体进入服装、建筑或材料的哪一层。用户未要求混合时，不主动把多个世界拼在一起。

## 按题材寻找可扩展的视觉维度

以下是选择入口，不是固定方向数或必装依赖。模块可用且确有帮助才读取；缺少模块时，仍用本技能的方法完成整体设计。

- **古风、武侠**：衣料、发式、器物与建筑尺度共同表现人物；按需补充古风服饰与武侠动作依据，古风不自动等于武侠。
- **赛博**：技术进入服装、身体与空间，协调发光材料与肤色；按需补充技术结构与未来材质依据，不固定霓虹雨夜。
- **都市高阶时尚**：协调剪裁、面料、妆发、姿态与留白，可直接设计；精致感不靠品牌名或堆首饰证明。
- **爱情、温暖**：以距离、触感、目光和生活动作选择光质；按关系需要补充亲密距离与光线依据，不强制暖黄或柔弱形象。
- **黑色、神秘**：组织遮挡、信息显隐、材质反差与视线；按信息显隐需要补充遮挡与光位依据，不等于整幅欠曝。
- **奇幻、仙侠**：人物尺度、服装与超现实空间遵守共同规则；按世界规则补充奇幻空间、尺度与材料依据，不自动混合文化符号。
- **史诗、战争**：协调规模、装备使用与群体层级；按规模与行动需要补充群体组织、军事服装装备依据，宏大空间仍须托住人物。

## 允许幻想幅度，转译真实成像

可以借鉴二次元插画的强风格和场景设定，夸张服装、道具与奇观完全允许。武侠古代、中世纪女将军、赛博、战争女神等均为开放例子，不构成清单。保持幻想设计的幅度：现实化的是材质、结构、重量、支撑、光线与表演，不是降成普通衣服或削弱奇观。

有指定插画参考时先实际看图，分别提取轮廓的识别作用、色块的观看秩序、空间的尺度关系及造型的世界规则；只有文字描述时明确据文字设计，不声称看过图片。具体转译方法按需读取 [插画参考到真人成像](reference-to-live-action.md)，不在此重复其执行细则。

## 明确哪些能变，再设计整幅画面

分别依据用户指令划定身份、妆发服装、环境道具、构图景别、光色材质的可变范围。身份锁定不等于服装固定，服装固定也不等于摄影固定。继承明确锁定；常规可逆选择自行完成，只询问会改变目标或已确认内容的缺口。

先安排色块比例、明度、纯度和邻接，再确定衣料、建筑等载体。检查皮肤、丝绸、金属、木石处于哪个光区，高光反射是否争抢脸部；同时组织轮廓、留白、前后景与观看路径。不固定颜色、焦距、道具或人物类型，换背景不能替代整体设计。

将有效建议汇成自然语言方案，删除冲突和重复。出图后检查整体关系，不能用“读过模块、身份一致”证明美感通过。不为每图强加结构化 JSON，不把入口变成固定栏目配额。
