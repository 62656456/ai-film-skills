# Creative direction lens

Use this lens before proposing or building a new interface or major redesign.

## Start from the product's own world

Name the product, its primary audience, the page's single job, and the real content it must carry. Derive the visual language from the user's tools, materials, vocabulary, pace, artifacts, and rituals. A direction that could be pasted onto an unrelated product is not specific enough.

## Make one signature decision

Choose one memorable device that expresses the product truth: a spatial model, a typographic behavior, a meaningful visualization, a material treatment, or one orchestrated interaction. Keep the surrounding system calm so the signature remains legible.

## Treat typography and structure as information

Assign distinct roles to display, body, and utility text. Let hierarchy, alignment, rhythm, and whitespace reveal priority. Use labels, dividers, numbering, and cards only when they encode a real relationship or task—not as decoration.

## Explore before committing

Privately compare at least two materially different directions. Define a compact token set for color, typography, spacing, radius, elevation, iconography, and motion. Reject a direction if its choices are generic defaults rather than consequences of the brief.

## Use restraint

Avoid indiscriminate gradients, glass panels, pills, rounded cards, fake metrics, neon-on-black styling, and scattered motion. Any of these can be correct when the subject demands it; none is a substitute for a product-specific point of view.

## Make the words useful

Write from the user's side of the screen. Use plain verbs, stable action names, specific errors, and real content. A label labels, an example demonstrates, and an action states what will happen.

## Verify the real result

Inspect the rendered interface at representative desktop and mobile widths. Test long translated strings, keyboard focus, reduced motion, empty data, loading, errors, and broken media. Source code alone cannot prove visual quality.
