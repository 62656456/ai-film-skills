# 道具资产参考图生成预设

> 当前包已经包含全部运行规则、参数依据和质量门；不使用未经用户确认的人脸或生物特征。

## 0. 加载规则与映射表

触发词命中 → 提取第1节字段 → 按第2节一致性锁定 → 第3–5节补足材质/光影/几何 → 选择平台和第7节模板 → 第8节验收 + 第9节负向 → 输出资产合同。资产编号：P01–P99，已确认编号不得复用。

| 节 | 独立输出 | 用途 |
|---|---|---|
| 1–5 | 资产描述、锁定规则 | 确定外观与状态 |
| 6–7 | 平台任务与提示词字段 | 直接生成参考图 |
| 8–9 | 验收和防崩 | 独立质量检查 |
| 10 | JSON 合同 | 供后续制作直接读取 |
| 11 | 类型适配字段 | 注入成片提示词的对应段落 |

## 1. 描述维度表

必填维度：类型、用途、尺寸、材质、颜色、重量感、状态/磨损、A面/B面、可读文字约束、初始持有人、朝向。

规则：用户未给出的关键维度标为 待确认，不臆造；已确认维度写入资产合同的 locked_features；描述按从整体到局部、从外观到材质、从静态到状态的顺序组织。

## 2. 一致性/状态规则

输出 A面、B面、侧面、关键细节与手持比例图；锁定尺寸、材质、磨损、可见面、扣件/开口和序列号位置。

变体规则：服装、受伤、昼夜、损坏等变化使用原编号后缀（如 P01b）并记录变化原因；不得悄然覆盖已审核版本。参考图一经通过资产审门，后续视频只可引用，不能重新发明外观。

## 3. 材质细化库

纸张纤维/折痕/卷边、金属拉丝/氧化、木材纹理、玻璃厚度/反射、布料织纹、皮革毛孔、塑料注塑线。

粗词禁止：高级材质、精致金属、真实皮肤、电影级纹理。每项必须改写为表面结构、磨损、反射、接触或微动态。材质与光源、接触点、重力方向一致。

## 4. 光影规则

柔主光、轮廓光、背景分离；反射材质保留真实高光而非镜面泛白。

标准资产图优先可读性而非情绪滤镜：主体与背景分离、关键细节不被死黑吞没、反射不遮挡结构；风格色彩作为可切换层，不能改变资产真实颜色记录。

## 5. 比例、透视与物理规则

手指与道具接触要有受力、遮挡、阴影和有限变形；重量、开合、液体、方向均符合物理。

禁止：结构断裂、无承重关系、穿模、悬浮、镜像/重复零件、透视与光影方向相互冲突。涉及手持、穿戴、打开或碰撞时，另交付一张交互校验图。

## 6. 平台适配

| 平台 | 输出重点 | 保留字段 |
|---|---|---|
| Midjourney | 英文主体、视角、镜头、材质、背景隔离 | aspect ratio / reference / version |
| 即梦 | 中文分段：主体—细节—状态—背景—光影—约束 | 资产编号与禁止项 |
| 可灵 | 图生视频前的多角度、材质、动作锚 | reference image / 状态起点 |
| Stable Diffusion | 英文正向/负向与可复现参数 | seed / model / reference / negative |

任何平台都不得改变 locked_features；平台版本能力未知时标记 unverified，不作为硬约束。

## 7. 资产提示词模板

适用模板：照片、武器、信件、设备、容器、食物、钥匙。

~~~
[prop资产编号]，[主体和用途]，[全维度描述]，
[正面/侧面/背面/局部或空间视角]，[真实材质和磨损]，
[标准布光和背景分离]，[比例/透视/物理规则]，
[目标平台参数]，[三层负向]。
~~~

每次输出至少包含：主参考图、必要的多视角/状态图、资产合同；不把视频动作或台词写入静态资产提示词。

### 模板A：照片/信件

~~~text
[Pxx名称]，[用途/尺寸/纸张类型/颜色/磨损]，[A面内容限制/B面内容或空白]，[折痕、卷边、污渍]，
A面+B面+侧面+手持比例图，柔主光+轮廓光+背景分离，纸纤维和受力弯曲可见，
锁定可见面、朝向、初始持有人和最终状态；不生成可读乱码文字。
~~~

### 模板B：武器/工具

~~~text
[Pxx名称]，[类别/用途/尺寸/重量感]，[金属/木材/皮革/涂层]，[磨损、接口、安全结构]，
左右侧面+细节+手持比例图，光源可见、边缘反射真实，锁定开关、开口、握持方向，
接触和承重可信，禁止漂浮、枪口/刃口方向错误、结构增殖。
~~~

### 模板C：设备

~~~text
[Pxx名称]，[功能/尺寸/材质/颜色]，[正面面板、背面接口、侧面厚度]，[磨损与状态灯]，
A面+B面+侧面+手持比例图，柔光控制反射，锁定按钮/接口/屏幕位置，
屏幕不生成乱码或无意义文字；电缆、散热、开合和重力方向一致。
~~~

### 模板D：容器/食物

~~~text
[Pxx名称]，[内容物/容积/材料/颜色]，[开口、封口、液位或食物状态]，[磨损/污渍]，
正面+背面+俯视+手持比例图，玻璃厚度/金属反射/液体重力真实，
锁定开合状态与朝向，禁止无故溢出、穿模、重复容器和不合逻辑反射。
~~~

### 模板E：钥匙/小物

~~~text
[Pxx名称]，[用途/尺寸/材料/颜色]，[齿纹/孔洞/刻痕/挂件]，[磨损状态]，
正反面+侧面+手指比例图，微距材质可读、边缘受光真实，
锁定 A/B 面、孔位、朝向和持有人；禁止变成多把、漂浮、文字乱码或过亮发光。
~~~
## 8. 质量检查清单

- [ ] 编号、版本、名称和用途唯一
- [ ] 第1节必填维度齐全或明确待确认
- [ ] 锁定特征跨视角一致
- [ ] 主体比例/透视/结构正确
- [ ] 材质可见且符合光源
- [ ] 接触、重量和阴影可信
- [ ] 关键面、朝向、开口/接口可辨
- [ ] 无多余肢体、物件、文字或水印
- [ ] 背景不抢主体且能辅助尺度
- [ ] JSON 合同可被下游解析

任一失败：状态为 rework；不进入 assets_approved。

## 9. 负向提示词

第一层（通用）：畸形、扭曲、多余肢体、错误手指、穿模、粘连、漂浮、重复元素、乱码、水印、低清、闪烁。  
第二层（prop）：穿模、漂浮、变多张、方向错误、崭新无磨损、发光、错误文字、尺寸漂移。  
第三层（画质）：CG感、3D animation、cartoon、anime、game render、plastic texture、waxy surface、low resolution、过曝、欠曝、过度锐化。

十条通用反面案例与三层负向写法详见 `references/NEGATIVE-CASE-BOOK.md`；本节的专属负向与之叠加，不可互相替代。

## 11. 类型适配字段

将道具参考图和状态账直接写入视频第③/⑥段或等价的动作与材质字段。

流程：资产生成 → 人审 assets_approved → 本地类型适配 → 10段式拼装 → 每镜引用资产编号 → 当前 Skill 的QC字段对照资产原图、实际尾帧和状态合同。若未获人审，不得进入正式镜头制作。
