# 道具资产参考图生成预设

> 当前包已经包含全部运行规则、参数依据和质量门；不使用未经用户确认的人脸或生物特征。

## 0. 加载规则与映射表

先确定本次媒介与改动范围。首次建立或重设计资产按下方剧本依据、描述、状态、材质/光影/几何和适用模板完成；局部修改只执行受影响部分，编号/文件查询直接回答。同一上下文已完整读取且未变的材料复用，不为改一处重新跑全流程。资产编号：P01–P99，已确认编号不得复用。

| 节 | 独立输出 | 用途 |
|---|---|---|
| 1–5 | 资产描述、锁定规则 | 确定外观与状态 |
| 6–7 | 平台任务与提示词字段 | 直接生成参考图 |
| 8–9 | 验收和防崩 | 独立质量检查 |
| 10 | JSON 合同 | 供后续制作直接读取 |
| 11 | 类型适配字段 | 注入成片提示词的对应段落 |

### 剧本先行与设计依据

首次建立或重新设定资产且用户提供剧本时，通读所提供的完整正文，理解世界规则、身份关系、剧情因果和时间线，再回到资产出现的场次设计。长剧本可分段读完并留简短连续性记录。局部修订复用本轮已读且未变的依据，只补读受影响原文、当前场次与必要前后状态；跨上下文或源文本变化时核对实际来源。不能只搜名称或读摘要就声称通读；只有片段时说明覆盖范围，未给剧本时依据当前描述设计。

内部保留简短设计依据：正文来源与阅读范围、相关场次、故事风格与成像方式、已确认事实、设计推定、关键未知。设计要能解释“为什么这个资产在此时此地是这个样子”；后文信息可帮助理解时代、身份与伏笔，但不能把后续损坏、受伤、天气或揭示结果提前带入当前场次。

用户与当前项目已经明确的画风优先；未指定成像方式时默认摄影写实，以可信结构、材质和光影呈现。悬疑、喜剧、奇幻等故事类型不自动等于某种画风。未提供细节或参考图时，从剧本与用途主动提出合理设计；影响剧情、身份、既有锁定事实的关键未知才需确认。一般颜色、材料、陈设、维护与使用细节可作有依据的设计推定，不一律退回待确认；推定不能冒充原文或用户已确认事实。

### 交付与成像模式

按用户点名的结果选择，不自动扩展为整套图：

- **提示词/设计说明**：交付当前请求的完整提示词、必要锁定信息与资产合同；尚未生成的参考图用空列表并标为计划，不填写虚构图片路径或声称图片通过。
- **实际参考图**：用户要求出图且有可用能力时生成所需图片；单图先交单图，整套资产请求或明确跨视角验收需求才扩展角度。实际看图后记录检查结果，用户批准前保持 pending_review。
- **诊断/局部修改**：围绕给定图或提示词指出可见问题、原因假设和对应修正；保留未点名的身份、风格与状态，不默认重做整套资产。

依第0节确定成像方式（无指定时默认摄影写实），再按本包 [电影画面关系判断](references/cinematic-image-direction.md) 设计画面关系与负向。新设计、整体改写或整体诊断读取此参考；局部修订仅补读相关判断，已读且未变时复用；编号/文件查询不必加载。模板中的多格、人物尺度、标准布光和材质纹理均按用途选取，不因模板固定成套、写实或宏大。

新设计、整体重设计或完整设定板任务读取 [道具造型与设定表达](references/prop-design-and-reference.md)：先完成形制与设计意图，再选解释它所需的视图。已有明确外观只做局部派生时直接继承基准，补读对应方法，不重开造型。

道具资产的重点是**整体设定与能解释设计的细节**。整套设定任务按需要组织整体外形、区别正反/侧面的视图，以及关键结构和材质的局部图；避免只有一张漂亮摆拍，也避免每个物件都机械套相同多视图。用户只要一张时，可按用途交整体图或一张设定板；用户指定单视角、单个局部或不拼图时严格遵从。视图数量由需要回答的设计问题决定，不固定格数，不自动扩成多张。

设定板的每个局部都对应同一件道具上的明确位置与当前状态，整体/视角图用于定位，局部用于解释构造。完整设定图可按表达需要使用简短部位名、引线、材料说明与有依据的比例/尺寸，不必等用户逐项点名；用户明确无字时不添加。纯外观参考和剧情画面不自动叠加说明。精确尺寸无依据时标为设计推定或留空，工程性能与可制造性不因生成图存在而成立。

## 1. 描述维度表

设计依据按用途覆盖：类型、用途、时代、使用者、形体比例、尺寸、结构/操作关系、材质、颜色、重量感、状态/磨损、必要视面、文字、持有人与朝向；不逐字段堆进提示词。先决定与使用方式和世界美术一致的轮廓、体块及辨识特征，再细化接口与新旧程度。磨损有使用位置与原因，不给所有道具统一做旧，不加入尚未发生的损坏或泄露后续线索。

规则：按第0节区分剧本事实、设计推定与关键未知；只把用户或剧本已确认的维度写入 locked_features，待审设计不冒充已锁定。描述按从整体到局部、从外观到材质、从静态到状态组织，并对应当前剧情节点。

未锁定形制时先给出能转成画面的设计理由：哪些比例、构件、材料连接和使用痕迹使它属于这个时代、这个使用者和这个用途。普通生活道具允许朴素，但不能只给通用商品换颜色。按钮数量、刻槽数等只在识别、操作或既有设计需要时明确，不用随手编出的微小数字代替整体设计；一旦选入本轮设计，各视图必须一致。

### 细节图选择

从剧情和使用方式选择真正需要看清的部位：识别身份的轮廓/标记，决定操作的扣件、铰链、接口、开口或握持区，决定材料的边缘厚度、接缝、加工与表面响应，以及本场已发生的使用痕迹。只取适用项；普通纸张、钥匙和食物不硬加机械结构。每个局部说明“展示哪里、要回答什么、与整体如何对应”，不能用满屏划痕、装饰线或微纹理冒充结构细节。

用户认可整体并希望“再细一点”时，保持已认可的造型、材料、风格、视图组织与使用方式，优先提升关键连接/接缝、边缘厚度、材料分界、握持/挂接等部位的可读性。用合适的局部占比、景深、受光与精简标注把既有设计讲清，不以新增零件、更多格子、满屏划痕、重度做旧或过度锐化代替细致；明确需要更多图时再扩展数量。

不同状态只在用途需要时并列并标明区别。设定任务需要解释连接或开合且依据成立时，可采用结构示意、剖视或拆解；不机械禁止，也不为炫细节给普通物品添加机关。隐藏结构和后续状态须与当前剧情可见参考分开，不能把幕后说明或设定板排版直接注入正片。

## 2. 一致性/状态规则

按用途选择整体、A面、B面、侧面、关键细节或比例图；近似平面物可优先正反与厚度局部，立体物选择能说明体量和关键结构的角度。只有需要握持校验且尺度适合时采用手持图，单图请求不自动扩为整套。锁定尺寸、材质、新旧状态、可见面、扣件/开口和序列号位置；局部放大保持左右、形状、部件数量和材料分界一致，只改变展示尺度，不新增零件。

有基准外观图时，以同一图和已定结构派生所需视图；可见局部优先从基准提取或定点细化，不仅靠重写文字重新造物。看不见的背面/内部须有额外依据或标为候选补设计。只有文字时先统一设计再编排设定板，用户只要一张不擅自增加基准图；一次生成整板仍要逐格核对，文字说“同一个”不等于实际一致。

变体规则：服装、受伤、昼夜、损坏等变化使用原编号后缀（如 P01b）并记录变化原因；不得悄然覆盖已审核版本。参考图一经通过资产审门，后续视频只可引用，不能重新发明外观。

## 3. 材质细化库

纸张纤维/折痕/卷边、金属拉丝/氧化、木材纹理、玻璃厚度/反射、布料织纹、皮革毛孔、塑料注塑线。

关键材料用其厚度、边缘、接缝、加工和表面响应解释；“高级材质、精致金属”等质量词不能替代具体设计。先读懂形体和连接，再按展示尺度补纹理；材质与光源、接触点、重力方向一致。

## 4. 光影规则

柔主光、轮廓光、背景分离；反射材质保留真实高光而非镜面泛白。

标准资产图优先可读性而非情绪滤镜：主体与背景分离、关键细节不被死黑吞没、反射不遮挡结构；风格色彩作为可切换层，不能改变资产真实颜色记录。

## 5. 比例、透视与物理规则

手指与道具接触要有受力、遮挡、阴影和有限变形；重量、开合、液体、方向均符合物理。

禁止：结构断裂、无承重关系、穿模、悬浮、镜像/重复零件、透视与光影方向相互冲突。涉及手持、穿戴、打开或碰撞时，说明接触、比例、受力与状态衔接；文字任务交相应设计或提示词。只有本次已要求实际图片且现有视图不足以判断交互时，才提出必要补图，遵守用户指定的数量和范围，不因描述交互自动出图。

## 7. 资产提示词模板

适用模板：照片、武器、信件、设备、容器、食物、钥匙。

以当前交付用途和设计意图起笔，再写决定身份的形制、结构与材料，最后安排视图和必要保持项。探索造型、确认外观、解释结构、局部修改是不同任务；不把设定图一律写成灰底商品摄影，也不把全部检查项贴到提示词末尾。短段落或结构化写法均可，按任务复杂度组织，不固定字数。

~~~
[交付类型与画幅]，[道具自然名称、时代/使用者/用途及设计意图]。
[整体轮廓和体块比例、辨识特征、关键结构/操作关系、材料组合与当前状态]。
[需要的整体视图与局部；各自解释什么，如何对应同一基准设计]。
[适合设定表达的成像、布光和版式；按需使用简短标注或纯无字画面]。
[必须保持的特征、实际参考职责及针对当前问题的少量约束]。
~~~

各模板依据剧本与使用状态填写，用户可复制提示词使用自然名称，编号保留在后台合同。人物的三视图加中景要求不套用到道具。

按已选模式交付提示词、实际参考图或诊断/局部修改及相应资产合同；多视角/状态图仅在本次用途需要时生成。单幅单视角任务只取指定视角；一张完整设定板可含本次需要的多视图与局部。不把视频动作或台词写入静态资产提示词。

## 8. 质量检查清单

- [ ] 编号、版本、名称和用途唯一
- [ ] 首次设计已读提供的正文；局部修订已核对受影响原文与必要连续性；阅读范围和设计依据可核对，没有只凭名称套模板
- [ ] 第1节维度已区分事实、合理设计推定与关键待确认；当前状态符合剧情时间线
- [ ] 成像方式符合用户要求，无指定时采用摄影写实
- [ ] 锁定特征跨视角一致
- [ ] 主体比例/透视/结构正确
- [ ] 材质可见且符合光源
- [ ] 接触、重量和阴影可信
- [ ] 关键面、朝向、开口/接口可辨
- [ ] 设定任务交代整体形制及必要结构；每个局部有位置和用途，没有用重复角度或纹理堆砌冒充细节设计
- [ ] 形体、材料和操作关系体现用途与美术方向；没有靠任意按钮/刻槽数量冒充设计，也没有把设定板自动降成商品照片
- [ ] 局部与整体是同一版本，左右、部件数量、尺寸关系和材料分界一致；单局部请求未擅自扩表
- [ ] 手持、开合、剖面、拆解及后续状态只在需要且依据成立时出现；说明图与正片可见状态参考分开
- [ ] 无多余肢体、物件、文字或水印
- [ ] 背景不抢主体且能辅助尺度
- [ ] JSON 合同可被下游解析

按交付阶段检查：提示词只验证设计与合同，未生成/未见图片的像素项目标 not_evaluated；实际图片的适用项目失败时为 rework。只有实际参考图通过用户审阅才进入 assets_approved，文本通过不替代看图。

## 9. 负向提示词

三层仅作内部风险来源，最终提示词只保留当前图需要的限制；不机械叠加无关清单。无人无手的静态道具图不写肢体、手指或视频闪烁；需要的结构标注和用户要求的文字不属于负向。

第一层（通用）：影响当前设计的变形、穿模、无依据漂浮/重复、错误文字或水印。
第二层（prop）：穿模、无依据漂浮或数量变化、方向错误、与锁定不符的新旧/磨损、非设计发光、错误文字、尺寸漂移。新出厂物品保留新表面，旧物按使用史分配磨损；灯具、状态灯和能量道具保留有依据的发光与对应照明，真实塑料保留其粗糙度和注塑特征。\
第三层（画质）：先按用户成像方式选择。摄影写实排除不符合目标的卡通化、蜡皮、合成渲染感；三维动画、二维动画/插画保留选定风格，排除结构错误、风格漂移或意外写实化。各模式按需要限制低清、遮蔽结构的过曝/欠曝、过度锐化；不一律禁止动画、卡通或真实塑料材质。

需要诊断具体错误时再读 `references/NEGATIVE-CASE-BOOK.md`；选用相关项，不把案例或数字参数当作统一配方。

本 Skill 自己完成资产审核字段、编号登记、参考输入说明和对照复核要求；后续制作只读取本 Skill 已交付的资产合同，不得重写锁定特征。

`view_plan` 按需记录各视图的 `purpose`、`view`、`detail_region`、`state` 和 `reference_role`（外观参考或说明用）；单图可只有一项，旧合同无此字段仍可读取。未生成时只记录计划，不编造图片路径。关键局部须能对应整体；多格设定板、剖面和状态对照交接时注明用途，实际生产按需选择适用参考，不把整板当作单幅电影画面。

`design_intent` 保存当前设计理由和参考职责，旧合同无此字段仍可读取；它不自动将候选外观升级为 `locked_features`。

## 11. 类型适配字段

把道具的必要外观、空间或状态以及实际参考图绑定到当前分镜/提示词的对应内容；用户正文使用自然名称，资产编号仅在后台合同中映射，沿用已确定的交付结构。

正式生成前，实际参考图须经用户审阅进入 assets_approved；后续生成保持已批准的外观与状态，并对照实际结果核验。尚未审阅的资产保持候选，可用于标明假设的候选分镜、设计稿和文本提示词，不以缺少图片或人审为由拒交所请求的文本；这些文本不提升资产批准状态，也不授权直接进入正式生成。
