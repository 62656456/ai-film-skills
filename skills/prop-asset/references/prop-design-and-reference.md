# 道具造型与设定表达

用于新道具、整体重设计和完整设定图。按当前用户/剧本的用途、时代、使用者与美术方向决定外形，再选择能把设计讲清楚的视图；普通局部修订继承已有设计，不重走探索。

## 从设计理由到可见形体

先明确这件道具怎样被携带、握持、放置或使用，哪些特征承担识别与剧情作用。把美术方向转成轮廓、体块比例、连接方式、材料分界与触碰区域；只采用当前对象适用的内容。风格来自这些相互关联的选择，不只是给通用商品换色、加划痕或贴装饰。

新设计可以比较少量形制方向，再在本次请求中选定一个候选展开；用户只要一件时不默认交一整套不同款式。已有参考负责已确认的轮廓/结构，材质或时代参考只提供相应启发，不自动覆盖形制。精确复原真实型号时依据可核对材料，缺少证据的部件不能编造为事实。

设计顺序：整体识别与轮廓 → 主要构件的连接/操作 → 材料与工艺 → 有作用的局部细节。先使整体有设计，再决定哪些局部值得放大。普通物件可以朴素、完整、新净；不强制奇形、损坏、机械机关或装饰性做旧。数量、尺寸和纹样在功能/识别需要时明确，选定后跨视图保持，不将随意编出的螺钉数或刻槽数当作审美目标。

## 按用途选择图，而不是统一套商品照

| 当前用途 | 图应回答的问题 |
|---|---|
| 造型探索/概念主图 | 轮廓、比例、时代与性格是什么；主要材料怎样共同形成它 |
| 外观确认 | 主要面与侧面如何连接；哪些轮廓/构件使它可辨 |
| 完整设定板 | 用必要的整体视图、正交或近正交视图、结构/材料局部解释同一个设计 |
| 局部细节图 | 该部位在哪里、由什么材料构成、怎样连接或使用；保持基准外观与状态 |
| 剧情使用参考 | 与已定人物/环境的尺度和接触是否成立；不把说明排版带入正片 |

版式有主次：主要形制足够大，辅助角度补充真正缺失的面，局部围绕有意义的连接与材料组织。不是所有物件都需要正反侧顶，也不是所有设定板都无字。设定用途可使用少量清楚的部位名、引线、材料标注或有依据的尺度；用户要求无字时改用位置/视图对应表达。不要添加广告口号或凭空编造工程性能。

已经认可的设定板只要求更细时，保留这套表达方式，先检查重要部位是否因占比过小、焦点或高光遮挡而难辨；针对接缝/压框、密封边、接口、铰接、握持或挂接等适用部位改善展示尺度与材质区分。不默认把已认可设计重新概念化，也不把增加磨损、螺钉或细线当作细节提升；数量与整体版式继续服从当前范围。

需要说明隐藏连接、开合或内部构造且设计依据充分时，可提供说明用的剖面/拆解；它们不等于剧情当前可见状态。不能为“丰富细节”给未设定道具加入秘密机关，也不以拒绝一切标注/拆解让设计无法解释。

## 从同一基准派生

已选基准图和结构描述应实际进入后续生成输入，不只写“保持一致”。已可见的局部优先提取原图或在原图上定点细化；纯裁切可以保留原有细节，但不会创造更多真实细节。未见侧面/内部需要其他参考或明确候选补设计，不声称是从主图核实得到。

整板一次生成可作为候选；逐格核对后再使用。不同视图允许透视与可见数量变化，但实体部件总数、连接、材料边界、左右手性与状态不能漂移。主图有六枚按键而正对同一区域的局部变成七枚，属于一致性错误；不能把文字约束存在当成通过，也不能从错误局部反向改写基准。只修问题格或关键部位，保留正确设计；额外生成数量仍服从用户范围。

## 让提示词表达设计

先写成品用途和设计意图，再写关键形制/材料，随后安排本张视图、参考职责和需要保持的事实。用正面可见描述组织画面，负向只针对真实风险；不固定字数，也不把工程账本、资产编号、审门字段和完整检查表放进生成正文。

例如“为常在户外记录声音的人设计便携设备”，应先决定便携方式与操作布局怎样影响形体、开口和保护结构，再选视图解释它；不是先写一枚红键、五枚黑键、三道槽再称为完整造型设计。本例只说明设计次序，不替代当前剧本，也不规定所有录音机的功能或形制。

实际用图后区分：文字自洽、外形表现、局部一致、结构可用及用户接受。漂亮的设定板仍可能存在无法装配的部件、错误标注或跨视图漂移，不能称已具备工程制造精度。
