# 战争技能统一交付合同

本文件统一类型参数、视觉顾问、图像与视频补充的输出。旧“12节”文件名保留为包内兼容引用；当前按交付模式执行，不强迫所有任务外显12节或十段。

## 先确定模式

| 用户要的结果 | 第一交付 | 仅在需要时补充 |
|---|---|---|
| 战争光色、空间或类型参数 | 当前场景的具体设计与style接口 | 来源、QC和连续性 |
| 人物服装、道具或场景参考 | 对应设计、完整自然提示词或实际图片 | 外观状态、必要多视角 |
| 故事/小队/战斗画面 | 可读的事件、人物关系、环境与实际画面 | 关键证据、方向与受力审查 |
| 已确定镜头的战争视觉补充 | 当前镜头的空间、动作、光色、材料、尾态与声场 | 有依据的时间及平台适配 |
| 纯场景或空镜 | 空间与光线 | 不自动加入人物、冲突、台词 |
| 已有图片局部修改 | 点名部位的实际修图 | 其余身份、构图和状态保持 |

图像请求需实际生成并看像素；只有提示词就只能称提示词交付。具体生成工具不可用时说明边界。生成服务权限与费用不由本包授予。

## 数字10作为信息内核

按媒介使用，不要求十段外显：

1. 画幅与媒介；视频才需时长、帧率、切点。
2. 主体与空间：前后层次、可达入口、站位和尺度；无人场景可以为空主体。
3. 行动或状态：姿态、受力、道具当前状态；视频再处理时序。
4. 摄影：机位、透视、景别、焦点；视频按需补运镜与轴线承接。
5. 光色：真实或世界观允许的光源、遮挡、反射与色彩用途；数字参数有依据或注明设计选择。
6. 材料与物理：表面差别、连接、接触、重力、介质反馈。
7. 情绪与注意力：用可见关系表达，不用导演名或质量词代替。
8. 连续性：人物/器材位置、朝向、持有、光源、环境痕迹及下一状态。
9. 声音：视频或用户要求时给声场、台词时间窗及声音延续。
10. 针对当前失败的负向、质检与未验证项。

用户可复制正文使用自然名称；C/S/P编号只在后台资产映射或用户明确要的技术合同里出现。完整视频任务已有六大模块母提示词合同的，保持其外层，不增加第七至十模块。本包不自动扩大为完整剧本或逐镜分镜。

## 类型参数兼容接口

保留字段名及style_module字符串身份。style_route的值记录本次实际采用的规则或包内出处，不只是抄字段路径；原六个键保留，sound可追加。只有用户或下游需要结构化参数时才展示JSON，普通图片结果先展示图片。

~~~json
{
  "style_module": "war-design",
  "version": "1.0.0",
  "style_source": "本包类型设计预设及逐项注明的视觉依据",
  "style_status": "bundled_design_preset_not_externally_validated",
  "style_route": {
    "camera": "",
    "color": "",
    "scene": "",
    "action": "",
    "material": "",
    "continuity": "",
    "sound": ""
  },
  "qc_contract": {
    "checklist": "references/visual-review.md",
    "negative_layers": "references/NEGATIVE-CASE-BOOK.md"
  }
}
~~~

此处空值仅是接口示意。实际输出填当前任务需要的值；不适用项标明不适用。style_status只声明类型参数的来源性质，不表示所有顾问事实或历史图像均未接受；实际知识、结构/文字检查、生成图片、用户接受和动态验证应分别记录。ready_for_prompt只表示参数或提示词准备完成；rework指出具体失败字段。

## 连续性与声场

人物位置、身形、朝向、服装开合、装备归属、道具可见面、受损状态、光源与地标应可追溯。动作结束状态作为下一镜输入，但静帧不虚构实际尾帧或已经发生的时间变化。

风、远近炮声、机械、布料、呼吸、脚步、金属接触可按场景采用；声源位置和遮挡对应空间。先保留已有台词与声音决定，按字数、语速、停顿和身体动作检查是否放得下。语速与原8秒模板均为起草依据，不是刚性限制。需要后期配音时说明，不因本包统一加“无字幕”覆盖用户字幕要求。

## 媒介、平台和负向

真人、三维动画、二维插画和用户其他成像方式分别保持其风格。人物形体、连接、透视和前后状态都要自洽，动画与干净材料本身不是质量缺陷。三层负向为通用结构、当前军事对象、目标成像失败；只用相关项，不堆全部禁止词。

中文图像工具可用自然段表达空间与结构；动作输入按起点、传导和终点组织；静帧或关键帧保留参考用途及外观锁定。平台支持的时长、参数、负向语法与参考机制按实际接口核实，未知不写成硬限制。

## 检查

- 画面有明确用途和注意力。
- 用户锁定、主体数量与媒介得到保持。
- 空间、比例、行动方向及受力一致。
- 关键连接、形制和材料有足够可见面积。
- 光源、反射与环境反馈有依据。
- 参数、提示词、实际图像和用户接受分层。
- 真实请求包含所有必要事实，不用未附入的合同替代。
- 故事任务检查可见证据，纯场景与静物不强制剧情。
- 视频才检查时间、动作衔接与声场，不以一图认证动态。
- 发现失败时指出位置、原因假设和修正方案。

无动机运镜、无依据光色、过度雾化、无意义浅景深、固定导演模板、未经验证的时间事实及错误参考继承均应回到本次任务修正。
