# 反面案例与按媒介修正

本表只针对当前任务的实际缺陷。例子不是固定焦段、时间、配色、人数或全局负向。

| 错误写法/现象 | 失效原因 | 可执行修正 |
|---|---|---|
| 电影级、专业、战术感 | 没有可见落点 | 说明人物目的、形制、连接、材料、空间与观看关系 |
| 像某导演 | 名字不能代替设计 | 从具体参照中选择有依据的注意力、遮挡、光源或节奏 |
| 镜头慢慢移动 | 路径和触发不清 | 视频写起点、终点、跟随对象、路径、速度与切点；静帧不加运镜 |
| 越暗越神秘 | 关键人物和装备丢失 | 指定必须看清的局部，用实用光或背景分离，不整图提亮 |
| 强烈冷暖对比 | 色彩无功能 | 对应当前光源和注意力，不强制橙蓝 |
| 宏大战场 | 没有尺度参照 | 用人物、设施、地形与遮挡表达相对尺度，焦段随任务决定 |
| 他把物件交给对方 | 持有与接触不清 | 用自然名称说明持有人、可见面、接触、受力与最终状态 |
| 紧张、恐惧 | 表演没有来源 | 具体描述事件触发、目光、动作中断或身体反应 |
| 火光/爆炸/霓虹很多 | 无来源装饰 | 让光源、冲击点、碎片、反射与人物处境形成因果 |
| 与上一镜一致 | 实际输入没有锁定事实 | 附上真实参考或内联所需角色、装备和前态 |
| 全部道具只有一次变化 | 机械限制故事 | 允许任务需要的多次变化，逐项保持状态可追溯 |
| 动画或整洁设备一律排除 | 忽略成像与使用状态 | 排除实际错误，保留用户画风及符合剧情的新旧状态 |

## 三层负向

- 通用：多肢、穿模、漂浮、接触错误、透视和重复物。
- 对象：本次服装、器材、场景或动作中高概率失败。
- 成像：与目标画风不符的材质/渲染，以及遮蔽关键内容的过曝、欠曝或锐化。

视频可按时间段指出具体风险，静态图不强制添加逐段时间。无来源雾气、装饰爆炸、无意义慢镜和无功能色彩应修正其原因；有具体叙事理由时不一律禁止。
