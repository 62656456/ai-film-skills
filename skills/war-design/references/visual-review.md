# 以可见效果验收

本检查用于已经看到的实际图片。提示词、文件存在和自动校验只能证明准备过程，不能替代图像验收。

## 先看整张，再看关键部位

整张检查：一眼是否读得出主体、职业/场所、注意力和空间；故事任务还要读出人物正在做什么、什么刚改变了他，以及哪件具体物品或空间状态提供证据；是否符合用户选择的风格、尺度与构图；是否出现未要求的拼贴、海报文字、界面或角色。

关键部位检查按本次任务选择，不让每一张图承担全部项目：

| 对象 | 需要真正看清的结果 | 典型失败 |
|---|---|---|
| 人物服装 | 衣身、袖部、背心、带具彼此分层，重要轮廓正确，脸和手可读 | 布料融入装具、同一袖口变形、额外肢体、僵硬无处境 |
| 穿戴连接 | 包袋有固定关系，线缆/绑带有去向，重物有承托 | 胸前附件悬浮、耳机线断在空中、扣带穿过皮肤 |
| 场景 | 用途、结构、工作面、通道及尺度能读出 | 满地随机军箱、管线在空中结束、门与设备互相堵死 |
| 器材 | 大形、分件、软硬材料和关键接口清楚，有接触阴影 | 面罩与头盔粘成一块、软管和线缆融为一体、重复旋钮、漂浮 |
| 光色与材料 | 光源可解释，主体与背景有层次，材料反射不同 | 所有东西同样亮或同样脏、雾气遮住检查重点、全图同样锐利 |
| 概念设计 | 有统一结构主题和尺度，原创/概念身份清楚 | 空贴发光条、密集假机械、将概念图写成现役证据 |
| 故事画面 | 主角、未完成动作、异常证据和人物反应同处一个空间，下一步有方向 | 中性摆拍、正常工作没有变化、全靠不可读文字或氛围猜剧情 |
| 低光小队 | 正常曝光可辨认本图需要展示的人数、轮廓、手和关键装备 | 用黑影掩盖人数、装备或身份缺失 |
| 系列身份 | 对照实际输入逐人核验，区分配装家族与精确角色 | 错误锚点继续传递；合同未提交却只归因模型 |

针对失败，写“位置—可见现象—对用户目标的影响—修改要求”。不能只写得分或“有AI感”。在自然观看尺寸检查整体，必要时放大原图核对连接；超出像素分辨率的细节标为看不清，不猜。

## 修正与停止条件

主体错、身份丢失、关键结构穿模或连接不成立是返修项；光色偏好或轻微背景瑕疵应说明是否影响本轮验收。优先对确定的问题做一次定向修订，保持其他有效部分；确实无法局部恢复时再换构图或重生，并说明取舍。

故事任务中，如果看不出异常是什么、人物没有因证据产生反应、关键物与人物分处不相关的画面区域，也属于返修项。先改变事件瞬间、人物关系或构图，不能只增加烟雾、颗粒和电影黑边。

用户要求看清的部件不能通过裁掉、加雾、变暗或改变为背影来逃避修正。结构通过后不无理由反复生成。如果经过针对性修正仍失败，交付可见版本并明确其未通过项，不掩饰成最终完成。

## 记录与能力边界

先判断像素支持的状态，再看故事文字；不能从“轮胎印存在”直接验证“车辆刚经过”，不能从“灯亮着”验证“刚来电”。批次需对照主要动作、相机高度、主体占比、画幅、光源与空间关系；重复构图应有本次叙事理由。

记录测试简述、实际读取的Skill版本及文件哈希、实际提示词、模型执行入口、输入参考、生成路径、观察与返修、最终候选和用户接受状态。单批多张图属于该批样本，不能当多个独立真实任务。

若要比较新旧方法，使用同一简述和同一模型条件分别生成；没有对照就只说明本技能本轮产出，不宣称效果提升了某个比例。静态穿戴和道具通过不能代替多人动作、动态连续性和真实装备考据通过。
