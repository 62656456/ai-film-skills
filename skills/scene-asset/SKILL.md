# 场景资产参考图生成预设

> 当前包已经包含全部运行规则、参数依据和质量门；不使用未经用户确认的人脸或生物特征。

## 0. 加载规则与映射表

确认资产设计任务 → 通读已提供剧本并建立设计依据 → 选择交付与成像模式 → 读本包画面关系判断 → 提取第1节字段 → 按第2节一致性锁定 → 第3–5节补足材质/光影/几何 → 选择平台和第7节适用模板 → 按当前交付阶段执行第8节检查与第9节负向 → 输出资产合同。资产编号：S01–S99，已确认编号不得复用。

| 节 | 独立输出 | 用途 |
|---|---|---|
| 1–5 | 空间描述、锁定规则 | 确定地理和可拍性 |
| 6–7 | 平台任务与提示词字段 | 直接生成参考图 |
| 8–9 | 验收和防崩 | 独立质量检查 |
| 10 | JSON 合同 | 供后续制作直接读取 |
| 11 | 类型适配字段 | 注入成片提示词的对应段落 |

### 剧本先行与设计依据

用户提供剧本时，第一步先通读所提供的完整正文，理解故事气质、时代与世界规则、人物身份和关系、剧情因果及时间线，再回到资产出现的场次设计外观、空间或状态。长剧本可分段读完并保留简短连续性记录，不能只搜资产名或读摘要就声称通读；只有片段时说明实际阅读范围，未给剧本时依据当前描述设计，不虚构已读全本。

内部保留简短设计依据：正文来源与阅读范围、相关场次、故事风格与成像方式、已确认事实、设计推定、关键未知。设计要能解释“为什么这个资产在此时此地是这个样子”；后文信息可帮助理解时代、身份与伏笔，但不能把后续损坏、受伤、天气或揭示结果提前带入当前场次。

用户与当前项目已经明确的画风优先；未指定成像方式时默认摄影写实，以可信结构、材质和光影呈现。悬疑、喜剧、奇幻等故事类型不自动等于某种画风。未提供细节或参考图时，从剧本与用途主动提出合理设计；影响剧情、身份、既有锁定事实的关键未知才需确认。一般颜色、材料、陈设、维护与使用细节可作有依据的设计推定，不一律退回待确认；推定不能冒充原文或用户已确认事实。

### 交付与成像模式

按用户点名的结果选择，不自动扩展为整套图：

- **提示词/设计说明**：交付当前请求的完整提示词、必要锁定信息与资产合同；尚未生成的参考图用空列表并标为计划，不填写虚构图片路径或声称图片通过。
- **实际参考图**：用户要求出图且有可用能力时生成所需图片；单图先交单图，整套资产请求或明确跨视角验收需求才扩展角度。实际看图后记录检查结果，用户批准前保持 pending_review。
- **诊断/局部修改**：围绕给定图或提示词指出可见问题、原因假设和对应修正；保留未点名的身份、风格与状态，不默认重做整套资产。

依第0节确定成像方式（无指定时默认摄影写实），再按本包 [电影画面关系判断](references/cinematic-image-direction.md) 设计画面关系与负向。此参考在设计、改写、诊断时读取；编号/文件查询不必加载。模板中的多格、人物尺度、标准布光和材质纹理均按用途选取，不因模板固定成套、写实或宏大。

## 1. 描述维度表

必填维度：空间类型与用途、时代/地点、使用者与活动状态、尺度、布局与必要设施、维护程度、材质、时间、天气、光照、色彩、前中后景深度、固定场景标志、日常使用及剧情事件痕迹。

规则：按第0节区分剧本事实、设计推定与关键未知；只把用户或剧本已确认的维度写入 locked_features，待审设计不冒充已锁定。描述按从整体到局部、从外观到材质、从静态到状态组织，并对应当前剧情节点。

### 从剧情到可见环境细节

按“场所用途与使用者 → 必要布局、公共/生活设施及陈设 → 使用与维护状态 → 天气作用 → 已发生事件 → 可见光照后果”推导画面。每项关键细节说明因何存在、出现位置和合适强度，优先让空间能承载本场人物行动；人读说明与提示词直接写实际可见结果，不堆空泛的真实感、生活感。

生活感包括使用、整理、清洁、维修、生产和自然作用，既可整洁有序，也可磨损凌乱。器具、家具、食物与衣物依据住户、职业、经济条件和正在进行的活动选择，不把例子变成固定采购清单。正常开放的公共空间依据时段与用途安排使用人群和设施；用户要无人空场、假期或停用状态时不强加人群，仍可用设施及使用痕迹交代用途。

天气必须落到具体表面与空间：积沙受地形、风向及遮挡影响，扬尘强度服从当前天气；雨痕、滴水、潮湿及反射发生在实际暴露或传递水分的位置，不因室外下雨就让封闭室内遍地积水。事件痕迹对应已经发生的剧情与维护历史；弹痕、破损、血迹、庆典食品等会暗示具体事件的细节须有叙事依据，不能凭题材标签添加或提前泄露后续情节。

## 2. 一致性/状态规则

同一场景锁定平面布局、入口/出口、主光方向、固定标志、材质老化程度；按用途选择建立全景、反向建立、关键局部或用于连续性核对的空间图，单图请求不自动扩为整套。

变体规则：服装、受伤、昼夜、损坏等变化使用原编号后缀（如 S01b）并记录变化原因；不得悄然覆盖已审核版本。参考图一经通过资产审门，后续视频只可引用，不能重新发明外观。

## 3. 材质细化库

建筑混凝土/金属/木材、地面颗粒与湿度、植被层次、天空介质、水体反射、雾的密度与光散射。

粗词禁止：高级材质、精致金属、真实皮肤、电影级纹理。每项必须改写为表面结构、磨损、反射、接触或微动态。材质与光源、接触点、重力方向一致。

## 4. 光影规则

主光方向+环境光+阴影方向明确；室内注明实用灯与门窗传入光，室外注明时段/天气。按光源位置、遮挡、材质粗糙度和湿度说明受光与反射；雨夜室内分别核对窗外天光/路灯和室内灯的来源、方向及亮度关系，不把雨夜一律做成同一种蓝光滤镜。

标准资产图优先可读性而非情绪滤镜：主体与背景分离、关键细节不被死黑吞没、反射不遮挡结构；风格色彩作为可切换层，不能改变资产真实颜色记录。

## 5. 比例、透视与物理规则

一点/两点/三点透视必须与机位匹配；地平线、消失点和人物尺度不能冲突。

禁止：结构断裂、无承重关系、穿模、悬浮、镜像/重复零件、透视与光影方向相互冲突。涉及手持、穿戴、打开或碰撞时，另交付一张交互校验图。

## 6. 平台适配

| 平台 | 输出重点 | 保留字段 |
|---|---|---|
| Midjourney | 英文主体、视角、镜头、材质、背景隔离 | aspect ratio / reference / version |
| 即梦 | 中文分段：主体—细节—状态—背景—光影—约束 | 资产编号与禁止项 |
| 可灵 | 图生视频前的多角度、材质、动作锚 | reference image / 状态起点 |
| Stable Diffusion | 英文正向/负向与可复现参数 | seed / model / reference / negative |

任何平台都不得改变 locked_features；平台版本能力未知时标记 unverified，不作为硬约束。

## 7. 资产提示词模板

适用模板：室内、室外、太空、城市、自然、废墟、幻想。

~~~
[场景自然名称]，[剧情节点、用途与使用状态]，[全维度描述与有依据的环境细节]，
[正面/侧面/背面/局部或空间视角]，[真实材质和磨损]，
[标准布光和背景分离]，[比例/透视/物理规则]，
[目标平台参数]，[三层负向]。
~~~

每个模板须写入适用的设施/陈设、使用与维护痕迹、天气落点及当前事件状态，不机械填满所有类别。提示词使用场景和物件的自然名称，编号仅作后台绑定。

按已选模式交付提示词、实际参考图或诊断/局部修改及相应资产合同；多视角/状态图仅在本次用途需要时生成。下列多格写法用于整套资产任务，单图任务只取指定视角；不把视频动作或台词写入静态资产提示词。

### 模板A：室内

~~~text
[场景名称]，[时代/地点/空间类型/尺度]，[左中右与前中后结构]，[建筑/地面/道具材质]，
[主光方向/实用光/色温/光比]，[固定标志、入口出口、人物尺度参照]，
建立全景+反向建立+关键局部，透视与消失点统一，真实材质/阴影/环境介质，三层场景负向。
~~~

### 模板B：室外

~~~text
[场景名称]，[地貌/地点/时间/天气]，[地平线、前中后层、尺度锚点]，[地面/植被/建筑材质]，
[太阳方向/云层/环境光/阴影方向]，[主色与强调色来源]，建立全景+反向建立+局部图，
~~~

### 模板C：太空/未来

~~~text
[场景名称]，[飞船/基地/异星空间]，[左中右固定结构、入口、设备、深度]，[金属/面板/岩石材质]，

~~~

### 模板D：城市

~~~text
[场景名称]，[城市年代/功能区/天气/时段]，[街道/建筑/前景遮挡/交通层]，[材质和磨损]，
[路灯/招牌/窗光/湿面反射的来源]，[地平线和人物尺度]，建立全景+街面视角+局部标志，

~~~

### 模板E：自然/废墟

~~~text
[场景名称]，[自然地貌或废墟类型]，[前中后景、破损结构/植被/水体]，[材质和天气痕迹]，
[太阳/天光/火光来源]，[尺度参照与固定标志]，全景+反向建立+关键局部，
风化、塌陷、积水、尘埃与植被符合剧情时间线及维护状态；有剧情依据的新置物、修缮或整洁区域可保留，禁止物理不通的结构与无因做旧。
~~~

### 模板F：幻想空间

~~~text
[场景名称]，[世界规则/空间类型/尺度]，[左中右/前中后结构]，[建筑、地面、雾气、能量材质]，
[可见光源/色温/光比]，[固定符号和人物尺度]，建立全景+反向建立+关键局部，
超自然元素也必须有位置、边界、发光来源和交互痕迹，禁止无理由泛光/空间折叠。
~~~
## 8. 质量检查清单

- [ ] 编号、版本、名称和用途唯一
- [ ] 已通读提供的正文，阅读范围、相关场次与设计依据可核对；没有只凭名称套模板
- [ ] 第1节维度已区分事实、合理设计推定与关键待确认；当前状态符合剧情时间线
- [ ] 成像方式符合用户要求，无指定时采用摄影写实
- [ ] 锁定特征跨视角一致
- [ ] 主体比例/透视/结构正确
- [ ] 用途、使用者、设施及维护痕迹成立；生活感没有被偷换为统一脏乱或空洞样板间
- [ ] 天气影响的位置、方向、强度与材质成立，室内外光源和受潮边界明确
- [ ] 人群与事件痕迹符合本场状态，无新增剧情或后续信息提前泄露
- [ ] 材质可见且符合光源
- [ ] 接触、重量和阴影可信
- [ ] 关键面、朝向、开口/接口可辨
- [ ] 无多余肢体、物件、文字或水印
- [ ] 背景不抢主体且能辅助尺度
- [ ] JSON 合同可被下游解析

按交付阶段检查：提示词只验证设计与合同，未生成/未见图片的像素项目标 not_evaluated；实际图片的适用项目失败时为 rework。只有实际参考图通过用户审阅才进入 assets_approved，文本通过不替代看图。

## 9. 负向提示词

第一层（通用）：畸形、扭曲、多余肢体、错误手指、穿模、粘连、漂浮、重复元素、乱码、水印、低清、闪烁。  
第二层（scene）：空间折叠、门窗/楼梯不连通、透视错误、无来源雾光、无尺度参照、固定标志漂移。  
第三层（画质）：先按用户成像方式选择。摄影写实排除不符合目标的卡通化、蜡皮、合成渲染感；三维动画、二维动画/插画保留选定风格，排除结构错误、风格漂移或意外写实化。各模式按需要限制低清、遮蔽结构的过曝/欠曝、过度锐化；不一律禁止动画、卡通或真实塑料材质。

十条通用反面案例与三层负向写法详见 `references/NEGATIVE-CASE-BOOK.md`；本节的专属负向与之叠加，不可互相替代。

## 11. 类型适配字段

将场景参考图和空间图直接写入视频第②/⑤段或等价的空间与光线字段。

流程：资产生成 → 人审 assets_approved → 本地类型适配 → 10段式拼装 → 每镜引用资产编号 → 当前 Skill 的QC字段对照资产原图、实际尾帧和状态合同。若未获人审，不得进入正式镜头制作。
