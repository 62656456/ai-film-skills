# 场景资产参考图生成预设

> 当前包已经包含全部运行规则、参数依据和质量门；不使用未经用户确认的人脸或生物特征。

## 0. 加载规则与映射表

触发词命中 → 提取第1节字段 → 按第2节一致性锁定 → 第3–5节补足材质/光影/几何 → 选择平台和第7节模板 → 第8节验收 + 第9节负向 → 输出资产合同。资产编号：S01–S99，已确认编号不得复用。

| 节 | 独立输出 | 用途 |
|---|---|---|
| 1–5 | 空间描述、锁定规则 | 确定地理和可拍性 |
| 6–7 | 平台任务与提示词字段 | 直接生成参考图 |
| 8–9 | 验收和防崩 | 独立质量检查 |
| 10 | JSON 合同 | 供后续制作直接读取 |
| 11 | 类型适配字段 | 注入成片提示词的对应段落 |

## 1. 描述维度表

必填维度：空间类型、时代/地点、尺度、材质、时间、天气、光照、色彩、前中后景深度、固定场景标志。

规则：用户未给出的关键维度标为 待确认，不臆造；已确认维度写入资产合同的 locked_features；描述按从整体到局部、从外观到材质、从静态到状态的顺序组织。

## 2. 一致性/状态规则

同一场景锁定平面布局、入口/出口、主光方向、固定标志、材质老化程度；输出建立全景、反向建立、关键局部与可用于视频的空间图。

变体规则：服装、受伤、昼夜、损坏等变化使用原编号后缀（如 S01b）并记录变化原因；不得悄然覆盖已审核版本。参考图一经通过资产审门，后续视频只可引用，不能重新发明外观。

## 3. 材质细化库

建筑混凝土/金属/木材、地面颗粒与湿度、植被层次、天空介质、水体反射、雾的密度与光散射。

粗词禁止：高级材质、精致金属、真实皮肤、电影级纹理。每项必须改写为表面结构、磨损、反射、接触或微动态。材质与光源、接触点、重力方向一致。

## 4. 光影规则

主光方向+环境光+阴影方向明确；室内注明实用光，室外注明时段/天气。

标准资产图优先可读性而非情绪滤镜：主体与背景分离、关键细节不被死黑吞没、反射不遮挡结构；风格色彩作为可切换层，不能改变资产真实颜色记录。

## 5. 比例、透视与物理规则

一点/两点/三点透视必须与机位匹配；地平线、消失点和人物尺度不能冲突。

禁止：结构断裂、无承重关系、穿模、悬浮、镜像/重复零件、透视与光影方向相互冲突。涉及手持、穿戴、打开或碰撞时，另交付一张交互校验图。

## 6. 平台适配

| 平台 | 输出重点 | 保留字段 |
|---|---|---|
| Midjourney | 英文主体、视角、镜头、材质、背景隔离 | aspect ratio / reference / version |
| 即梦 | 中文分段：主体—细节—状态—背景—光影—约束 | 资产编号与禁止项 |
| 可灵 | 图生视频前的多角度、材质、动作锚 | reference image / 状态起点 |
| Stable Diffusion | 英文正向/负向与可复现参数 | seed / model / reference / negative |

任何平台都不得改变 locked_features；平台版本能力未知时标记 unverified，不作为硬约束。

## 7. 资产提示词模板

适用模板：室内、室外、太空、城市、自然、废墟、幻想。

~~~
[scene资产编号]，[主体和用途]，[全维度描述]，
[正面/侧面/背面/局部或空间视角]，[真实材质和磨损]，
[标准布光和背景分离]，[比例/透视/物理规则]，
[目标平台参数]，[三层负向]。
~~~

每次输出至少包含：主参考图、必要的多视角/状态图、资产合同；不把视频动作或台词写入静态资产提示词。

## 8. 质量检查清单

- [ ] 编号、版本、名称和用途唯一
- [ ] 第1节必填维度齐全或明确待确认
- [ ] 锁定特征跨视角一致
- [ ] 主体比例/透视/结构正确
- [ ] 材质可见且符合光源
- [ ] 接触、重量和阴影可信
- [ ] 关键面、朝向、开口/接口可辨
- [ ] 无多余肢体、物件、文字或水印
- [ ] 背景不抢主体且能辅助尺度
- [ ] JSON 合同可被下游解析

任一失败：状态为 rework；不进入 assets_approved。

## 9. 负向提示词

第一层（通用）：畸形、扭曲、多余肢体、错误手指、穿模、粘连、漂浮、重复元素、乱码、水印、低清、闪烁。  
第二层（scene）：空间折叠、门窗/楼梯不连通、透视错误、无来源雾光、无尺度参照、固定标志漂移。  
第三层（画质）：CG感、3D animation、cartoon、anime、game render、plastic texture、waxy surface、low resolution、过曝、欠曝、过度锐化。

十条通用反面案例与三层负向写法详见 `references/NEGATIVE-CASE-BOOK.md`；本节的专属负向与之叠加，不可互相替代。

## 11. 类型适配字段

将场景参考图和空间图直接写入视频第②/⑤段或等价的空间与光线字段。

流程：资产生成 → 人审 assets_approved → 本地类型适配 → 10段式拼装 → 每镜引用资产编号 → 当前 Skill 的QC字段对照资产原图、实际尾帧和状态合同。若未获人审，不得进入正式镜头制作。
