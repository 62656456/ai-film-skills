# 同一空间的多视角与多机位参考图

本专项只在用户提出常规主图＋反打以外的多角度、多机位、九宫格或复杂空间覆盖时展开。普通场景设计沿用主入口的一张主图＋一张反打，共两张独立图片，不因空间复杂自动扩表。用户明确只要单图/局部时不补齐两张；仅改光色时沿用已有机位。点名九宫格时交3×3九格，其他数量、独立图片或组合板按用户要求；九格不是数量上限，也不是日常默认。

## 先有一个空间，再决定从哪里看

从已确认图纸、资产图、文字与实际场次建立共同空间依据。场景主图提供美术基准；平面/布局描述提供几何依据，二者职责不同。一张透视图只证明其可见范围，背墙、拐角后、遮挡物后与高处未见结构仍是未知或候选推定。若用户只允许还原现有证据，保留未见区域为空缺并说明无法完成的视向；若允许补设计，可合理补足并显式标明，不虚称精确还原。

内部用简短布局记录足够的空间关系：

- 稳定方向：入口墙/窗墙/内墙或实际方位；复杂场所可用一致的平面坐标和楼层标高，单位与原点写清。画面左、右不能充当世界坐标。
- 边界与连接：房间轮廓、墙段、门窗洞口、走廊转角、楼梯起止及平台、栏杆/夹层开口。L形、环廊与复式先有连通关系，不假装一个相机能看穿所有区域。
- 固定锚点：大件家具、立柱、设备、固定标志的位置、朝向与体积；用能够互相辨认的锚点校对各视图，不因换角度移动它们。
- 同一状态：时段、天气、光源位置与开关、物件开合和既有损坏。通常所有格表示同一时刻；时间变化研究另行说明，不能混作机位变化。

几何未提供精确尺寸时只写有依据的相对关系或标注估计，不堆虚假精度。新设计的共同依据可作为本轮候选保持项使用，不自动成为用户已批准资产。

## 每个机位提供不同的空间信息

每个视图写清：摄影位置、朝向的目标/墙面、镜头高度与俯仰、取景或视角宽窄、主要可见锚点、重要遮挡、这张图补足的空间信息。复杂机位按需要增加相机与障碍物的关系，不能只写“正面、侧面、背面”。

九宫格可从下列观看关系中选择并替换，但不是固定九种标签：

| 观看关系 | 主要用途 |
|---|---|
| 入口向内、主要使用区反看入口 | 建立出入和主要空间关系 |
| 两个不同角落的斜向全景 | 解释相邻墙面、大件前后与体量 |
| 沿长边/短边的侧向观察 | 展示纵深、侧面和遮挡变化 |
| 门洞、走廊转角或柱间的越界观察 | 解释空间相接与视线受限 |
| 场内可成立的高机位俯看 | 解释布局、楼层与平台关系 |
| 低位或功能区附近的观察 | 解释高低关系、尺度及局部空间特征 |
| 从夹层/楼梯平台看下层，或从下层看上层 | 解释复杂垂直连接 |

根据实际空间选出有用的组合；不必平均绕圈，不固定每45度一张，不强求每个房间都含楼梯或高台。用户要九机位时，每格须有实际摄影位置或视向变化及有效信息；同机位变焦、裁切、换滤镜不算新增机位。若真实约束只能支持较少有效位置，说明缺口或重新分配可行视向，不能穿墙或换房间凑九格。

相机须在所定义空间中有位置和观察路径。高机位可以是室内可成立的架设位置，并不要求现场本来就有阳台；但不得落在实墙、楼板或天花板内。需要去顶、移墙或剖切才看清的图，明确标为技术布局图，不能冒充真实摄影机位或默默替代用户要求的九个电影视角。空场景不强造人物关系轴；已有表演轴时记录机位所在侧，跨侧视图可用于参考，但不自动构成可直接剪接的正反打序列。

## 空间不变，画面随相机重新推导

换机位重新判断画面左右、远近尺寸、遮挡、镜面反射、可见墙面与受光。固定窗光在不同视角中可以从画面左侧变到右侧，实际窗户和太阳/灯位不因此移动。反打不是把原图水平翻转；广角与较长焦段变化不能拉长房间、改变家具尺寸或打通原来不通的门。

有平面坐标且相机不倾斜时，可直接用视向核对左右：若向前为 `(dx,dy)`、z向上，画面右方在平面上为 `(dy,-dx)`；目标相对相机的向量与它点积为正才在右侧。例如朝南看时东侧在画面左，不能写成右侧。俯仰、滚转、反射或明显透视遮挡再按实际几何处理；空间方位不确定时用“转角墙遮住桌子”等可核对关系，不凭空指定左右。

机位之间通过共享锚点互相校核：不要求每格都看见全部锚点，但整组需要足够的重叠关系，能够判断它们属于同一空间。主图、反向和侧向有共同家具/墙段；拐角或楼层通过门洞、楼梯平台等连接锚点接上。若某格只剩微距材质且无法定位，它是细节图，不能冒充完整空间机位。

## 生成与参考输入

没有基准图时，先完成共同布局和美术设计，再按请求直接给提示词或生成候选。用户只要求一张九宫格时，不擅自多生成一套基准图；同一条提示词先写共享空间，再逐格明确九个机位。有现成基准图时实际附带合适参考，并说明其职责。独立生成多张时，后续视图沿用同一基准与布局，不让每张靠同一句文字重新发明场景。

复杂空间的一次九宫格生成不能保证一致。实际逐格检查门窗、家具、楼层、光源和遮挡，发现问题只定点修复问题格；保留有效视图。需要额外图片、工程或白模时先按当前请求范围处理，不能因多视角自动启动三维预演。九宫格用于比较机位；制作时按需要使用对应单格原图，不把九格拼图直接当成单幅电影场景输入。若只有拼图，说明裁出的单格分辨率限制，不将放大后的像素数当作新增细节。

## 提示词组织

共享场景只写一次，每格只写机位和由该机位产生的画面关系：

~~~text
一张3×3九宫格场景机位参考板，九格展示同一处[场景自然名称]，同一时刻、同一美术设计和空间布局。
共同空间：[稳定方向、门窗/通路、固定家具及其朝向、层高或楼层连接]。
共同视觉：[情绪、美术大形、材质与色块、有来源的光影关系]。
从左上到右下：
[逐格写摄影位置→看向哪里、镜头高度/俯仰、取景、可见锚点与关键遮挡，共九格；按实际空间设计，不套固定房间]。
保持建筑、物件位置与数量、光源世界位置及场景状态。各格只改变摄影机；按当前请求使用无字画面或简短自然名称机位标签。
~~~

提示词不打印后台资产编号、空字段、内部自检或无关禁令；用户已锁定的构图只约束其对应视图，不把其他机位强行拉回原图。多张独立提示词各自含足够的共享事实和明确参考，不能只写“同上一张”。

## 内部合同与验收

按需记录 `spatial_contract`：`basis`、`world_orientation`、`boundaries_and_connections`、`fixed_anchors`、`lighting_state`、`unseen_or_inferred_regions`。

每个 `view_plan` 项记录 `view_name`、`camera_position`、`look_at`、`height_and_pitch`、`framing`、`visible_anchors`、`occlusion`、`purpose`、`reference_role`；已有合同缺少这些字段仍可读取。图片生成前 `reference_images` 为空，机位计划不算图片成果。

文字阶段核对几何自洽、覆盖意义、数量/版式和保持项。实际图片逐格核对，再对相邻/共享锚点视图交叉检查；格数正确不能替代同空间一致性。只有真实图片经用户接受，才提升资产状态；文字、像素、用户接受分开记录。
