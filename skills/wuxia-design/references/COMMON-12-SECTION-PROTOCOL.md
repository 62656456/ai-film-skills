# 12 节类型 Skill 共享执行规约

本文件是所有 `*-design` 类型 Skill 的共同细则。各类型文件必须仍包含 0–11 节；本文件只避免重复抄写通用规范，不能替代类型文件的真实色彩、导演、场景或负向参数。

## 统一加载与输出

1. 用户触发词命中类型文件的 frontmatter 后，先加载第 0 节与第 2、3、4 节；仅在分镜/视频任务时加载第 1、5、6、7、11 节。
2. 生成 `style_route`（可观察参数）与 `style_module`（分镜可用的镜头、空间、动作规则），而非直接覆盖剧本、资产或分镜决定。
3. 缺少场景、时长、主体、资产编号或目标平台时，输出缺口字段；禁止以“电影感”“高级感”等空词补全。

## 通用时间线与动作规则

- 8 秒结构只是一种短镜头起草模板：`建立焦点 → 发生变化 → 完成动作 → 反应/台词/尾帧`。它不是通用时长、动作数或切点规则；镜头时长和节拍须由题材、情绪、视点、台词时序与实际生成可行性共同决定。时长改变时重排节拍，不得机械等比压缩。
- 单一镜头段只允许一个主要运镜；一个 AG-CLIP 内不得隐藏硬切。对话默认固定机位或极缓、明确方向的推移。没有叙事动机不得推、拉、绕、变焦。
- 道具以 `初始持有人/可见面/朝向 → 变化节点 → 最终持有人/可见面/朝向` 记账；每段都要写禁止的错误状态。

### 微动作分类表

| 主体 | 基础动作 | 进阶微动作 | 必须检查 |
|---|---|---|---|
| 对话人物 | 视线、呼吸、点头、手部停顿 | 吞咽、指腹摩擦、重心微移、欲言又止 | 不抢台词、不改变站位 |
| 太空/失重 | 扶手接触、躯干转向 | 安全带受力、浮物因推力缓慢漂移 | 不能把失重写成无原因漂浮 |
| 战斗/移动 | 重心转移、脚步落地、手臂发力 | 发力从脚到髋到肩传导、衣料滞后 | 武器方向、接触和惯性正确 |
| 道具 | 接触、握持、提起/放下 | 手指压强、纸面弯曲、盖子阻尼、收纳变形 | 只能有一个可追溯状态变化 |

### 速度限定表

| 速度 | 适用 | 禁止 |
|---|---|---|
| 极缓 | 察觉、恐惧、压抑对话 | 用于奔跑、格斗或多次状态变化 |
| 缓慢 | 试探、递交、仪式 | 与快速切换镜头冲突 |
| 自然 | 日常步行、常规操作 | 不写“自然且激烈”这种矛盾词 |
| 快速 | 只能写明确发力起点、路径、终点 | 不能作为“有动感”的空词 |

## 通用材质与物理规则

| 粗略词（禁） | 可执行词（例） | 交互验证 |
|---|---|---|
| 金属 | 哑光不锈钢、拉丝方向、边缘氧化、冷凝水 | 高光随光源移动，不穿模 |
| 布料 | 经纬纹、缝线、压褶、磨损区、受力褶皱 | 肢体屈伸时褶皱传导 |
| 地面 | 潮湿粗糙混凝土、积尘、擦痕、局部反射 | 接触点有阴影和压力感 |
| 纸张 | 哑光纤维、折痕、卷边、褪色 | 指压产生有限弯曲 |
| 霓虹 | 可见灯管/招牌、局部染色、湿面反射 | 不是无来源泛光 |

禁止：手指或道具穿模、粘连、漂浮、无故增殖、方向反转、接触不受力、光源与阴影方向冲突。

## 质量门与反面案例

未同时通过以下项目，不得输出 `ready_for_prompt`：

- [ ] 光源可在画内找到或有世界观依据
- [ ] 景别、构图、运镜各有叙事动机
- [ ] 色彩有来源、区域分配和叙事功能
- [ ] 焦段、机位、景深和轴线明确
- [ ] 人物比例、站位、高度关系不漂移
- [ ] 前/中/后或左/中/右空间可区分
- [ ] 道具状态可追溯
- [ ] 材质与接触物理可信
- [ ] 台词时间窗可说完，且不生成字幕/乱码
- [ ] 未使用空质量词替代参数

假电影感补查：无来源光、滤镜代替色彩叙事、无动机慢推、过度雾化、过亮霓虹、无意义浅景深、导演姓名代替技术写法。

反面写法必须改为参数：`“很压迫”→“24mm、主体居中、逆光轮廓、前景遮挡、暗部60%”`；`“慢慢移动”→“沿 Z 轴匀速推镜，中景至中近景，3 秒”`。

## 统一负向三层

1. 通用防崩：人物/手指/肢体错误、穿模、粘连、漂浮、多余物体、文字水印、闪烁、主体漂移。
2. 类型专属：由类型文件第 9 节提供。
3. 画质负面：CG 感、3D animation、cartoon、anime、game render、plastic texture、waxy skin、low resolution、over-sharpen、oversaturated、fake bloom。

## 平台与 7-Agent 接口

- 即梦：中文语义分段；将最重要的时空、主体、动作、镜头和约束置前；复杂镜头明确“内切”与每段时长。
- 可灵：突出动作起点、传导、终点，材质与环境交互；一段一个主要动作。
- Midjourney：以静帧/资产为主；英文、镜头和构图先行，参数仅写平台认可的格式。
- SD：英文参数化强；保留 prompt/negative prompt/seed/reference 的可复现账本。

| 消费方 | 字段 | 必须保留 |
|---|---|---|
| 02-art-director | asset_contract / style_module | 资产编号、来源、版本、审核状态 |
| 03-storyboard | style_module | 镜头、空间、动作、导演“可观察方法” |
| 04-prompt-engineer | style_route | 色彩、材质、模板字段、平台适配、资产引用 |

## 连续性与声音

- 尾帧写为：`人物位置 + 姿态 + 道具最终状态 + 光源方向 + 背景锚点 + 下一镜入口`。
- 台词估算：`秒数 = 汉字数 ÷ 语速 + 停顿次数 × 停顿秒数`；慢/克制 2.5–3.2 字/秒，自然 3.5–4.2 字/秒，急促 4.5–5.5 字/秒。台词必须留出动作和呼吸。
- 环境音只描述可听见的声源；台词默认后期配音，禁止生成字幕或屏幕文字。

### 环境音速查

| 场景 | 声源层次 |
|---|---|
| 基地/工厂 | 低频设备、通风、液压、脚步回声、冷凝水 |
| 飞船/太空舱 | 风机、继电器、面板提示、服装摩擦；舱外真空不直接传声 |
| 城市/雨夜 | 交通远近层、雨、招牌电流、排水、脚步 |
| 异星/荒野 | 风、砂石、植被/生物、装备、远处地貌回响 |
| 室内关系戏 | 布料、餐具、钟表、房间底噪、呼吸和停顿 |
