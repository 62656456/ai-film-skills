# 反面案例与改写账本

所有类型/资产 Skill 的第9节使用本表作为十条共同反面案例；类型专属负向仍保留在各自文件内。

| 错误写法 | 为什么错 | 正确写法 |
|---|---|---|
| 电影感、氛围感、高级感 | 没有可执行参数 | 焦段、机位、光源、光比、区域分配和材质各写明 |
| 很像某导演 | 姓名不是镜头指令 | 写该导演对应的负空间、实用光、对称/遮挡或色彩方法 |
| 镜头慢慢移动 | 无方向、速度、起止 | 沿 Z 轴匀速推镜，中景至中近景，3 秒 |
| 画面很暗很神秘 | 暗部和光源不受控 | 台灯来自左侧，暗部60%，光比8:1，线索受暖光照明 |
| 冷暖对比很强 | 没有色彩功能 | 主色、强调色、色温与强调色服务对象明确 |
| 宏大史诗场面 | 没有尺度关系 | 24mm、人物占画面1/10、前中后景与远景尺度锚点 |
| 他把道具交给对方 | 无持有人、面向、状态 | P01 A面朝镜头在C01右手，翻转后由C02左手收入口袋 |
| 角色紧张 | 情绪没有行为 | 视线停顿、吞咽、指腹压住衣角，台词前留0.4秒呼吸 |
| 华丽魔法/霓虹光 | 无来源泛光 | 可见法杖/招牌为光源，局部染色并在湿面/雾中产生对应反射 |
| 保持上一镜一致 | 没有可核对对象 | 写明上镜尾帧的人物位置、朝向、道具、光源方向和背景标志 |

## 三层负向格式

第一层：通用防崩；第二层：类型/资产专属；第三层：画质负面。每个时间段另写该段的具体禁止项，不能只把所有风险堆在末尾。
