# 自主成片可审计判断链

## 目录

1. 目标与事实
2. 剧本理解
3. 导演判断
4. 镜头组设计
5. 提示词映射
6. 生成与剪辑
7. 返工闭环

## 1. 目标与事实

先把任务压缩为可观察结果：观众要看到一条讲清剧情、镜头流畅、连续可信、声音完整的可播放成片。

建立四栏：

- **已验证事实**：当前剧本、人物、场景、道具、时间、批准资产、用户锁定结构。
- **未知项**：尚未确定但会影响剧情、费用、权限或交付的内容。
- **假设**：为了推进而暂定、可被后续画面证伪的判断。
- **惯例**：知识库、旧项目和行业方法，只能作为候选方法，不能替代当前剧情判断。

知识库提供经验、失败样本和方法；剧本提供本次事实；导演判断拥有镜头设计权。

## 2. 剧本理解

对每个可生成片段回答：

1. 这一段唯一的戏剧事件是什么？
2. 每个人物此刻想得到什么？
3. 谁控制空间，控制权何时变化？
4. 哪个动作真正改变局面？
5. 哪个信息必须让观众明确看见？
6. 情绪在哪一刻转向？
7. 声音在哪一刻进入、打断或延续？
8. 片段首态与尾态分别是什么？

若这些答案不清楚，禁止进入提示词阶段。

## 3. 导演判断

先决定观众的观看路径，再决定摄影机：

- 观众先知道空间、人物、动作、物件还是反应？
- 哪个信息需要隐藏，何时揭示？
- 哪个人物拥有画面中心，何时失去？
- 哪个动作适合完整展示，哪个动作适合用细节、反应或遮挡完成？
- 哪个切点能减少生成模型必须同时维持的可见状态？

连续性不是像素连续。连续性是世界坐标、人物身份、动作因果、道具状态、光源方向和声音空间保持可信。镜头可以频繁变化，但每次换机位必须重新推导画面左右、纵深、遮挡、出入画和受光。

## 4. 镜头组设计

### 层级

`剧本事件 → 短片段 → 7–8个以上有效镜头 → 生成材料 → 剪辑后的片段 → 长成片`

一个有效镜头必须同时满足：

- 是一次明确、不间断的观看位置；
- 有独立的景别、角度、摄影机行为或视觉对象；
- 给观众增加新信息、动作阶段、情绪反应或空间关系；
- 有进入理由和离开理由。

重复裁切、无信息变化的推拉、同机位换文字描述，不计作新镜头。

### 常见覆盖功能

按剧本需要选择，不机械套用，但自主模式下镜头总数不得少于7–8镜：

1. 空间或关系建立；
2. 主体意图或动作启动；
3. 关键动作关系；
4. 身体、道具或环境细节；
5. 另一人物的反应；
6. 反打、视线落点或权力变化；
7. 动作结果或情绪转折；
8. 下一片段的视觉或声音交接。

镜头时长由观众读取、表演、动作、台词、情绪停顿和剪辑节奏决定，必须非等分。模型时长只约束提交方式，不拥有导演时间决定权。

### DIRECTOR_SHOT_PACKAGE

每个片段至少记录：

- 片段戏剧目标；
- 总时长；
- 首态与尾态；
- 世界空间与光源锁；
- 镜头编号与非等分时间；
- 景别、机位、焦段和运镜；
- 可见动作与表演；
- 台词、声音和停顿；
- 剪辑动机；
- 与前后片段的连续性交接。

## 5. 提示词映射

提示词只编码已经完成的导演判断，不负责临时发明镜头。

沿用 `ai-storyboard-director` 的六大模块与数字10信息内核：

1. 生成任务：写清这是一个含至少7–8个内部镜头的短片段，而非默认长镜头；
2. 主要主体：只写画面可见的身份、状态和表演约束；
3. 场景状态：写世界空间、方位、道具和光源；
4. 情绪目标：写可观察的情绪进展和权力变化；
5. 视觉风格：写摄影、材质、色彩、运动和负向边界；
6. 分段脚本：逐镜映射时间、景别/机位、摄影机、动作、声音、切点和交接。

分段脚本中的一个时间块必须对应一个真实镜头。不得把同机位的光线渐强、石粉下落等动作阶段伪装成多个镜头。

## 6. 生成与剪辑

先保留导演方案，再适配工具：

- 模型能稳定执行多镜头：用一条片段级提示词生成并检查每个内部镜头是否真实出现。
- 模型不能稳定执行：按单镜或小镜头组生成，保留身份、空间和光源锁，再剪成原设计片段。
- 平台限制导致需要拆段：拆的是执行批次，不是戏剧结构。

剪辑优先使用动作、视线、物件、遮挡、声音和信息变化作为切点。相邻镜头只需可靠传递当前必要状态，不强迫模型维持所有像素。

## 7. 返工闭环

完整看片后，按观众最早失去信任的位置排序：

1. 剧情看不懂；
2. 人物或空间断裂；
3. 动作因果不成立；
4. 表演和节奏失效；
5. 明显生成穿帮；
6. 声音后贴或不连续；
7. 次要画面瑕疵。

每轮只先解决最早、影响最大的劝退点，再重新完整看片。局部通过不等于全片通过。
