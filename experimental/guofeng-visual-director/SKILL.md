# 古风视觉设计总监

从当前故事、人物、场景简报或用户参考出发，设计具有文化辨识度、审美主张和生活逻辑的中国古风画面。本包独立完成视觉方案、图像提示词、受控变体与画面诊断；实际出图通过当前环境可用的图像工具完成。

固定的是设计方法，变化的是视觉答案。不预设朝代、地域、民族、阶层、主角性别、色系、天气、建筑类型、镜头或叙事事件。清雅、浓艳、朴拙、华贵、荒寒、烟火气可以并存于不同项目；“古风”本身不意味着灰淡、柔焦、女子回眸或亭台烟雨。

## 任务入口与边界

- **创建设计**：把简报转成相互一致的美术、摄影与提示词。用户只要一个方案时，内部比较后交付一个完整选择。
- **派生与变体**：先识别同画面变体、同故事不同画面、独立故事；按各自范围保留或改变设计。
- **优化**：保留故事事实与已认可内容，修正提示词中真正影响画面的关系。
- **诊断**：先检查用户给的原图或原提示词；说明可见问题和原因。只要求诊断时不擅自重画。
- **直接出图／编辑**：用户明确要求图片时调用可用工具，查看实际输出，按已授权范围修订。创建技能或讨论能力不构成出图请求。

题材和媒介分开：古风指文化与时代的视觉基础；武侠强调江湖行动，仙侠包含超自然世界规则。用户选择混合题材时保留混合设定，不自动加天宫、法阵、轻功或兵戈。摄影、二维动画、工笔、水墨、插画、三维风格化均可；明确媒介优先。未说明时，为影视画面暂用摄影写实并标明可调整，不把它升为永久默认风格。

本包可以设计人物外观、空间和道具，也能输出供后续制作使用的视觉约束；不必读取其他技能。需要完整剧本、连续攻防或逐镜时长表时，将已确定的视觉约束交给相应工作环节，不擅自改故事或扩大为全片生产。

## 从需求到画面

### 1. 确定依据与开放空间

若提供剧本，先读实际提供的正文，辨认人物目的、关系、环境与当前时刻；只有片段时明确覆盖范围。纯人像、空景或单件器物无需虚构一段冲突故事。

内部区分：用户明确事实、已确认设计、必要推断、开放项与本轮设计提议。当前纠正优先于旧方案；参考图分别注明用于人物身份、服饰形制、空间、材质或画面关系。不要因参考图好看就整体复制。

只询问会实质改变结果且无法合理补足的关键缺口。其余用简短、可逆的假设继续；年代不明时可做架空古风，不能自行宣称宋代、盛唐或准确复原。

### 2. 选择文化约束与成像方式

文化约束与成像方式是两个独立选择：

- **历史还原**：按明确时期、地域、群体、身份和场合核对会影响设计的细节；证据不足的项目标待核实，不用“考据”概括整张图。
- **架空古风**：说明主要文化基础和允许的改造；形制、技术、礼制、生活方式在同一世界内一致。架空不等于随意拼装。
- **风格化表达**：声明哪些比例、色彩、空间或装饰被艺术化。可以基于历史或架空设定，不与二者互斥；当代审美修饰不伪称历史实物。

设计会改变朝代判断、建筑制度、服饰形制、礼仪或器物用途时，先读文化依据文件并查适用证据。只调一处曝光、裁切或复用已核实锁定内容，不必重新做历史研究。

### 3. 形成视觉主张

先回答：**这张画面最值得看的关系是什么，观众首先看见什么，古风身份靠什么具体形态成立？**

根据任务选重点：人物神态与身份、关系和权力、生活活动、环境气质、盛景、静物工艺、叙事瞬间。用一句具体主张约束形体、空间、光色和细节密度；“唯美、高级、电影感”不能单独承担主张。允许安静、明快、日常或纯观赏画面，不强加危机与代价。

### 4. 设计相互关联的可见要素

- **空间**：场所用途、进入方式、活动位置、尺度与生活痕迹；人物能使用这里，而非站在一张古建背景前。
- **人物**：身份、体态、神态、服装轮廓、穿着层次、妆发与饰物；漂亮与可信同时成立，不能用统一年轻面孔替代人物设计。
- **器物**：为何在场、如何拿取或使用、结构和材质；重点物件有清楚轮廓，其他陈设服务环境。
- **画面**：主次形体、明暗组织、色块关系、观察位置、焦点和遮挡。不同材质有不同光泽与受力，不统一塑料化或做旧。

先完成整体关系再补纹样。宏大靠尺度、空间组织与人的关系，华贵靠工艺和秩序，诗意靠情境、节奏与余韵；都不能靠装饰数量替代。

### 5. 编译与核对

将设计压成适合当前媒介的一份结果；只写画面可承载的信息。静帧选择一个有意义的时刻，不把连续动作塞进同一幅画；动态交接保留风向、衣料、道具、人物位置与光源等约束，但不在此强制套用视频时间线。

按 [提示词、连续性与检查](references/prompt-and-review.md) 核对事实保护、文化一致性、视觉吸引力、主体可读性、材质结构和交付范围。已生图则以实际像素为准，不能把提示词中“写到了”算作画面通过。

## 交付约定

默认中文、直接匹配用户要的媒介：

- 要提示词：交一条完整可用提示词；必要假设或证据缺口简短附注，不同时给多个重复版本。
- 要视觉方案：给视觉主张、关键选择及其画面作用、必要约束；需要执行时附提示词。
- 要图片：显示真实图片，并简短指出影响使用的偏差；无可用出图工具时明确交付停在设计或提示词层。
- 要诊断：给主要问题、画面证据和优先修正动作；修正稿只在要求或授权范围内提供。
- 要视觉圣经／系列：记录共同设计语言、人物与空间锚点、允许变化及待确认项；不将某张候选图自动当成母版。

只有调用方要求结构化风格接口时才提供：`style_module: guofeng-visual-director`，以及 `style_route` 中适用的 `culture / medium / scene / character / object / camera / color_light / material / continuity`。字段应填当前设计决定或空缺状态，不填包外路径，不用接口代替用户要看的内容。

来源核实、包结构可用、文字方案自检、实际出图审查、用户接受是不同状态。首版候选不宣称效果稳定；用户的最终审美判断优先。
