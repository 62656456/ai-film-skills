# 5.4.3 实验候选｜输入职责与预演裁决

## 1. 输入只承担被授权的职责

| 输入 | 主要负责 | 不负责 |
|---|---|---|
| 纯文字 | 剧情事实、人物目的、动作因果、情绪变化、摄影机与视觉变换的可执行描述 | 像素级身份锁定、复杂拓扑的几何证明、参考运镜的精确节奏复现 |
| 人物／场景／道具参考图 | 身份外观、材质、色彩、固定地标和已批准设计 | 摄影机路径、动作时间、画外空间、完整拓扑 |
| 运镜参考视频 | 摄影机速度曲线、身体质感、阶段节奏、遮挡接力和运动语法 | 当前剧情事实、人物身份、场景拓扑、原视频中未授权的品牌或具体造型 |
| 3D白模／黏土预演 | 空间拓扑、尺度、站位、摄影机路径、碰撞、遮挡和进出接口 | 最终人物外观、材质、色彩、表演细节和成片光影质量 |
| 首尾帧／关键帧 | 指定时间点的构图、身份、状态和可见结果 | 两帧之间必然怎样运动、完整动作因果和空间路径 |

不得让素材职责自动外溢。运镜参考视频中出现的人物、建筑和品牌不自动进入当前故事；3D白模的灰色材质不自动成为视觉风格；风格图中的画面左右不自动成为世界坐标。

## 2. 裁决顺序

1. 先问当前失败风险来自哪里：剧情与动作描述、身份外观、运动节奏，还是空间拓扑。
2. 纯文字能把起点、触发、路径、接力、终点和硬约束说清时，优先纯文字。
3. 运动的速度曲线、手持重量、遮挡时机或复合节奏难以用文字校准时，引入运镜参考视频。
4. 摄影机与人物要穿越、环绕、循环、内外翻转或在非欧空间重接时，引入3D白模／黏土预演。
5. 多输入并用时，先写职责表，再写冲突优先级；没有职责分配不得直接编译提示词。

## 3. 冲突优先级

默认优先级为：

```text
用户当前明确事实与锁定项
> 已批准人物／场景／道具资产
> 3D预演提供的空间与路径事实
> 运镜参考视频提供的运动语法与节奏
> 风格参考提供的材质、光色和气质
```

若用户另有明确排序，以用户最新指令为准。低优先级输入不得覆盖高优先级事实；发生冲突时指出具体冲突并给出一个最小修正，不用“综合参考”掩盖。

## 4. 三种典型选择

### 纯文字直出

适合：单一连续空间、路径可描述、主体不超过两个、视觉变换有清晰形状接口。输出直接给五列分镜与六模块提示词，同时说明这是文字层行为验证，不保证特定平台一次生成成功。

### 运镜参考视频

适合：低机位高速跟拍、无人机揭示、手持重量、速度突变或遮挡接力依赖具体时间质感。提示词必须写“只借鉴摄影机运动语法与节奏，不复制人物、场景、品牌、镜头内容和声音”。

### 3D白模／黏土预演

适合：复杂空间穿越、非欧几何、镜头隧道、克隆调度、精确遮挡或多阶段无限缩放。先交预演要求：固定拓扑、人物代理体、路径曲线、机位高度、碰撞和关键时间点；预演通过后再把其空间事实编译进六模块提示词。不得把预演完成写成成片完成。

## 5. 验收

- 每个输入都能用一句话说明“负责什么”和“不负责什么”；
- 素材冲突有明确优先级和处理结果；
- 选择输入方式的理由直接对应当前失败风险；
- 未声称平台一定支持参考视频、3D预演或指定视觉变换；
- 预演、提示词、真实生成和用户体验四个验收层级分开记录。
